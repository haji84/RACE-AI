# 予想販売者の買い目から推定した展示前シャドーモデル v1（研究用）

## 凍結条件・目的

- モデル識別子: `seller-shadow-v1-20261104`
- 過去解析データ: 2026-10-13〜2026-11-03 の103件（本人投稿の3点買い目）と、そのうち64件の5点買い目。
- **前向き評価対象は2026-11-04以降に初めて購入締切前に保存したレースに限定**。103件は学習・着想のみ。後から成績に混ぜない。
- 公開コードはあくまで買い目から推測した規則であり、販売者の本物のノウハウ・内部計算式とは断定しない。
- このモデルは既存RACE-AIの正式A/B予想に自動採用しない。独立したシャドー研究系列。main統合、一般公開、課金、自動購入は行わない。
- **出走時点を保証する外部保存前は正式な事前予想としない**。JSON中の `built_at_jst` だけでは時刻の真正性を立証できない。

## 固定したルール（結果を見てから変更禁止）

入力: 当日付`race_cards`（全国勝率・級別）と`waku10`（枠番別勝率）、艇番照合済みの全6艇。**展示値・オッズ・人気・確定結果は選択に使用しない**。

1. 1着は1号艇に固定。1号艇の級別がA1/A2/B1、全国勝率5.6以上、枠番別勝率7.8以上で、それぞれ必要項目が欠測しないレースだけ候補。
2. 全国で候補が多い場合、日別最大5レースに制限。同点ならレースIDが小さいものを優先。候補スコアは `2×(1号艇全国勝率−6)＋(1号艇枠番別勝率−8)＋0.5×(1号艇全国勝率−他5艇の最大全国勝率)`。
3. 2着候補の順位は、2〜6号艇の `Z(全国勝率)+Z(枠番別勝率)` の降順。同点は艇番昇順。Zは当該5艇内の母標準偏差で標準化（標準偏差0なら0）。
4. 特定2着候補に対する3着候補の順位は、残り4艇を `枠番別勝率降順→全国勝率降順→艇番昇順` でソート。
5. 3点: 本命2着＋最有力3着（5000円）、本命2着＋次点3着（3000円）、対抗2着＋最有力3着（2000円）。
6. 5点: 上記3点に、本命2着＋3番手3着、対抗2着＋次点3着を追加し、それぞれ全5点2000円均等購入として別評価。
7. 1日最大5予想に選ばれなかった全レースは `FILTERED`、`RANK_LIMIT`、`MISSING_INPUT`、`NO_WAKU10` のいずれかを記録し、都合よく分母から消さない。

## 事前凍結と時刻の証明

- **レース当日の07:00 JSTより前**に処理できた場合だけ候補を生成。それ以後はエラーとする（過去日は `--dry-run` 研究専用）。
- 候補生成後、`model.py` のバージョン/commit SHA、出走表・枠別データの元ファイルURL/取得時刻/SHA256、予想JSON、レースIDを記録。
- **予想JSON本体は非公開Libraryなどへ保存**し、公開GitHub側にはJSON全体のSHA256と外部タイムスタンプだけを凍結する。非公開原本と公開コミット時刻の両方を検証して初めて正式な前向き予想と認定。
- 元データが07:00までに公開・確認できない場合は `NOT_FORECAST`。事後に遡って作らない。第三者データの使用権限と更新時刻も検証すること。
- 研究コードには通信・自動投票・認証情報・クラウド費用を発生させる処理を含めない。

## 予想販売者本人と比較する場合

本人が同日・同レースについて展示前に公開した**別の新規投稿**を収集して時刻照合できることが前提。販売者の未来投稿が入手できなければ `SELLER_NOT_OBSERVED` とし、「本人予想に何％似ていた」と勝手に算出しない。

比較指標は、(i) 選別レース一致率、(ii) 1/2/3着の本命買い目一致、(iii) 3点/5点の集合一致率、(iv) 非返還レースでの3連単的中率、(v) 実質購入額に対する払戻＋返還の回収率、(vi) 1レース1万円固定の損益、(vii) 未予想/欠測/返還/中止の数。買い目を見てから勝つルールに更新しない。

## 実行とローカル試験

```bash
python -m unittest discover -s research/seller_shadow_v1 -p 'test_model.py' -v
python research/seller_shadow_v1/model.py forecast --date 2026-11-04 --cards race_cards.csv --waku waku10.csv --out private_20261104.json
python research/seller_shadow_v1/model.py settle --forecast private_20261104.json --payouts payouts.csv --realtime realtime.csv --out settle_20261104.json
```

- `forecast` はソース取得完了後、当日07:00 JSTまでにのみ実行。既存出力は上書き禁止。
- `settle` は結果CSVのうち実際に存在する行だけを採点、未確認は `RESULT_UNVERIFIED`。F返還はコース欄から実艇番へ変換して全買い目に反映する。
- 出力の `AWAITING_INDEPENDENT_TIMESTAMP` はまだ公式な凍結証拠を意味しない。
- 同じ103過去レースでの2着本命再現83/103という探索結果は、**将来的中率を表すものではない**。
