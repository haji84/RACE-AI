# RACE AI

ボート・競輪・オート・競馬の予想・検証を統合する開発正本リポジトリ。競技ごとの専用機能もこのリポジトリ内で管理する。

## 競輪部門の一本化（2026-11-10）

- **競輪の唯一の開発先はこの RACE-AI**。選手情報・既存4モデル予想・映像学習・暗号保存・公式結果PDCAを既存の競輪モジュールとして継続する。
- 旧 [KEIRIN-AI](https://github.com/haji84/KEIRIN-AI) は履歴・旧設計の参照用。そこに新しい競輪開発を分岐させない。旧リポジトリの削除・アーカイブは行わない。
- 正式な開発GOALは Issue #67 / #68、既存競輪PR #101 / #102 / #103 に紐付ける。GitHub Actionsの既存実行経路を優先し、ChatGPTの新規定期タスクで並行運転しない。
- 一本化は実データ全件自動予想・学習・公式成績の完成を意味しない。合成CIと実レース証拠は明確に分ける。
- 詳細: [競輪リポジトリ一本化の決定](docs/KEIRIN_REPO_CONSOLIDATION_20261110.md)。

## 2026-10-13時点の初期記録（履歴）

- このリポジトリは設計の登録から開始。以前に別途作成された研究用v0.6の実装コードがここへ移植・動作検証されたことは確認されていない。
- 予想の的中率・期待値・回収率や展示動画の解析精度は実レースで独立実証されていない。
- 自動投票・決済は対象外。
- 発走前情報の時点管理と取得元の利用権限の確認を必須とする。

## 開発方式

設計変更は原則として変更ブランチからDraft Pull Requestを作り、レビューと検証を経てmainへ統合する。設計と実装の完了判定を混同しない。
