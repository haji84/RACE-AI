# RACE AI

ボートレースを優先対象とする確率予想・検証システムの設計正本リポジトリ。

## 現在の状態（2026-10-13）

- このリポジトリは設計の登録から開始。以前に別途作成された研究用v0.6の実装コードがここへ移植・動作検証されたことは確認されていない。
- 予想の的中率・期待値・回収率や展示動画の解析精度は実レースで独立実証されていない。
- 自動投票・決済は対象外。
- 発走前情報の時点管理と取得元の利用権限の確認を必須とする。

## 開発方式

設計変更は原則として変更ブランチからDraft Pull Requestを作り、レビューと検証を経てmainへ統合する。設計と実装の完了判定を混同しない。
