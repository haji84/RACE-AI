# RACE AI v0.9 モーター能力の乗り手補正と追加分析
設計日: 2026-10-13。状態: MOTOR RESEARCH IMPLEMENTED / ACTUAL RACES UNVERIFIED。

## 原則
「前節に新人が乗ったからモーターの2連対率を無視」とはしない。新人・上位選手で固定倍率を適用しない。
出走前に予測した選手自身の2連対確率（モーター評価を含めない）と実績との差から、「選手の能力で説明しにくい着順の傾向」を調べる。ただし数走では固有のモーター性能は確定できず、縮約する。

架空例:
- 事前2連対予測10%の選手が4着: 観測値0、残差-0.10。
- 事前2連対予測70%の選手が4着: 観測値0、残差-0.70。
過去レースから事後推計した確率を「当時の事前確率」と偽装しない。選手能力、枠・進入、相手の強さ、風、水面等を補正したモデルが必要。

## モーター履歴の構造
- venue + motor_cycle + motor_no で識別。番号が同じでも割当周期を混ぜない。
- race_id / meeting_id / racer_id / 枠 / 実進入 / 着順 / race_at / published_at / captured_at / source / hash。
- rider_label (rookie/other/unknown) と racer_experience_starts は補助説明項目。ラベルのみでは成績を機械的に下げない。
- baseline_top2 は出走前かつモーター固有の成績を使わない予測のときだけ入力可。ない場合は調整済み指標をnullにする。
- 節IDが確認できる場合にのみ previous_meet を表示。単なる前走を前節と呼ばない。
- 前節の新人が1人で数走しても独立標本と考えない。現行の有効標本は時間重みのみで同一選手/節相関は未補正。要検証。
- ギヤケース交換・主要部品交換では暫定的に機力の状態を分ける。プロペラ等の調整履歴も保存し、今後は校正する。

## 新たに追加登録する分析（現時点では未実装）
1. 現在節/前節のモーター直近5・10走、同一モーターに乗った過去選手のプロフィール。
2. 前節・今節の行き足、伸び足、回り足、展示数値の変化と整備情報の突合。
3. 1マークの攻め・抵抗・差し場、2着・3着の残り方、2マーク後の追い上げ。
4. 当日の風・波・潮汐・コース別着順・決まり手の時刻別更新。
5. 展示ST対本番STの選手別/コース別の乖離と安定性。
6. ピット離れ、チルト、調整重量、整備交換、選手コメント、予選・準優・優勝戦の得点条件。
7. 昼夜/潮位/風/出走間隔/相手の強さとの交互作用。
8. 全120通りの3連単確率、オッズ時点付き比較。通常8点、設定16/24/32点、期待値不足なら0点。
