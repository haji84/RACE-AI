## データと表示の条件

- 氏名・登録番号・車番は対象レースの確認済み出走表で結ぶ。脚質は掲載値を使う。同じ名前や車番による別レースの取り違えを防ぐ。
- 能力図には、計測や出走表で確認できた根拠を付ける。先行の手掛かりとなるバック先頭、捲り、差しは掲載回数で表示し、同じ目盛りで読めるようにする。瞬発力・戦術対応力・調子などの観測不足は軸を残して明示する。欠損値には点を描かない。1年・4か月の入着率は長期・直近の実績として扱う。
- 年間・5年間の率は、その期間と会場・開催段階が確認できるときに表示する。収録期間が異なる場合は資料の期間と分母を併記する。同日の複数走の前後が未確認なら順位の順番を作らない。Kドリームスの成績欄が含まれる保存済み出走表は、全車の氏名・登録番号、レースID、資料のSHA・時刻を確認して既存の公開カルテ資料に追記できる。
- 着順別の確率は、同一レース、同一出走者、予想時点と全着順分布を検証した資料から表示する。1着・2着以内・3着以内は同じ分布から算出する。資料が揃う履歴の研究予測では全員完走・同着なしの条件、モデルと時刻を添える。
- 本人コメントと戦術の見立てはそれぞれの出典・時刻を表示する。予想着順評価には確認済み分布から得た最頻着順・期待着順を用いる。コメントのみのレースでは発言に基づく見立ての範囲を示す。

## 操作の受入条件

公開予想のレースカードからカルテを開き、スマホで車番順の選手をタップして同じレース内の資料を切り替えられることを確認する。指定の6軸、全着順の棒と3つの集約値、成績の分母、コメント、戦術の表示を確認する。欠けた資料の扱いと、もとの画面への復帰を確認する。既存の三連単候補・信頼度・結果・モデル別的中率の表示は現行の受入条件を使う。

[11月26日に確認した公開版50の記録](KEIRIN_MASTER_READBACK_20261126.md#写真に合わせた選手カルテ)から、西武園11Rと小松島1Rの[確認済みの成績・コメントの要旨](evidence/keirin-rider-dossier-20261126.json)を引き継いだ。西武園11Rの山本勝利は準決勝10/11走と当場9/13走。同じ資料の出走表を氏名・車番で照合し、掲載脚質、競走得点、最終バック先頭、捲り、差しの回数を元のSHAとともに収録した。締切後に確認した閲覧用資料で、保存済み予想の証拠には使用しない。

## 日付変更と過去3年の収録成績

公開予想の初期表示はJSTの当日を確認する。公開前なら直近7日以内の掲載済みレースを探し、当日の掲載待ちと表示中の日付を併記する。再読み込みで当日分を確認できる。日付を選んだ場合と個別レースへのリンクは、その日付で開く。

- 2023-11-29〜2026-11-22の合計は登録番号を照合した2,404選手・463,082件。前半はKドリームスの保存済み月次結果を当時の登録資料などへ結んだ251,870件。後半は2025-10-01〜2026-11-22の既存の照合済み211,212件。同じ期間の重複を除き、11月23日以降は既存の公式日別結果から対象日前の確認分を加える。少数の選手も実数を表示する。
- 会場別成績・上がり・決まり手の基礎資料は2023-11-29〜2025-09-30。この期間の掲載50,962レースのうち中止7件、登録番号付きの着順を1人以上照合できた47,113レース、確認できなかった3,842レース。上がりは2,166選手・249,867走、決まり手は2,162選手・69,959件。3年収録分の会場率には対象期間と走数を添える。
- 瞬発力は同一レース内で上がりが速かった割合を参考表示する。同タイムは半分として数える。調子の参考は対象日前30日以内の確認済み3着内率。戦術欄には1・2着の掲載決まり手を添える。戦術対応力の計測は、仕掛けと相手の動きを対応付けた観測が必要。
- 公開着順確率は、レースIDと出走者が一致し締切前に保存・独立確認された全着順分布を使う。過去成績は登録番号に結び付いた閲覧用の集計で、対象日前の資料を表示する。 [過去3年の資料と照合の記録](https://github.com/haji84/RACE-AI/blob/cf4426da253334479ca3cff033f2eb20ea9ff4cb/docs/evidence/keirin-rolling-three-year-20261124/analysis.md)

## 予想掲載前と過去日の出走者

開催一覧で公開された会場別出走表から、開催日・会場・レース番号と車番を照合する。公式の公開名簿が揃ったレースはそれを優先する。Kドリームスの公開出走表を利用するレースでは出典と確認時刻を示す。登録番号は一致する確認済み資料を使い、公開登録名簿の氏名・府県で照合した場合はその根拠を表示する。

出走表が確認できたレースは予想掲載前や過去日も一覧から開ける。結果の表示と着順確率は従来の照合条件を使う。長期の総計の締め日が対象日と重なった場合も、対象日前に終わった期間の会場・上がり・決まり手は表示できる。日次更新は既存の公開結果ワークフローを使い、当日の出走表が登録済み全レース分そろった時点で再取得を止める。
