## 追加した予想要因
次の競馬専用・任意特徴を既存の4競技特徴量レジストリに追加した。

| 特徴名 | 評価対象 |
|---|---|
| previous_g1_route_win_signal | 前走G1のレース種類・直行ローテーション等と当該レースの勝率の相対的関係 |
| jockey_continuity_win_signal | 継続騎乗と乗り替わりの過去の勝率差 |
| route_jockey_joint_win_signal | 前走ローテーション×継続騎乗の組み合わせ |
| race_specific_history_win_signal | 開催G1固有の過去傾向。適切な比較群がある場合のみ |

「前走が宝塚記念×同じ騎手」も3番目の候補。ただし、過去の「8/8」の放送内容・母数・対象レース・指標は未特定であり、**実データとして登録・学習していない**。

## 研究用計算
正本：race_ai/horse_historical_patterns.py。

- まず比較対象（例：前走宝塚記念×継続騎乗 / 前走宝塚記念×乗り替わり）と、予測対象アウトカム（ここでは「1着」）を事前に固定する。対象期間・母集団・除外・集計方法を別途監査する。
- 前走データ・当該レースの出走条件・比較期間は予想時点に既に公開されたものだけを使う。
- 条件該当の勝利数 k、出走数 n、比較群の勝利数 kc、出走数 nc を受け取り、ベータ(1,1)事前分布の単純な平滑化による2群率差に n/(n+20) の小標本縮小を掛け、0.5を中立とした0〜1の補助スコアに変換する。
- 式: case=(k+1)/(n+2); comparison=(kc+1)/(nc+2); signal=0.5 + 0.5*(case-comparison)*n/(n+20)。
- この数式は暫定的な工学設計で、**校正済み勝率でも有効性が証明された推定量でもない**。「8/8」でも勝率100%とは扱わない。
- 実行結果の observation は既存の各特徴量と同じ公開/取得時刻、出典、用途別権利参照、標本数、変換バージョンを持つ。auditには両群の分子・分母・集団の文章定義を別に返す。観測値だけでは元資料の真正性は証明できないため、外部監査が必要。

## 予想コードへの接続
- race_ai/comprehensive_four_sport_models.py：競馬専用4特徴が入力可能になり、0.5を中立とした暫定係数0.18の補助評価を行う。値が欠落なら加点・減点なし。2研究モデルに反映。
- race_ai/four_sport_matchup_models.py：ベース評価に反映し、1着段階では補助係数0.10を追加。2研究モデルに反映。
- race_ai/four_sport_learning.py：学習ベクトルに特徴追加。欠測時は中立0.5と観測マスクを使用し、ベクトルと学習アーティファクトの版を変更。**実データでの再学習・前向き精度検証は未実施**。
- 予想は引き続き全3連単を評価、最大8点、オッズの入力禁止。追加の12点はオーナーの別枠・手動参考案のみ。公式Hit@8には混入不可。

## 入力安全
- 「8/8」というテレビの未確認情報を、source_refがありそうだというだけで検証済み統計扱いしない。分子分母・勝利/3着内の別・対象期間・比較群を監査した資料が必要。
- 研究入力でも published_at <= captured_at <= forecast as_of を満たす。PRODUCTIONや勝手な外部収集は許可しない。
- RESEARCHスコープでは、用途別権利判定の独立コールバックを必須とする。コールバックが通っても統計の真偽は別に検証する。
- オッズ、払戻、人気、レース結果を予想特徴に混入させない。
- 締切前の予想を事後編集せず、2026年天皇賞（秋）の結果は事後振り返りにのみ使い、検証済み未来結果と混ぜない。
