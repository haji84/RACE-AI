## PR #291に追加した実装

- `race_ai/keirin_blind_rider_holdout_gate.py`: 未使用レースの識別・学習履歴・検出原本SHAを検証し、別々の独立レビュアーによる全対象フレーム注釈が揃ったときだけIoUを用いて検出領域のTP/FP/FN、適合率、再現率、F1を計算。2者の回答が不一致、注釈漏れ、同一レビュアー、独立証明不足、改ざんされた入力なら全件HOLD。都合のよい一致ラベルだけを採点しない。
- `scripts/keirin_blind_video_review_packets.py`: 非公開の原動画から、元フレームSHAを確認して**予想枠を見せない**レビュアーA/B用画像と未完成ラベルフォームを生成。レビューする一部フレームの後選びで検出精度を良く見せることを禁止。非公開の画像はGitHubアーティファクトに公開しない。
- `tests/test_keirin_blind_rider_holdout_gate.py`: 16件の合成データテスト、`tests/test_keirin_blind_video_review_packets.py`: 6件の合成映像・非公開フォームテスト。

これらのテストはレビュアー関数を模擬した純粋なコード検証であり、本当の二者の独立性・正解確認を証明しない。ソース動画が存在しない、又は外部レビュアーが使えない場合の正しい出力は**精度null、HOLD**。

## 今後の本番合格条件（未達）

1. 採点前に検出候補・モデルコード・レースID・フレームのSHAを固定し、独立した別実行で読み戻す。
2. 同じ映像の元フレームを、予想枠と互いの回答を見せず別々に確認し、フレーム内の全選手の境界枠と車番の視覚証拠を記録する。人を写したものだけを評価する場合は**人体の境界枠検出器**と同じ対象の正解枠が必要。ジャージ色の塊と人体の枠を同じ検出指標で混ぜない。
3. 2者の注釈不一致はUNKNOWNとして別途解消。全員注釈が完成したフレームだけでTP/FP/FNと適合率・再現率を算出。未使用の複数レースで同条件を確認する。
4. 車番色一致とOCR数字の正解を別評価。車番と走行選手の継続同定を確認するまで「同じ選手の追跡」としない。
5. 先頭、番手、ライン、仕掛けを独立した映像証拠で局面ごとに採点し、6局面のcoverageとaccuracyを別管理。
6. 本物の締切前PR71予想原本SHAと検証済み公式結果を結合し、既存PDCAに接続。未見レースで基準モデルを上回ったと独立に証明できるまで学習重み・本番は更新しない。

**現在の結論**: 実レース映像・自動領域検出・候補原本固定・二者レビューフローの実装まで進んだ。二者独立確認による個人識別精度の本番合格、正式局面採点、PDCA学習はまだ未達。
