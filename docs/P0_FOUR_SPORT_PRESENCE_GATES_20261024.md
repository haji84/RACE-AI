# RACE-AI 4競技共通：直前情報が発表されたら予想入力の準備を開始（2026-10-24）

## 4競技の予想開始トリガー（10分上限は設定しない）

当日の出走を締切順に管理し、**公式のレース直前の映像・観察・数値のうち、対象となるイベントが本当に確認できた段階で入力充足チェック**を開始する。

| 競技 | 競技ごとの正本の観測イベント | 機械的に検証できる項目 | 監視・自動取得の現状 |
| --- | --- | --- | --- |
| ボート | 公式`beforeinfo`（スタート展示・周回展示と展示タイム） | 出走者ID、展示タイム、展示ST数値、風速/波高 | **既存PR64のHTML parser実データで成功**。しかし本番の無人・合法定期監視は未完成 |
| オート | 公式試走タイム発表 | 当該試走タイム、再試走/非数値状態、ハンデとレースID（予定） | PR71入力スキーマに`trial_performance`などは存在。**公式試走掲載を自動監視するadapter/E2Eは未実証** |
| 競輪 | 公式選手紹介（脚見せ）・並びなどの**信頼できる事前観測** | 選手紹介の映像/走行観察、正式な並びの根拠がある場合のみ | 選手紹介は実在するが、**公式の統一された数値掲載feedの権利・URL・時刻証拠は未確保**。映像があるだけで出走戦術を確定した扱いにしない |
| 競馬 | 公式パドック観察、または別イベントとして公式当日馬体重発表 | パドックは実映像/観察根拠がある場合のみ。**当日馬体重は「パドックを検証済み」と区別** | JRAは当日馬体重を出馬表へ掲載する。パドック映像/馬体評価の自動取得・利用許可は未実証。地方競馬は主催者/提供元ごとに異なるので一括して許可扱いしない |

## 予想には5段階の別々のゲートを通す

1. `PENDING`：対象の公式情報は公開されていない。または公式の公開状態が独立して確認できない。
2. `PRESENTATION_PUBLISHED` / `PRESENTATION_PUBLISHED_PARTIAL`：**公式を確認できる方法で、映像/試走/展示/馬体重の公開状態を当該race_idに紐づけて取得できた**。残り時間は10分制限しない。ただし映像や馬体重だけでは他の必要な特徴量を得たと判断しない。試走F/L等は欠測のまま。
3. `INPUTS_ADMITTED`：直前の公開データ以外にも、PR71既存モデルの**競技ごとの全必須データ**、K/過去成績や当日の風波等、個別の元公開・取得時刻、利用権限、変換係数と標本数が揃い、入力Firewallを通した状態。オッズ・他社の予想・結果は順位予想に入らない。
4. `PREDICTION_FROZEN`：**元PR71モデルの上位最大8点を実行**し、締切前に永続保存・読戻し・server側受領時刻を確認済み。結果を見てからの変更は禁止。
5. `SETTLED/PDCA`：公式結果、返還/不成立/訂正履歴を予想版とは別に照合。無予想や欠落は対象全レースの主KPI分母へ正しく計上する。

## 新しく登録したコードと検証範囲

- `race_ai/four_sport_presentation_trigger.py` はすべての競技について **明示的に別々のイベント名**（`boat: exhibition`, `autorace: trial_run`, `keirin: rider_introduction`, `horse: paddock` or `race_day_bodyweight`）で、供給済みの観測証拠をそのまま検査する**オフライン純粋関数**。
- この検査は、明示的なrace_id、観測段階、本人/参加者ID整合、source URL・SHA、時刻、欠測の種類を要求。展示10分上限は持たない。公式イベント公開が観測できたかだけ判定し、全競技の開始条件を一律「映像がある」にはしない。
- 公式と称する偽の入力が紛れ込まないように、将来の本番では**競技ごとの公式ドメインとHTML/データfeedの構造検証、用途権限、人間による原根拠の認定**を別に実装・検証する。現在の純粋関数は、`https://`表記だけから「公式に掲載された」と独立認定できない。
- `tests/test_four_sport_presentation_trigger.py`は架空証拠を使い、4競技それぞれの`AVAILABLE`確認、予定締切41分前でも候補になること、`PENDING`/出走者不一致/締切後拒否、競輪映像だけからライン数値を捏造しない、競馬の当日馬体重とパドックの区別、F/Lの非数値を維持、オッズ・結果フィールド遮断、元初公開時刻・権利未承認を確認する。
- **PR71本体・元係数/入力契約・過去に保存したTop8・PR64やmainは無変更**。公開データの継続監視、公式配信権限、全4競技の実レース前E2E、元情報公開時点と不変予想保存を、この合成テストの成功で証明したことにはしない。

## データ利用条件・運用制限

一般に見える映像・直前情報があっても、映像取得/録画・数値の自動収集・DB長期保存・学習・予想結果の一般配信・有料サービスには独立した利用条件の検証が必要。**公式掲載を即時検知する常時ワーカーや多会場の巡回は今回追加していない**。データ元の許容レート・クォータ、当日各開催予定締切、時間余裕、権限を審査してから正式監視ループへ接続する。

**判定**：展示・試走・選手紹介・パドック/馬体重について「公式掲載が観測されたら入力確認を開始」という共通の選定仕様はコードとCIに反映した。機械取得とモデル本番連結は、ボート以外まだ実証できていない。
