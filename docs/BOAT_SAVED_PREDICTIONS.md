# 保存原本の同期と閲覧

設定済みの `RACE_AI_STATE_KEY` を使い、既存の予想・結果を GitHub Actions 内で暗号化保存する。キーの再設定・持ち出しは不要。

2026-11-06 の朝版156レース・624予想に、並行作業の福岡6Rの別時点比較を加えた157組・628予想を保持した。福岡6Rは朝版と別時点のため、157をユニークなレース数として扱わない。結果観測5件、採点5件、保存ファイル版759件を保持する。11月5日の原本ZIP2本と既存の照合記録も同じ暗号化状態に含め、予想は再生成していない。

実データの生成側・独立復元側の証拠は [Actions run 42156874611](https://github.com/haji84/RACE-AI/actions/runs/42156874611)。カノニカル状態は `state/boat-pdca-encrypted-history` の世代2。公開するのは暗号文と件数・ハッシュだけ。既存世代・別作業の暗号化原本アーカイブも保持する。原本の完全な包含は、SQLiteのレイアウトに依存しない内容ハッシュと原本マニフェストで照合する。

## 既存の個人用画面

復元済みの私有SQLiteがある環境で、リポジトリのルートから実行する。

```sh
python -m race_ai.saved_pdca_view --state /private/pdca.sqlite --port 8875
```

`http://127.0.0.1:8875/` に保存済み予想を自動表示する。既存の7ページとレース詳細を使い、モデル・履歴なし／ありを切り替えられる。日付は保存原本の日を選び、後日開いても今日の日付で原本を隠さない。表示時にモデル実行・情報収集・採点は行わない。

この作業の個人用ビューは朝版156レース・624予想を対象とする。福岡6Rの別時点比較は暗号化保存に保持し、朝版の分母には混ぜない。同じレースの複数比較セットを含むSQLiteをそのまま投影した場合は、対象セットを明示するまで停止する。

配布用の単一HTMLも私有ディレクトリに書き出せる。

```sh
python -m race_ai.saved_pdca_view --state /private/pdca.sqlite --export /private/saved-predictions.html
```

HTMLには選んだ保存予想・結果の表示値を含む。公開Git・公開成果物には置かない。外部通信を許可しないCSPとスクリプトのハッシュを付け、元SQLite・暗号鍵は含めない。HTTPで配信した単一HTMLと既存ループバックAPIの両方でブラウザ確認済み。検証環境のポリシーが `file://` を禁止しているため、その直接起動は未確認。

既存公開サイトへの反映先URLは未確認。GitHub以外の新規ホスティング、Cloudflare・Vercelの再使用、予想原本の一般公開は行っていない。
