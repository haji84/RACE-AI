# 2026-11-08 松山1R 映像録画の一件実証

## 目的と判定基準
- 対象は松山競輪2026-11-08初日1R（発走20:40）のみ。
- 公開の [Kドリームス出走表](https://keirin.kdreams.jp/matsuyama/racecard/75202611080100/) 内「ダイジェスト映像」からブラウザ再生を試す。ストリームURLの抽出やDRM回避はしない。
- 合格条件: 実映像を本人の画録なしでブラウザ再生 → ブラウザ録画 → 松山1Rだと独立確認 → 実画面から選手位置・先行／捲り・⑤が④より先着した経緯をタイムスタンプ付きで説明 → 元の締切前予想と比較。
- 3-5-4という結果は結果照合用であり、動画から走行経過を判読した証拠ではない。
- 今回追加したコードは録画エンジンと技術的な再生検証のみ。現段階で実映像の取得・車番追跡・戦術的敗因検証を完了したとは言わない。

## 実証経路
1. scripts/keirin_replay_probe.py は対象公式ページを1回だけ開き、1Rの「ダイジェスト映像」をクリックする。
2. Playwright Chromiumが描画したブラウザ画面を16秒WebMに記録する。URL直接ダウンロードではない。
3. video.currentTime が進んだか、WebMが生成されたか、ffprobeで読めるか、簡単なフレーム差分があるかを検証する。画面の動きだけでは競走映像を確認できたとは判定しない。
4. 公開リポジトリのGitHub Actionsには**平文の原動画・フレームを保存しない**。一時WebMをAES-256-GCMで暗号化し、その鍵を試験専用RSA公開鍵で包んでから、暗号文のみを短期Action artifactに保存する。復号の秘密鍵はリポジトリやActionsログに置かない。永続保存の鍵管理と映像利用条件は別途確認する。
5. 技術試験を通過しても、動画内容の識別、レース中の車番追跡、展開の原因分析、予想モデルへのPDCA反映は未完了のままにする。

## 合成テスト
- python -m pip install playwright==1.56.0 opencv-python-headless==4.10.0.84 numpy==1.26.4
- python -m playwright install --with-deps chromium
- python -m unittest discover -s tests -p test_keirin_replay_probe.py -v

合成テストは競輪映像ではなくFFmpegで生成したテスト映像を用いる。合成テストに合格してもレース録画が成功したことを意味しない。

## 法務・安全ゲート
- インターネット上で視聴可能なことだけから、録画・保存・機械解析の利用許諾は断定しない。著作権法の情報解析例外と個別規約、技術的制約は分けて確認する。
- 認証の迂回、DRM解除、動画ストリームの逆解析、第三者への原動画再配布をしない。
- GitHub以外のクラウド製品、追加費用、新しい自動化タスクは導入しない。
- 元のレース前予想は書き換えず、映像検証結果も事後情報として区別する。
