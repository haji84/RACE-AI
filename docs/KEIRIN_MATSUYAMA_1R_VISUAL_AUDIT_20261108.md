## RACE-AI 予想の敗因
1. **①の能力上位と最終勝利を混同**。映像上、①が一時的に前へ出たことは確か。しかし③が最後の先着を決め、①を軸にした予想は外れた。「③のラインが最初から最後まで主導権を握った」という単純な説明は誤り。
2. **別線決着と隊列逆転の組合せを除外**。③→④→⑤の並びは、最終着順で③→⑤→④に逆転。⑤の追い上げを順位の条件付き分布に適切に残せなかった。
3. **8点選定で①②への集中が大きすぎた可能性**。会話で示した参考予想8点には③⑤④が含まれず不的中。ただしこれは学習済み公式RACE-AI原本の照合・確定モデル確率の評価ではない。
4. **確率校正は未完了**。走行映像1件のみでモデル重みは変更せず、類似展開での条件付き1-3着確率と番手・3番手の逆転率を過去複数レースで検証する。
