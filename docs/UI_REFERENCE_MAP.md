## 実装へ変換した要素

白・淡い青を基本面とし、紺でナビゲーション、青・青緑で選択状態を表現。カード・数値・艇番色・余白を統一。スマートフォンは下部ナビと縦カード、PCは左サイドナビ・中央情報・右補助パネル。ホームから一覧／詳細／手入力買い目へ遷移し、予算と購入事実を分離する。
