# Source fallback, official B/K LZH, 2026-10-24

BOAT RACE's official [download directory](https://www.boatrace.jp/owpc/pc/extra/data/download.html) links the B daily program and K daily results to the separate `www1.mbrace.or.jp` domain. Existing PR71 [`race_ai/boat_b_offline_archive_intake.py`] supports the source B archive with independently reviewed binary extraction/parsing, while PR72 supports same-day race audit.

`race_ai/official_bk_archive_transport.py` adds a **one-download-per-invocation**, bounded (4 MB / 10 s / no redirects) transport for the daily `B/YYYYMM/bYYMMDD.lzh` or `K/YYYYMM/kYYMMDD.lzh` path. This filename/path convention is consistent with third-party descriptions; actual live current date files and this endpoint's exact HTTPS behavior still require empirical verification. Strictly separate B advance programs as research candidates from K post-race settlement; never use K as a pre-result prediction input. Quarantine compressed bytes in memory, never write to public Git and never claim verified official contents before format-specific parsed review.

The caller must supply an **independently reviewed** decision for exact source URL, use purpose and request budget. Site publication of B/K links is not a blanket data-mining licence. The receipt contains SHA256, compressed byte count, local capture clock, HTTP Date/Last-Modified **unverified hints** and optional hashed ETag. Source publication time, underlying sample sizes, rights, decompressed identity, actual race finality and model admission remain explicit FALSE/UNKNOWN. CI uses mocked fake LHA payload bytes; no real provider downloads.
