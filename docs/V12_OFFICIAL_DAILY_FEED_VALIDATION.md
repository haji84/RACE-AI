## 更新対象を分離
1. 前日または完了した公式B/Kの事後履歴: 翌朝の1回更新と、ファイル公開までの再試行。
2. 当日の番組表、今節中の選手・モーター情報: 出走前だけを予測に使う。
3. 展示ST/通常展示・オリジナル展示・風・潮: レース締切前に時刻付きで追加する必要あり。
4. モーター台帳全数と利用開始周期、前節乗り手、整備履歴: 場別公式の同定または許可を受けたデータ提供元が必要。
5. 歴史データの恒久保存: 現時点で管理者の正式なデータ保管先が設定されていないため未完成。公開GitHub Actionsアーティファクトだけを永続DBの代わりにしない。
6. モーター乗り手補正: 事前の選手能力期待値を計算してホールドアウトで検証するまでは確率の本番出力に採用しない。
