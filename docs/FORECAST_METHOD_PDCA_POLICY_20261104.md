## 1. 予想の流れ（共通）

1. **全対象レース台帳**：日付、競技、会場、レース番号、締切時刻、開催/中止/発売の状態を登録。未予想、見送り、遅延、取得失敗は残す。
2. **同一の as-of 時刻で入力を固定**：出走者、選手・馬の識別子、過去成績、戦法、当日利用可能な展示・試走・馬場・走路・風雨・オッズ等を、出典・観測時刻つきで保持。予想締切より後の情報を特徴量へ混入させない。直前情報が未公表なら欠測と明記する。
3. **選手・馬の個別特徴**：全国成績の単純順位ではなく、コース/枠、直近の調子、展開・相性・得意条件、経験件数を統合。母数が小さい特徴は縮小推定し、年齢や知名度だけで過大評価しない。
4. **複数のレース展開をモデル化**：本命残り・先行/逃げ・差し・まくり/追い込み・混戦等の事前シナリオを生成し、それぞれの3連単候補を評価する。シナリオの確率は過去の未使用期間で校正できるまで「研究値」とする。
5. **正規の全3連単候補を順位付け**：出走人数に合った重複なしの組合せを評価し、推定確率（校正済み/未校正を区別）と根拠を表示。人気順と予想順位を混同しない。
6. **買い目と見送り判断**：固定8点を基準、固定12点を比較対象、事前の荒れ判定に基づく可変8/12点、信頼度に基づく少点数1〜8点の4系統を、同一レース・同一時点で独立比較する。**予想を出す場合の買い目は必ず1〜12点。0点の予想は生成しない。** 見送り・未予想は予想とは別の状態で記録し、全レース台帳から消さない。最少点数や荒れ判定の閾値を事後の的中から都合よく選ばない。校正不足なら少点数/12点の切替はシャドー評価のみ。
7. **締切前の不変保存**：競技・場・R・モデル版・as-of・選択ルール・全順位と採択券・券別根拠・締切・元データSHA・保存時刻/独立受領証拠を版別に記録。A（早期）/B（直前）等の異なる時点を混ぜない。結果後の書換え禁止。
8. **結果と払戻の独立照合**：3連単、100円払戻、返還対象番号と券、中止、失格、同着、訂正履歴、結果出典・取得時刻を保持。全額返還は不的中にせず、部分返還は券別精算。取得不能は未確認とする。
9. **毎レースPDCA**：1着候補未カバー / 1・2着ペア未カバー / 3着違い / 的中 / 返還・特殊を分類。予想順位別Hit@1/3/6/8/12、選択点数別収支、配当帯（1,000円未満、1,000〜4,999円、5,000〜9,999円、1万円以上）、万舟捕捉率を比較。実購入と100円/点の仮想購入を分ける。
10. **学習候補→次回採否**：予想後に判明した結果はその予想には一切使わず、日付順TRAIN/VALIDATION/TESTで候補係数・展開モデル・点数最適化を独立評価。対象全レースを分母とする指標と、購入/予想したレースのみの指標を併記。新方式が有意に改善し、必要な受入確認を通るまで現行モデルを自動置換しない。

## 2. 競技別特徴量の優先順位

- **ボート**：選手ID別の実進入コース、枠→進入変更・前付け率、1コース逃げ率と勝者決まり手別敗戦、2〜4コースの差し/まくり/まくり差し、前付けされた際の成績、直近10/30走、当地・モーター・展示/ST、風/波/天候、対戦相性。1号艇が勝てないシナリオを必ず別評価。勝者の決まり手だけで敗者の「差され弱さ」など因果特性を断定しない。
- **競輪**：選手ID・ライン構成、先頭/番手/三番手・単騎、直近先行/捲り/差し・S/B傾向、バンク・距離・風、相手ラインとの対応力。1着候補の漏れ、2着ペアの漏れを検証。
- **オート**：選手別スタート力、試走、ハンデ、走路状態（湿走路を含む）、整備・直近走・枠と展開。試走前Aと試走後Bは別as-ofで凍結し、事後に同時点だったと主張しない。
- **競馬**：馬・騎手・調教師、近走、枠/距離/コース・馬場適性、脚質とレースのペース、調教や当日公開情報、展開上の相性。テレビ等のジンクスは説明可能な過去データで検証されるまでは検証候補として分離し、予想確率へ無条件採用しない。

## 3. 11月3日の課題と11月4日の採点

2026-11-03朝版252レースは**参考照合**で、全額返還4レース除外後99/248的中（39.92%）、仮回収率73.46%。結果/返還記録が揃ったことは、252件すべての一次公式独立監査の証明とは異なる。

- **課題**：3競技合計で外れ149件のうち1着候補漏れ77件、2着ペア漏れ39件、3着違い33件。ボートで1号艇1着に偏重。低配当には強く、万舟や5,000円以上の決着に弱い。
- **11月4日の事前評価（未実行・未合格）**：①固定8点 ②固定12点 ③事前荒れ判定で8/12点 ④1〜8点の少点数候補（予想最少1点。見送りは別状態）。予想原本を別ハッシュで事前保存し、全対象レースで的中率・回収率・仮収支・網羅率・見送り率を対比。12点で的中が増えても購入額の増加に勝てないなら不採用。
- **98%の目標**：全対象レースを用いた未来の前向き実測でのみ評価。到達を保証せず、回収率・サンプル件数・未予想を隠さない。

## 4. 保存状態と実装の境界

本書は**予想の出し方の仕様案としてGitHubに保存**したもの。既存 `boat_racer_tendencies.py`, `boat_tactical_scenarios.py`, `boat_feature_adapter.py`, `historical_pairwise.py`, `verified_bulk_backtest.py` は関連する研究/照合実装だが、全競技の実データが完全に接続され、点数可変ルールが自動稼働することを意味しない。

## 5. 2026-11-04 実装追加：予想エンジンと最低1点の契約

- `race_ai/ticket_selection_engine.py` を新設。`four_sport_model_suite.run_suite` は従来の4競技共通全候補順位と旧 `ordered_top8` を変えず、`ticket_trials` をモデルごとに出力する。予想を発行する場合は**1〜12点**で、0点リストは禁止。
- 比較版は `fixed_8`、`fixed_12`、`spread_adaptive_8_or_12`、`confidence_shortlist_1_to_8` の4種類。同じas-of、同じ原順位から抽出し、モデル元SHAと別の提案SHAで検証する。
- 可変12点は予想前に算出した「1着候補確率の散らばり」の未校正代理指標、少点数は上位券の未校正スコア比で決定する。**現状の数値・閾値は実証済み確率でも勝率でもなく、研究用。** 元の8点を自動で本番置換しない。
- 未予想・購入見送りの `NO_BET` は0点の予想と同義ではない。研究用券は1点以上発行できても、実投票を許可・実行した意味ではない。
- `evaluate_ticket_trials` は予想と独立した結果イベントの締切後観測を要求し、返還・中止を別精算する。実ソース・独立した締切前保存時刻の真正性までは証明しない。正式な比較結果の算出は、これらの証拠が揃った後。
