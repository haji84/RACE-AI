## 次に完成させる順序（実装を増やすよりE2E）

1. **全会場のレース別進捗台帳**：当日公式全国一覧→会場12R締切を統一。未開催・終了済・展示未公表・欠場・保存失敗を分類。公式の結果一覧が遅れても各個別`raceresult`を検証可能な範囲で照合。締切順で次に予想できるレースを処理し、既存予想IDは共通索引でスキップ。
2. **全国1日分の実稼働を完走**：新しい未来レースA/Bを同じ6艇と展示データで計算し、締切前の外部時刻・保存SHA読戻しを1件ずつ確認。保存不確実なら再投稿禁止。後からの変更や確認済みの過去結果を新規予想に使わない。
3. **終了順の結果→PDCA→次レース**：結果確定後に別revisionで追記。A/B別にHit@1/8と勝ち券順位・多クラスBrier・Log loss・払戻・返還を集計。1レースの結果を見てBの重みや過去予想を差し替えない。次レースには前時点の事実だけを使用。
4. **若手・個別展開の実入力**：当日出走の選手登録番号に対する**締切前に取得済みの過去K**で、選手ごとの実進入、枠と進入コースの移動、当該コース勝率、1コースの逃げ成功、イン敗戦時の勝者の決まり手、外に押された時の3着内、直近10/30走を分母とともに記録。これをC戦術モデルにのみ入力し、事実がなければ`MISSING`、年齢を能力とみなさない。実データのC前向き凍結が通ってからA/Bと比較。
5. **万舟取りこぼし監査**：確定3連単の100円払戻が1万円以上の実レースを集計し、そのうち各モデル上位8点に含まれたかを追跡。締切前のオッズ100倍以上は**確定万舟とは別**で、配当の変動・返還を踏まえた探索用の候補。主指標Hit@8は8点で固定し、6本命＋2穴の独立仮説が成立するか保留レースで検証。
6. **正式な改善判定**：予想原本が同時保存された少なくとも100レース/5開催日/10会場日ブロックを暫定比較ゲートにする。母数不足ではモデルB/Cの自動昇格禁止。Hit@8_all 98％は別の最終目標であり、現状未達。
