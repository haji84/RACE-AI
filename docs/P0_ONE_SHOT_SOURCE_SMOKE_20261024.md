# Single source transport smoke, 2026-10-24

BOAT RACE official racecard URL: https://www.boatrace.jp/owpc/pc/race/racelist?hd=20261025&jcd=11&rno=1 . The official policy https://www.boatrace.jp/owpc/pc/extra/policy.html prohibits unauthorized protected-content reuse and high volume/operations-disrupting requests; this specific engineering probe is **one bounded GET, not any continuous collection or a licence for training or reproduction**.

`scripts/p0_single_source_smoke.py` is a single URL, one-read script with max 1.5 MiB, 8-second timeout, no redirects, no retry or backoff recursion, no cookies or authentication, no raw HTML publication and sanitized logs. It captures the SHA256, length, source HTTP Date/Last-Modified **as unverified hints, not publication times**, runner clock capture time **without external timestamp attestation**, and whether the existing PR72 racecard AUDIT_ONLY parser accepts the actual HTML. No feature normalization/admission, odds, betting or publishing.

The one-shot workflow `.github/workflows/p0-single-source-smoke.yml` is limited to the dedicated `p0-source-smoke-20261024` push branch and a single trigger marker `docs/evidence/p0-smoke-trigger-20261024.txt`; no schedule/PR rerun/cron, no write permissions, GitHub credentials or paid resources. It does not run on Draft PR branches or main. The workflow may report connectivity blocked (e.g. provider 403 / network DNS / layout drift): such results must be retained rather than hidden. Moving this mechanism to scheduled multi-venue operation requires independent terms/rate/purpose evaluation and explicit scope.

**Not yet a real forecast E2E**: the official live HTML may differ from the invented table fixture; parsers should reject unexpected markup, never hallucinate provenance or required model input values. Future races need actual official sales-cutoff evidence, published and captured times, sample sizes, independently documented feature normalizations, then PR71 delivery + actual GitHub freeze + outcome revisions.
