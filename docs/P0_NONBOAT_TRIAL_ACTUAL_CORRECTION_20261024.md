# RACE-AI 2026-10-24：非ボート3競技の掲載差分実証と利用権限の実査

対象 [Issue #67](https://github.com/haji84/RACE-AI/issues/67)、既存Draft [PR #72](https://github.com/haji84/RACE-AI/pull/72)。事前入力と結果を分離し、PR #71の全モデル係数・既存予想を変更しない。

## 開催中止の過去誤判定を撤回

旧実験 [Actions #40068720296](https://github.com/haji84/RACE-AI/actions/runs/40068720296) では伊勢崎10月24日のAUTORACE.JPプログラム内の「該当レースの開催は中止となりました」を**対象開催が中止**と誤判定していた。しかし、[伊勢崎競走場公式の2026年10月24日GⅡ開催案内](https://www.isesaki-auto.jp/race/)は当日開催を示す。また[同じAUTORACE.JPの10月22日12Rプログラム](https://autorace.jp/race_info/Program/isesaki/2026-10-22_12)は当該中止の定型文と、選手8車分の試走Tデータを同じHTMLページに掲載している。このため旧ステータスの **`EXPLICIT_CANCELLATION_NO_TRIAL`を撤回**し、コードは`AUTO_GENERIC_PAGE_RACE_STATUS_UNVERIFIED`へ変更した。偽の中止をもとに予想スキップしない。

新規`race_ai/autorace_official_trial_adapter.py`はURL中の公式競走場・日付・R番号を元HTMLのレースID・可視行と照合し、**「試走T」見出しと同じ表に属する車番と試走タイムの対応**が確認できる場合に限り`trial_data_observed`候補にする。説明テキスト、過去5走成績、他レース、オッズ、直近結果を混同しない。車番値の非数値・欠車は欠測。車番8個の時だけ8/8と報告できる。キャンセルには別のrace-bound提供元決定証拠が必要。合成回帰では、8車分の数値が存在するのに汎用中止文言もあるケースを安全に扱う。

## 明示的に照合した規約・取得頻度のゲート

## 2026-10-24 19:45追記：伊勢崎11Rの5回の実観測とテスト結果

同じ公式11Rについて、前述の3回に加え、[19:39:42の1GET #40086785363](https://github.com/haji84/RACE-AI/actions/runs/40086785363)および[19:42:40の1GET #40086983883](https://github.com/haji84/RACE-AI/actions/runs/40086983883)で元HTMLのSHA・日時・DOM表構造だけを確認した。

公式HTMLは都度HTTP200、日付と11Rの表記があった。最後の取得でも3つのtableのうち試走ラベルを含む表が2列15行であることは確認できたが、**車番に対応する試走タイムの値の真正な抽出は0**。前後で原HTMLのSHAが違うからといって`PENDING→AVAILABLE`の正式発表を証明していない。初回の見出しや汎用の中止バナーだけで試走Tあり/開催中止扱いにする誤判定は排除した。両者とも明示的に未認定。

[5回の時点別GitHub実行証拠の集計(JSON)](https://github.com/haji84/RACE-AI/blob/feat/p0-offline-discovery-gate-20261022/docs/evidence/P0_IS11_FIVE_PRE_CUTOFF_TRIAL_OBSERVATIONS_20261024.json)を新規保全。これらはrace_id/取得時点/HTML SHAのみで、選手の原数値・映像・元HTMLを公衆配布しない。**取得成功は継続監視・学習・再配信の許諾の根拠にならない**。

新規`autorace_official_trial_adapter.py`は公式DOMの車番→試走Tが専用表に存在する場合を合成データでテスト。並列2列・ネストしたHTML spanでも8車を抽出する合成回帰が成功。公式の実レースではこのパーサーを通る行がないため実試走値の配信経路・DOM契約の追加調査が必要。試走TがJavaScript/AJAXでロードされている可能性はあるが、本HTTPだけでは確認できていない。**架空の公開時刻・値を作らない**。

[CI #40087111526](https://github.com/haji84/RACE-AI/actions/runs/40087111526)にて、head `da41e15a163a4df598528f4facd684b473085d36`で通常290テスト、PR64/71統合12テスト、同一レース接続6テスト成功。現行の模型予想や正式Top8は実行していない。

## 公式ポリシーの具体的な運用判断

- **AUTORACE**：[利用規約](https://autorace.jp/policy/)は運営者と第三者のコンテンツ保護と無許諾の転載・複製・送信等を明示している。個別試走数値の自動収集・定期的再取得・private保存・AI学習・自作予想配布に必要な契約または適法な例外、アクセス頻度は**確認できていない**。従って無人監視は許可しない。
- **JRA**：[ご利用に際して](https://jra.jp/use/)は映像/音声/画像/記事等の権利および法定範囲外の二次利用許諾、特に映像について法人に限定された申請方式を示す。当日馬体重を出馬表の一部として合法に数値分析できる条件と、パドック動画の保存・AI視覚分析は**別の審査**。競走終了後の馬体重を締切前に取得済みと捏造しない。
- **KEIRIN**：[サイトポリシー](https://keirin.jp/pc/dfw/portal/guest/policy/index.html)では公式映像/文章/画像の著作権と例外範囲外の複製・転用を制限。公式日程と脚見せ映像を混同しない。source確保・視認できた映像の内部分析・長期記録/配信・商用目的をそれぞれ別の使用条件として判断する。

提供元の各目的別レート上限が公開資料に明示されていないため、**毎分/全Rの自動巡回を技術的に可能というだけで開始しない**。正式な契約や発表通知インターフェースを確認できた後に、時点付き2観測が`PENDING→AVAILABLE`になったことを検証し、同一Rの自律起動へ進む。
