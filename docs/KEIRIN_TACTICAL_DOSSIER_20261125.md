# 競輪の選手カルテ、着順確率、展開照合

開発正本は `haji84/RACE-AI`。既存のA、改善前B、C方針、締切前原本、本人用保管、結果の改訂履歴を保全する。比較は三連単上位4点・二車単上位2点を主にし、三連単1・4・8点も同一レースと時点で採点する。全国・最大8点で95%は複数開催日の前向き評価で判定する。

## 既存コードの利用

- `scripts/keirin_rider_profile_history.py` と `scripts/keirin_rider_profile_identity.py` に登録番号で照合した過去走を渡す。長期間の実績と、直近30・20・10・5走を別に扱う。格付け、同場、ライン役割を考慮した既存の寄与と、各期間の観測件数を別々に示す。
- `scripts/keirin_video_rider_learning.py` と `scripts/keirin_tactical_history_study.py` の確認済み観測を使う。時計、登録番号、情報源、観測範囲を記録し、目視で確定した項目から選手に結ぶ。発言と行動は別イベント。走路速度は校正できる測定を要する。
- `race_ai/keirin_nationwide_auto_generator.py` と `race_ai/keirin_rider_context.py` の6局面を用いる。初周・打鐘・最終H・最終B・4角・ゴールの間に仕掛けや反応の順を保存する。展開の仮説、発生確率の検証、実際の映像観測を別に保存し、戦術は学習・独立検証後に比較Bへ渡す。
- 既存の順序付き三連単分布と、残る選手の条件付き着順分布から同じ着順分布を構成する。三連単・二車単・全選手の着順ごとの確率はその共通分布を使い、全員完走・同着なしの条件を明示する。比較Bのものとして保存・採点し、公式の着順取得と払戻の有無は個別に扱う。
- 既存の `keirin_form_fall_blind_pdca` で締切前原本と着順を照合し、展開は独立した観測から採点する。公開予想に展開の原本がなければ、的中を採点して展開はE。会話に基づく事例は参考判定を付け、正式な展開の分母に入れない。保留理由と観測できた局面を次回試験に渡す。
- 元サイトでは選手名から出走時点の実データを表示する。追加の資料は、レースID・車番・予想原本SHA・予想時刻で一致した資料を使う。率が校正された範囲を示し、観測欠損を表示する。配備先と既存の公開対象を引き継ぎ、予想原本や本人用資料を変更する必要はない。

## カルテに追加した観測項目

| 項目 | 分母と観測内容 |
| --- | --- |
| 捲りへの抵抗力 | 別線が外から進出し、対象選手の位置に到達した観測機会。区間終了まで出切らせたかの判読が可能かを記録 |
| 番手からの自力発動 | 実走で番手にいて先頭の失速を確認した機会。自力加速の発動有無と未判読を記録 |
| 並走時の持続力 | 並走の観測機会。速度の維持を判定できる校正済み測定と、相対位置だけの記録を区別 |
| 戦術の切り替え能力 | 追走中から自力へ移行する状況を観測した機会。発動と成功の根拠を保存 |
| 消耗後の末脚 | 踏み合い等を観測し、終盤まで追えた機会。相対的な伸びと実測速度を区別 |
| 内外の位置別能力 | 内外を特定した並走機会。公式着順を結んだ件数と未取得を内外それぞれに記録 |

`race_ai/keirin_tactical_observations.py` で確認済みの観測機会、結果あり、結果不明、資料の矛盾を集計する。成功率は結果を確認できた観測の割合とし、観測全体に対する結果不明時の範囲も残す。一件の観測から次走の能力を断定しない。

終盤で①が④を外からかわし、その後に⑤が①を外からかわした。捲りを受けた2つの場面と、内外を相対的に判別できた4件の選手位置を公式着順に結んだ。並走中の速度、番手の自力発動、追走からの切り替え、先行争い後の消耗は未判定。[観測した場面](evidence/keirin-tactical-dossier-20261125/seibuen-11-tactical-episodes.json)

## 着順履歴、多段階の展開、着順確率

- **着順履歴**　登録番号ごとに全収録期間、3年、1年、6・4・3・1か月と直近30・20・10・5走を集計する。西武園11Rの7人と11月26日の確認済み72レースの501人で読み戻した。翌日は500人に直近30走分、1人に28走分の公式着順があった。今回使った実績は11月22日までで、収録外の件数は不明。時系列採点では予想時点のアーカイブ版を使う。[実データでの照合](evidence/keirin-tactical-dossier-20261125/finish-history-verification.json)
- **条件別履歴**　会場、掲載ラインの役割、級区分S/A/Lを単独・交差で集計する。西武園11Rの同会場・掲載時と同じ役割・A区分がそろうのは4人14走。翌日の確認済み501人のうち397人に同会場の記録があり、203人に同会場で役割と級区分まで知られる走があった。実走中の位置は別資料で評価し、欠測件数を表示する。[条件別の読み戻し](evidence/keirin-tactical-dossier-20261125/finish-history-filter-verification.json)
- **多段階の捲り**　締切前の得点、S・H・B、脚質、決まり手、掲載ラインから、相手の仕掛けに続く捲りを複数の6局面で表せる。西武園11Rの締切前資料を使った事後再現では、108の条件付き展開に観測と同じ②の先行、④→①→⑤が含まれた。位置と追走は展開の条件として扱う。観測した仕掛け順の候補への収録と、予測精度の採点を分ける。11月26日の確認済み72件のうち68件で比較用の展開を締切前に暗号化して保存した。競りの3件と条件を満たす複数ラインがない1件は項目別集計で保留。発生確率と前向きの展開精度は未検証。[事後再現](evidence/keirin-tactical-dossier-20261125/multi-stage-case.json)・[締切前の固定](evidence/keirin-tactical-dossier-20261125/multi-stage-forward-receipt.json)
- **着順確率**　比較Bで三連単の全組を一つの同時分布とし、残る選手の条件付き着順を過去の完全着順25,471件から学習した。75レース全516出走で、選手ごと・着順ごとに確率の合計が100%になり、二車単も同じ分布から求められた。選手別に2着以内、3着以内、着外、最頻着順、期待着順を算出する。全員完走、同着なしが前提。時系列で後続の12,234件では4着以降の対数損失が3.367から3.285に下がった。同じ三連単8点の的中は4,583件で同数。公開二車単の照合済み57件では上位2点の的中21件、実掲載点数の的中26件がいずれも同数。全選手の確率校正と公開表示は未完了。[同条件比較](evidence/keirin-tactical-dossier-20261125/joint-finish-verification.json)・[二車単57件の再採点](evidence/keirin-tactical-dossier-20261125/verified-joint-exacta-2113.json)
- **確率と実績の照合**　締切前の出走表まで照合できた321レースで、3着以内の予測が80%以上だった延べ188出走を調べた。平均予測は87.5%、実績は84.6%。この時点では公開信頼度を確定していない。[確率帯別の標本と採点](evidence/keirin-tactical-dossier-20261125/joint-finish-reliability.json)
- **バンクと気象**　西武園で400m、みなし直線47.6mの資料と、締切前に取得した所沢アメダスの観測を照合した。その風補正を前向きに試した6件は補正前後とも3件的中。翌日の確認済み72件では7場全てのバンク資料と気象庁の地域予報を保存した。場内の風と走路状態、翌日の実測、予想精度の改善は未確認。翌日の既存固定予想ではこの気象資料を使っていない。[入手時刻・出典と比較結果](evidence/keirin-tactical-dossier-20261125/venue-weather-verification.json)

残る工程は、観測資料をそろえた条件別カルテの拡大、本人コメント・気象・個別バンク適性の接続、多段階仕掛けの候補の順位付け、比較Bの校正と独立採点、全国のカルテ更新・展開照合までの定期運転。ここで確認できた精度改善は4着以降の着順分布。三連単・二車単の精度改善や全国稼働は引き続き検証する。

## 確認資料をカルテに入れる

既存の本人用生成 `scripts.keirin_build_rider_dossiers` に `--tactical-observations` と `--expected-tactical-sha256` を追加した。入力はレビュー済みの `KEIRIN_REVIEWED_TACTICAL_EPISODES_V1`。出典原文と選手・車番・着順資料を確認したレビュー担当者が作る。生成処理は別途確認したSHAを使い、レース、登録番号、車番、出典と結果の対応、時計を検証する。日本時間の対象日より前に確認できた過去の観測を既存の集計器へ渡す。観測から能力の予測値は作らない。選手名・着順履歴の通常処理は従来の入力のまま実行できる。

- **京王閣6R、2024年10月29日**　①森田一郎の先行する脚の使用は本人談、最終3角からの踏み上げと直線半ばの追い抜きは公式詳報。公式結果と登録番号を照合した。後日確認済みの観測として「消耗後の末脚」1件を集計できた。実測速度や消耗量は不明。新しく観測を確認した当日の予想時点では除外された。[公式詳報](https://keirin.jp/pc/dfw/portal/guest/report/GIII/27keiokaku/2024/report_4.html)
- **松阪7R、2025年9月9日**　⑥橋本優己の勢いが落ち、予定番手の③東口善朋が最終2角過ぎから自力で仕掛けた順序を公式詳報で確認。東口は4着。掲載ラインは⑥―③だった。仕掛け時の実際の車間・追走位置は未確認のため「番手からの自力発動」の集計は保留。[公式詳報](https://keirin.jp/pc/dfw/portal/guest/report/GIII/47matsusaka/2025/report_2.html)
- **函館5R、2025年9月16日**　⑤市本隆司の保存映像・結果・登録番号を使い、戦術切り替え1件を既存集計器で読み戻した。レビューが確認できた日より前を基準とする場合は保留し、次の日の基準では1件を集計した。[出典と映像区間](evidence/keirin-tactical-dossier-20261125/hakodate-5-tactical-switch.json)・[生成時の採否](evidence/keirin-tactical-dossier-20261125/hakodate-5-dossier-admission.json)
