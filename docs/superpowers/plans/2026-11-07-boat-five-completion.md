# BOAT Five Remaining Gates Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans within each isolated
> ownership domain and superpowers:dispatching-parallel-agents for independent
> domains. Root integrates and obtains a fresh whole-change review.

**Goal:** complete the five acceptance gates with genuine original data and
durable GitHub operation, with honest pending states for future observations.
**Architecture:** retain existing native models and owner view. Add authenticated
external prediction evidence, encrypted exact-original retention and bounded
history views; use the existing hourly automation for environment-independent
coordination.
**Tech Stack:** Python/unittest, Node24, existing AES-GCM/Git state and browser.
**Spec:** `docs/superpowers/specs/2026-11-07-boat-five-completion-design.md`.

## Global Constraints

GitHub only. Active source run unchanged. 240/45 GET, 24 rounds/65 minutes,
180-second polling. No original mutation, plaintext private upload, root-key
export, source-denial bypass, main merge, new task/service/fee/permission or bet.
Use existing hourly automation without changing its cadence.

## Review Focus

- A missing projection clock must not become an invented original timestamp.
- Same-frame/course/window/scoring semantics must match the actual source.
- Expired or denied live artifacts must not lead to fabricated receipts.
- Pending/void/refund and duplicate model variants must preserve denominators.
- Old/new viewers and active producer versions must retain original inventories
  across evidence enrichment and historical view routing.
