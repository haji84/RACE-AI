# 1レース1,000円の参考配分と収支

ユーザーは既存の日予算試算に1レース1,000円の場合を追加し、追加分を単純な予想順位では決めず、その時の信頼度の根拠や穴候補へ配分することを希望した。保存原本には検証済みの信頼度や事前の人気・オッズがないため、最初の提案は参考配分であり、的中確率や穴判定の実証として扱わない。追加の任意質問にはモデル間の支持・履歴の安定性を使う案を示し、まずその前提で進めると伝えた。

比較方式は既存800円均等を残し、1,000円上限の参考配分を追加する。Top8各100円に、追加200円をモデル間の支持で配分する。選択原本と同じ時点・同じ締切で、選択原本の保存時点までに生成・保存された完全なTop8だけを用いる。曖昧な重複、時刻不明、将来の別時点は除外する。同一モデルの履歴違いを独立モデルとして水増ししない。

候補は元のTop8。異なるモデルID2系統以上が支持する候補を、支持モデル数、同一モデル・版の履歴あり／なし両方の支持数、組合せの数値順で選ぶ。上位2候補に100円ずつ、該当1候補なら200円を配分する。この順序は実装上の参考ルールで、予想順位・結果・払戻・オッズを選定に使わない。該当候補なしなら追加200円を未配分にし、800円だけを試算する。各レースの内訳・支持系統数・履歴安定数・同点処理と未配分理由を表示する。

日予算は変更可能な既存設定を使い、締切順、払戻再投資なし、日ごとにリセット。1,000円方式では1レースの上限1,000円を日予算から先に確保するため、1万円なら最大10レース。未配分分は未使用予算へ残し、後続レースへ配り直さない。

払戻・返還・中止は各券の100円単位の金額で計算する。不明な払戻はそのレースの実配分額を保留する。原本Top8、正式成績ゲート、実購入台帳、worker、原本用鍵は変更しない。穴への自動配分は、締切前の判定根拠が保存されていないため今回の試算へ混ぜない。

公開先は既存GitHub Pages、既存秘密リンクを維持。私有原本の一致、架空データの加重払戻・返還・日予算、結果に依存しない配分、順位1への固定配分がないこと、モバイル／PCと実公開URLを検証する。
