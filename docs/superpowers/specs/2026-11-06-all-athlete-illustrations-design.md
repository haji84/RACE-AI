# 全選手の公式プロフィール由来イラスト

オーナーは公開した6名を実際に確認し「今のでいいよ！選手全員分作成して」と指示した。承認済みの自然なイラスト調・本人の公式写真の顔立ちと髪型・ヘルメットなし・背景透過を保ち、既存のボート選手台帳1,643名と公式の現行検索一覧1,657名を照合し、追加26名を含む1,669名全員を対象にする。既存6名の画像は再生成しない。

公式期別台帳2026-2の固定SHAを照合して登録番号と名前だけを抽出する。公式プロフィールで写真と氏名を再照合し、写真を確認できない人物を他人の絵で埋めない。403/429等では取得を停止し、既存成果と再開位置を保持する。

未作成分を順番の固定された5×5または6×6の画像シートとして生成し、各登録番号にシートとセル番号を結びつける。顔の描画には画像生成ツールを使う。元写真や他人の顔をサイト画像に流用しない。参考用一覧はローカルのHTMLで表示してスクリーンショットを用意する。生成したシートはCSSで各セルを表示し、顔をコードで描いたり別人に置換しない。

作成・参照元・セル対応を再開可能な台帳へ記録する。公開レジストリは作成済みだけを返し、対象数と未作成数を正直に表示する。全員分できたという完了表示は全対象の作成・照合・配信後に限る。

GitHub Pages上の既存サイトを更新し、予想暗号文と本人用リンクを保持する。新しい有料サービス、Cloudflare/Vercel、APIキー、アクセス変更、モデル実行は追加しない。大きい画像は必要なシートだけ読み込み、オフライン書出しにも対象レースで必要な画像だけを含める。
