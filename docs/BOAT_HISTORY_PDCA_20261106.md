## 実行方法

CIと同じ固定PR64パーサーを`pr64-reference/`へ用意する。実データの出力先はGit管理外かつ0700の私的ディレクトリとし、既存ファイル・欠落DBを勝手に初期化しない。

```sh
python scripts/boat_history_collect.py --start 2026-08-07 --end 2026-11-04 --private-dir /private/history
python scripts/boat_history_compare.py prepare --p0-zip /private/p0-original.zip --receipt /private/p0-receipt.json --event-day 2026-11-06 --history-db /private/history/history.sqlite --private-dir /private/comparison-20261106
python scripts/boat_history_compare.py score --pair /private/comparison-20261106/20261106-17-01-P0.json --observations /private/official-result-observations.json --private-dir /private/scored
```

収集は既存保存原本をSHAで検証して再利用する。403/429/一時障害時は源流待機を保存し、別URLで回避しない。未取得日・解析不明は明示し、CLIは部分成功を正常完了の終了コードにしない。訂正版を`HistoryStore.ingest_day`へ投入すると版を追加し、当時見えていた最新版で照会する。

`HistoryStore.racer_profile(racer_id, as_of)` / `motor_profile(venue, motor_no, as_of)`で実績を照会できる。現在コースが未確認なら、履歴のコースを現在のコースと仮定しない。

## 完了と未完了の区別

実装・収集・未来比較原本の準備はできた。**未来結果による改善実証はまだない。** 同一結果・固定額で両版を採点し、未予想・例外・配当帯・日/場の偏りを含めて判断する。単日の好成績、入力追加、テスト成功を理由に本番切替しない。

ローカル保存時刻と自己ハッシュだけでは、独立した事前時刻の証明にならない。公開監査には買い目を含まないSHA一覧だけを使用し、外部の実行時刻・取得証拠と照合する。既存の正式な外部receipt契約へ接続するまでは、pair内の独立証明フラグはfalseのまま。

**常時運転への適用・期限なし私有保全は別ゲート。** ownerが別途設定する暗号鍵なしで、原本や平文SQLiteを公開リポジトリ/Actionsへ渡さない。現行workerを再起動・停止せず、現行の朝版/直前版を置き換えていない。BOATERS固有項目、実進入不明時の展開効果、モーター交換周期、全4競技の履歴完備は完了としない。
