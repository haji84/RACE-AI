# 全国競輪・毎日全レース動画保存→解析→研究学習→未来予測比較 v1

## 依頼と運用方針
毎日の開催場数・開催レース数を事前に固定せず、WINTICKETに実際に表示された当日racecard/resultsの通常公開ページから、開催一覧と各レースの参照URLを取得する。全周回の動画を優先するが、なければ通常の過去レース映像（仕掛け/ゴールの一部を含む短い映像）も研究教材の候補にする。システムは、映像の『候補』『実際に再生・録画完了』『暗号化成功』『所有者Library独立読戻し成功』『フレーム解析』『行動ラベル確定』『学習候補作成』『本当の予想精度改善』を別の状態に分ける。

## 毎日の構成
1. `race_ai/keirin_daily_public_catalog.py`, `scripts/keirin_daily_public_discovery.py`: その日の日本時間日付と普通の一覧リンクを突合し、実開催場・レース・大会初日からの日数を検証して当日manifestとSHAを固定。翌日は完全に新しいmanifestを作る。未公表・開催中・中止レースは完了動画と仮定しない。
2. `race_ai/keirin_daily_clip_batch.py`, `scripts/keirin_daily_dynamic_clip_collector.py`: 結果ページにリンクが表示された当日レースのみ対象。非公開LibraryへのSHA読戻しを確認できたrace_idは再録画しない。最大24件/回、ブラウザの通常『映像を観る』を使用し、再生が自然終了し技術WebMが十分な長さを持つ場合のみ所有者公開鍵でAES-256-GCM暗号化。認証回避・動画URLの直接抽出はしない。失敗レースは必ず失敗と記録し次回retry対象に残す。
3. `.github/workflows/keirin-daily-all-races-video.yml`: Draft PR #102で本物の当日リストから実録画する検証ワークフロー。GitHub一時暗号アーティファクトは2日しか保持しないため、専用自動タスクが `/RACE-AI/KeirinVideo/{YYYY-MM-DD}/` に移管・独立SHA読戻しをする。`docs/evidence/keirin-daily-private-retention-receipts.json` を書き換え、次回の重複録画を回避。
4. `race_ai/keirin_daily_video_research.py`, `scripts/keirin_daily_private_owner_research.py`: 非公開鍵でAES復号、元SHA検証。実映像の2秒間隔で196次元HSV+輪郭等を抽出し、動き・画面転換の候補時刻を私有のレビューキューへ保存。TRAINの実レースだけで自己教師なしKMeans場面特徴モデルを作成、未見HOLDOUTのモデル距離を評価。**これは画面表現の実学習であり、選手の捲り/差し分類や3連単の改善を証明するものではない。**
5. 独立に確認できる選手番号・行動・複数フレーム・映像ハッシュ・結果時刻がそろった行動のみ、後のレースに対する戦術履歴へ採用。短編に映っていない行動はUNKNOWNで、ゼロ/失敗と学習しない。映像の重複リプレイも同じ行動として二重計上しない。
6. 本番予想改善ゲートは既存PR71の締切前原本A、同時刻に固定した映像B、全210/504通りの完全確率、後から独立確認した結果が揃うこと。Top8・対数損失・Brier・万車券捕捉率・仮想収支/回収率でA/B評価。単なる場面認識・自己教師モデルの『改善』では本番重みを自動変更しない。
