# 競輪：相互駆け引き・条件分岐型6局面予想 仕様案（2026-11-17）

## 0. 目的・位置づけ
ユーザー要件：選手ごとの先行・番手・3番手・単騎の適性だけでなく、誰がいつカマシ／捲りを仕掛け、相手が突っ張る／合わせる／譲る／切り替えるか、競り合いの消耗・ライン分断・第3ラインの漁夫の利まで予測し、最後の着順の確率順位を改善する。

この文書は**実装前の詳細設計**。正式な予想・学習・本番合格の報告ではない。GitHub mainは変更しない。既存RACE-AI競輪 PR #71（4モデル）、#102（映像）、#103（買い目研究）、#291（6局面保存・採点）を再利用し、別の権威モデルやワークフローを新設しない。AGENTS.mdを守る。Codexへの引継ぎは既存 docs/KEIRIN_CODEX_HANDOFF_REAL_ONE_RACE_20261116.md。

## 1. 基本原則：選手個別スコアではなく「相手依存の行動と状態遷移」
- 単に「先行A、捲りB、番手C」と配置するだけでなく、**Aがこの位置・相手・残り距離でどの行動を選ぶか**、**Bがその行動を認識してどの行動を選ぶか**、**結果どの位置・勢い・残余余力になるか**を連続予測する。
- 六局面（初周、打鐘、最終H、最終B、4角、ゴール）は出力チェックポイント。局面間に「前受け・抑え・カマシ・突っ張り・叩き・捲り・合わせ・切り替え・追走離れ・中団確保・番手捲り・差し」を伴う複数イベントを許容。ゴールだけを逆算して動きを後付けしない。
- **カマシ（他選手がペースアップする前に早めに叩いて主導権を取る）**、**捲り（終盤後方から前団を追い越す）**、**突っ張り（内の先頭側が出させず先行する）**を混同しない。カマシ後の捲り移行や失敗・途中変更は連続イベントで表現する。参考：KEIRIN.JP公式用語集 https://keirin.jp/pc/static/beginner/keirin-glossary/sa-so.html および https://keirin.jp/pc/static/beginner/keirin-glossary/ka-ko.html
- 行動は選手の固定「性格」ではない。当日の並び、脚質、相手、位置、レースの流れ、疲労の代理指標で条件付きに変わる。

## 2. レース前に用いる入力（すべて取得・公開時点を保持）
A. 全出走選手と当日ライン: 車番、選手ID、脚質、級班、競走得点、直近成績、逃げ/捲り/差し/マーク、H/B、ギヤ、選手コメント、初日/前日内容、出走人数、欠場・補充、正式変更情報。
B. 各選手の過去レース行動: 前受け率、先頭/番手/3番手/4番手以降/単騎の実際の走行率、各位置からの仕掛け頻度、番手追走成功・離れ・切り替え・差し、前受け突っ張り試行率/成功率、カマシ試行率/出切り率、抑え/早仕掛け/遅仕掛け率、捲り試行率/成功率、競りの有無、主導権争い時の末着悪化、前受け・後方・中団それぞれからのゴール分布。
C. 相互作用: どの脚質と対戦した際に早仕掛けを選びやすいか、前受け相手の突っ張り傾向、同じ組み合わせの過去連係（標本不足ならUNKNOWN/縮約）、相手先行力、番手追走力、後方の追上げ力、3番手の伸び。選手間の親交や心理を根拠なく推定しない。
D. バンク・当日状態: 周長、みなし直線、カント（取得できる場合）、内外進路、当日時点の風/雨/気温/路面、公式締切の変更と取得時点。バンク内実測が無ければ周辺推定値を明確に区別。
E. 品質: source_id、source_url、observed_at、available_at、SHA、UNKNOWN、データ欠損率・観測走数を保持。「B回数」と映像からの実際の番手割合を同一とみなさない。直近レースだけで性格を断定しない。

## 4. 時間進行型・条件分岐型推論
ステップ1（初周）：ライン、想定先頭、番手、3番手、各ラインの前後、選手の疲労代理初期状態を仮説化。観測不能な正確な車番順はUNKNOWN。
ステップ2（赤板〜打鐘）：どのラインが抑える/前受けを維持するか、後方ラインが動くか、誰が仕掛けを先行するかを条件付き確率で列挙。
ステップ3（打鐘〜最終H）：カマシAを仕掛けた場合、先頭Bが突っ張る/出させる/合わせる、Bの番手が守る/離れる、Aの番手が追走/離れる、第三ラインCが温存/先捲り、という**多選手の反応**を分岐。
ステップ4（最終H〜B）：出切った/出切れない/並走継続で位置関係と消耗の代理指標を更新。もがき合いの影響が先頭2人だけでなく番手・3番手・第3ラインにも伝播。仕掛け位置、残距離、速度差の確からしさを更新。
ステップ5（最終B〜4角）：先行持続、番手捲り、別線捲り、追走離れ、切り替え、内外の進路選択、誰が前に出るかを分岐。
ステップ6（4角〜ゴール）：上がりタイム/直線長/位置・勢い・進路・前にいる相手の抵抗から各選手の着順確率分布を算出。脚を使い切った先行選手の失速、番手差し、3番手浮上、差し返し、別線混入を評価。**各シナリオの条件付きゴール分布**を加重平均して3連単候補を生成。
正式な落車・失格・同着・返還は別の結果処理契約で扱い、推測を事実にしない。

### 分岐の例（架空、2026-11-16名古屋9Rの実走認定ではない）
初期ラインが「③-⑥／①-②-⑦／④-⑤」の場合:
- S1: ①がカマシ、③が突っ張らず①が出切る → ②と⑦の追走をそれぞれ判定 → ③⑥が巻返すか判定 → 4角とゴールへ。
- S2: ①がカマシ、③が突っ張り①③が長時間並走 → 両先頭の消耗代理上昇 → ②と⑦が追走継続か進路変更、④が漁夫の利の捲りを仕掛けるか → ゴールへ。
- S3: ①がカマシに失敗・①後退 → ②が①に付いたまま後退する場合と、②⑦が切替／前進する場合を分離 → ③の押切・⑥の番手差し・④の捲りが競合。
- S4: ①が様子見、③が先行、④が早仕掛け → ①の捲りと②⑦追走の可否を評価。
- S5: 仕掛けが遅れ別線が先に先頭へ → 初期の「本命が主導権」と違う世界線。名目上の先頭選手を自動で1着固定しない。
各Sの確率は**実データで学習・校正するまでUNKNOWN**。百分率を説明の都合で捏造しない。

## 5. 確率モデルと順位
- P(先手行動 | 直前状態・選手・相手・残距離)、P(相手の反応 | 行動・相手・当日条件)、P(出切り/追走/分断 | 双方の特徴・位置)、P(着順 | 最終B/4角の状態)を**異なる推定対象**として扱う。
- 同じ状況の少数履歴を過信せず、選手個別→脚質グループ→級班/開催/バンク等の階層的縮約を使う。サンプル数と信頼区間・欠測率を表示。
- 全組合せ探索が膨大なため、同時に整合した状態遷移を保持するbeam-search/シナリオ・サンプリングを研究。途中で同じ選手が前方と後方に同時存在する、同一選手が2枠に現れる、追走離れが無かったことになる等を禁止。
- レース前の3連単の第1候補は**シナリオごとのゴール着順確率を合算**し、最も高い推定確率の組合せ。第2候補以降も同一の分布でソート。人気/市場オッズは参考比較、特徴量に加える場合はその時点までの値に限定し、公開前・締切後情報を使わない。
- 「最も当たりやすい買い目」と「期待収益が高い買い目」は別ランキング。推定確率が未校正なら高信頼という表示をしない。購入を自動化しない。

## 6. 選手・ライン単位の標本設計と評価軸
- 選手: カマシ試行/成功、突っ張り試行/成功、先頭継続、競り合い回数・持続時間、位置別上昇率、終盤の順位上昇、番手差し、3番手浮上、追走離れ、切替成功。
- ライン: 先頭がカマシ成功でも番手が離れる、先頭が失速後に番手と3番手が残る、先頭と番手がともに失速、第三ラインの上位独占、ライン内外で2・3着が入替わる等。
- 相手条件: 突っ張りが多い先行相手か、先行1車に近いか、相手のB/ダッシュ、前受けか後方か、バンク直線長/気象/級班/日目。
- 推定には必ず分母（適用局面数・試行数）、強い相手を含むか、欠測、データ範囲、出典、古い映像混入を保持。差を意味のある確率と断定しない。

- 車番検出→継続ID追跡→ライン位置（2番手など）・隊列→各イベントの開始/終了・対象→各局面の位置/追い越し→公式結果の突合。画像の色一致だけで車番を認証しない。表示カメラのパン/ズーム・視界外はUNKNOWN。
- 最低限「どのフレームで」「何番が」「誰に対し」「どんな行動を」「どの位置から」「どの位置へ」「成功/失敗/未確定か」を証拠付きで保持。内外進路/相対速度は撮影角度とID追跡の品質が足りなければ未測定。

G5 本番導入: 標本が十分で再現した改善を説明できる場合のみ本人承認後に昇格。事後結果を見て都合の良いシナリオだけを残す行為を禁止。
