# 武雄2R A/B不一致の実原因分類と追跡保留ゲート

基準日：2026年11月15日（JST）
研究の目的：新たな人手の独立レビューを必須にせず、既存46フレームと凍結済みA/B候補を使い、未認識・不一致の**原因を切り分ける**。研究用不一致の集計を正式な選手識別率・適合率・再現率に混同しない。

## 1. 実レースで再現した根拠

- 武雄2R、2026-11-09、レースID `202611098402`。元録画SHA256 `4e389a46c223b7cb2eaa7c5c5bdc34ade229deedea8a3c795c8be987b57aa810`。
- Aは前回保存した変更禁止の色領域原本。予測manifest SHA `b207ec30d3fb368b9d9e64b494aa8e9e3657aac388023226c798da8ba8a98bae`。
- Bは同一BGR画素の厳しめHSV閾値。46フレームでA=222色候補、B=114色候補。1対1の40px距離以内の位置一致99組、位置と色の一致96組。3組は位置が一致しても色が違う。
- したがって「**Aの123候補に位置一致するB候補がいない**」と「**Aの126候補に位置と色の両方が一致するB候補がいない**」は異なる。Bも同様に、位置で未一致15件、位置と色で未一致18件。過去の126/18記載は色不一致3組を含む値で、123/15と矛盾しない。
- 検証に用いたA/B HTMLは同一元フレームを内包した未記入の2セットであり、2人の独立レビューを行った証拠ではない。

## 2. 新しい失敗原因の自動切分け（実フレーム）

前回は「Aだけの候補」の合計しかなかったが、今は**元フレームSHA照合後に凍結済みA領域内部のB側HSV画素数**を検査し、次のように研究上の候補原因を分類する。

| A候補の不一致状態 | 件数 | 何が分かるか |
| --- | ---: | --- |
| 厳しいHSV条件を満たす画素が0 | 49 | Bではその領域の同色根拠が消えている |
| 厳しいHSV画素が1～94 | 65 | Bの連結成分を成立させる最小面積95画素に満たない |
| 厳しいHSV画素が95以上でも空間一致なし | 9 | モルフォロジー、分割・結合、中心位置のズレなどを次に調べる必要がある |
| **計** | **123** | すべて真の誤検出とは断定しない |

色別のA空間未一致：3番色29、4番色11、5番色17、6番色38、7番色28。領域の形状が横に長い候補8件、1024×584座標系で上側240画素未満から始まる候補29件を、重複ありの**背景リスク**として別計上した。

実映像の単独目視検査では、14秒の路面・自転車付近、32秒の背景看板、82秒の路面に、実際の選手以外へ付いた色の枠を確認した。画面によって乗員も写っており、**B側のHSVをさらに厳しくするだけでは乗員の服色を欠落させる危険**がある。この目視は一者の研究上の観察であり、全46フレームの独立正解アノテーションではない。

検証コード：`race_ai/keirin_color_failure_triage.py` と `scripts/keirin_private_color_failure_triage.py`、合成テスト `tests/test_keirin_color_failure_triage.py` 6件。実映像の全46SHA、222/114/99/96の一致を固定条件として検証し、勝手な予想変更や結果書換えを拒否。

## 3. 前後フレームの「動き」は独立した別ゲート

近傍に同色の塊が見えても、同一選手が続いているとは言えない。背景が動くカメラ、遠近やズーム、画面切替えの問題があるため、別途、元動画から固定した2秒間隔46フレームの**隣接45組**でOpenCVのSparse Lucas–Kanade特徴点追跡と部分アフィンRANSACを実行した。

背景の幾何学的変換が研究上の品質条件（追跡された特徴点中20点以上が整合、インライア率50%以上等）を満たすのは**16/45組**。それ以外の**29/45組はHOLD**。内訳はRANSAC整合不足27組、元の特徴点不足1組、追跡特徴点不足1組。

14、32、82秒など不一致が多い付近は、この背景変換の検証条件を満たさなかった。低整合でもカメラカットだと断定せず、理由として特徴不足・物体の動き・撮影変化を候補に残す。品質を満たす16組も選手追跡成功ではなく、**背景の動きの幾何学候補**にすぎない。

検証コード：`race_ai/keirin_camera_motion_quality.py`、`scripts/keirin_private_camera_motion_audit.py`、合成テスト `tests/test_keirin_camera_motion_quality.py` 6件。入力の全元フレームSHAを確認した別プロセスで実行し、画素と非公開座標を出力しない。

## 4. 今回の改善点と次の未完了

**今回できた改善**
- A/B不一致を単なる総数ではなく、**色閾値で消失、成分面積不足、色画素は残るが位置一致なし**に切り分ける。
- 看板や路面に付く色領域のリスクを形状・領域で優先記録し、難しいフレーム14、32、82、6、34秒から研究を進められる。
- 動きの推定が不十分な29組を自動HOLDして、同色blobの追跡を「同じ選手」へ水増ししない。
- どの失敗群も、既存の6局面スコア・予想モデル・学習重みには接続しない。前回の凍結A原本は変えない。

**次の改善対象**
- 画像の人物・車体の形状検出と、服色/数字OCRの**異なる情報源の結合**。看板・路面・シャドウと選手の区別をする。外部モデル導入・新課金・本人承認なしの重要変更は行わない。
- 9件の色画素十分なのに位置不一致の原因を、連結成分の分割/結合、中心移動、同色の遮蔽と区別する。カメラ切替え/追跡の境界を検査する。
- 同一映像のA/B一致は教師正解ではないため、人を探すことなく**研究上の診断と学習から隔離したテスト**を継続する。一方、正式精度・選手本人識別・ライン・6局面・PDCA採用の合格ゲートは保持。
