## 1. 最上位の成果目標
ボートレース・競輪・オートレース・競馬（中央/地方）の**全開催・全レースを日次台帳化**し、3連単発売・結果評価可能な全対象レースについて、出走前に利用可能だった合法な事実情報から独自の展開・着順評価を行う。**オッズ・人気・市場由来情報を一切使わず**全有効3連単組合せを採点して、**最大8点**を投票締切前に永続保存・改変不能化する。

そのうえで結果照合→誤差診断→仮説→モデル改良→未来レースで新旧モデル並走比較→採否→再学習を継続し、**全対象レース基準の実測3連単Hit@8を98%以上に近づけ、達成・再現することが最上位の挑戦目標**。単に予想できたこと、PDCA画面ができたこと、合成試験が通ったことを最終GOALとしない。

**98%は現時点で未達・実現可能性未実証の目標**。保証や実績表示は禁止。結果後に予想を変える、評価対象を都合よく削る、券点数を増やす、研究期間の結果を未来検証と偽る行為は禁止。

## 2. 既存53章との矛盾の解消
- **8点:** AI公式予想・Hit@8評価の上限は「最大8点」。既存UIの16/24/32点は、必要なら**ユーザー手動購入検討・仮想投票機能**として保持できるが、AI公式候補の数・順序・精度評価から完全に分離。既存機能の無断削除は禁止。
- **競技:** ボート先行は実装優先順位としてのみ維持。完成対象は4競技すべて。共通の6艇固定ロジックを競輪・オート・競馬へ転用せず、N人(頭/車/艇)でN×(N−1)×(N−2)の全有効券を列挙。
- **市場遮断:** オッズ・人気・確定配当・市場由来確率は特徴作成・特徴選択・学習・モデル選定・推論・説明・上位8点選抜に入れない。凍結後の独立した購入価値評価は、凍結済み予想を変更しない条件でのみ許可。PR #64の `race_ai/model_training.py` にある `market_implied_win_probability` は**利用有無を確認して対処する監査対象**であり、利用済みと憶測しない。
- **出走前:** 締切時刻は発走時刻の代用にしない。出典・公開時刻・観測時刻・取得時刻・学習締切・保存完了時刻・外部時刻証拠と、改訂前後の履歴を区別する。
- **権利:** 公開事実の独自解析と、ソースへの自動アクセス・原データ保存・学習・配信・動画使用は分けて扱う。許諾不明ならその用途/ソースだけ停止し、別の安全な開発を継続。禁止された無断大量取得/認証回避/無断再配信・新規課金・自動投票は禁止。

## 3. 台帳・予想・監査の契約
`race_id=(sport, organizer, venue, meeting_id, event_date_jst, race_no)` を基本に、同一レース変更・中止・延期・取消・出走構成改訂を追記イベントとして保存。全開催を対象にDiscoveryの欠測と「開催なし」を区別。開催台帳は**3連単非発売・取得不可・予想不可・締切超過**を削除しない。

競技別FeatureAdapterは個別の過去実績、能力、環境、展開、直前状態をas-ofで評価。ボート: ST/進入/モーター/展示/風波・決まり手。競輪: ライン/先行・捲り・差し/番手/バンク。オート: ハンデ/試走/スタート/湿走路。競馬: 距離/馬場/枠・馬番/ペース/近走/騎手/馬体重等。利用条件が未確認の特徴は欠測を記録して不使用。

`prediction_freeze` は`race_id, model_version, feature_allowlist_sha, trained_until, source_as_of, generated_at, frozen_at, persisted_at, sales_cutoff_at, input_hash, full_candidate_hash, ordered_top8, prediction_hash, evidence_ref`などを持つ。信頼できる時刻検証により**persisted_at < sales_cutoff_at**を満たした予想だけ事前公式記録。結果後のUPDATE/DELETEは不可。予想を出せない場合は理由付きの`NO_FORECAST`とし、的中に加算しない。

公式結果と3連単発売/成立条件、同着・失格・返還・中止の取扱いは公式ルール・改訂時刻付きで別保存。順位が並んでいるだけで払戻成立を推定しない。

## 4. 主指標と補助指標
**Hit@8_all** = 「締切前に固定した有効な最大8点予想が公式に的中したレース数」÷「全開催のうち**3連単が発売され、公式結果で券種の評価可能なレース数**」。

分母に**未予想・見送り・欠測・締切遅延**を含める。3連単非発売・正式中止・結果不成立・未確定などは台帳に残し、独立した件数と根拠を表示。これを都合よく主母数から消す操作は禁止。結果評価自体が未確定なら値は未検証とする。

併記: 条件付きHit@8(事前凍結済のうち)、1位候補のHit、競技別/場別/日別/モデル版別、全レース捕捉率、事前凍結率、欠測・見送り数、多クラスBrier/Log Loss/校正、仮想と実購入を分けた払戻ベース回収率。正しく校正されていないモデルのスコアを的中確率として表示しない。

98%到達は**未来の未使用レースで事前登録された母数・期間・必要サンプル・信頼区間・独立証拠**によって判定。300件は初期検証の入口であり安定精度を証明しない。合算値が98%でも、競技ごとの実績を隠して全競技達成と称しない。

## 5. 改善エンジンのDone条件
`全開催Discovery → SourcePermission → PreRaceSnapshot → 全3連単評価 → 最大8点freeze → OfficialResultRevision → Scoring → CauseClassification(fact/hypothesis/unknown) → CandidateModel → WalkForwardValidation → FutureParallelComparison → Promote/Reject/Rollback`。

候補モデルは旧モデルと**同一の未来レース、同一時刻条件、最大8点、同一母数**で並走して差分と信頼区間を比較。研究期間に勝つだけでは昇格禁止。データ不足、漏えい、性能悪化では旧版へ巻き戻し、予想履歴は残す。

段階完了は①既存PR/Source権利棚卸②4競技合成E2E③合法な各競技実データの事前freeze→実結果照合④日次全レース発見/復旧とiPhone実機⑤前向き精度改善実証を**別々の成果**として確認。98%の未実証を完成扱いしない。
