analysis_window=claim_copy). Old three-argument callbacks deny V2. The fixed
claim binds request/raw/snapshot/policy/source-verdict SHA, original three

The independent callback must establish the original policy/capability through
cutoff. Mutable policy.grants are not signed-horizon authentication. Preserve
the admitted claim unchanged; actual fresh execution start after READY must be
at or after admitted start and before cutoff. Persist claim+True only in V2.
All original source/private-path/cutoff/roster checks still apply. Callback
admission is not code-authenticated rights, producer execution or clock proof.

Only fresh V2 uses a fixed isolated producer. Fixed public bundle and manifest,
63 entries, each <=64KiB and total <=512KiB; exactly 29 race_ai modules. Verify
and retain the actual bytes, install a closed in-memory importer, then READY
before receiving any private input. Unknown imports never fall back to cwd or
site packages. Parent never changes sys.path/package paths/module identities.
Minimal explicit child environment, isolated/no-site/no-bytecode/unbuffered
Python, close unrelated handles, no secret/policy key or private path in argv.

Protocol is uint32 big-endian length + frame: READY/result JSON <=4KiB,
canonical control <=2MiB, original source/typed wire each <=4MiB. Reject duplicate
keys/nonfinite/depth/type/count/length/trailing errors before use. Control carries
exact request/SHA/profile/pin/manifest, actual start, original policy SHA and
complete original decisions. Child calls actual pinned source.deliver and codec,
using a clearly labelled recorded-policy adapter; no fabricated signed policy.
Parent independently decodes, validates all hashes/plans and full universe.

One 30-second total monotonic spawn-to-reap deadline, further cutoff capped;
never reset after READY. Fresh UTC/policy/window check after READY immediately
before first private byte, after computation and immediately precommit. Proactive
kill/reap/pipe-thread cleanup on timeout, overflow, truncation or death. Bounded
concurrent I/O, stderr DEVNULL, generic private exceptions. No retries or late
adoption. Missing bundle denies before DB creation; unexpected startup failure
after BEGIN may leave an empty private DB, never a committed preparation row.
No OS network sandbox, hard native RAM quota, independent real clock, global
exactly-once coordinator or protected external retention is claimed.
