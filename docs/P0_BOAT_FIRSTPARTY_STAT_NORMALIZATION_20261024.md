# P0 official-first-party numeric stats -> partial feature candidates (2026-10-24)

Input: six-racer **first-party venue** factual observations, restricted to public numbers viewed from `https://boatrace-biwako.jp/sp/`. **No HTML/CSV copied to GitHub**, no public athlete profile bulk dataset or odds, and no automatic provider HTTP. Test fixtures in `tests/test_boat_firstparty_stat_normalizer.py` are imaginary.

`race_ai/boat_firstparty_stat_normalizer.py` explicitly maps the provider's 0-10 **national win score** to a proposed `ability` proxy (score/10), 0-10 **local win score** to proposed `course_compatibility` proxy (score/10), and motor **2-ren-tai percentage** to a proposed `motor_form` proxy (percentage/100). These are **engineering proposals, not learned/calibrated weights** and are not claims of calibrated win probabilities. They must be prospectively evaluated before production.

It matches all six racing lanes to independently observed official **registration numbers** (reference `docs/evidence/2026-10-24-biwako-1r-official-facts.json`), rejects spoofed sources, mismatched/missing participants, NaN, invalid units, odds/results and fabricated provider-publication timestamps. It emits 18 **numeric candidate values** for the six runners, each retaining exact input field, unit and formula. Crucially, official source publication times and sample sizes are **unknown** from the small public summary; the adapter stores `published_at=null`, `sample_n=null` and `admitted_as_pre_cutoff_model_feature=false`. It does not create PR71's full snapshot or fraudulently fill required 75 observations.

Why this matters: PR71 `comprehensive_four_sport_models.validate` requires per-observation `published_at <= captured_at <= as_of`, `sample_n>=1`, independently admitted source rights and a complete 75-observation roster/environment. A visible numeric figure alone cannot fill those requirements without lawful as-of provenance and justified transforms. Source terms, machine access and limited public-output rules are independently reviewed; a human-read public fact is not itself automatic scraping approval. Keep model code in PR71 unchanged.
