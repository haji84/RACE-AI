1. 出走表、選手番号、ハンデ、各レースの発売締切、過去成績、当日の試走タイム、欠場・変更、確定着順、返還・払戻、結果訂正を提供する正規の機械可読データ（API、ファイル配信等）の有無
2. 個人の非公開研究における定期的なデータ受信、端末・非公開クラウドでの保存、AI予想・モデル学習・結果照合の可否
3. 将来、予測結果や分析指標のみを第三者に表示する場合、また有料サービス化する場合の追加契約や許可の要否
4. データの提供間隔・更新遅延・試走公開通知（push等）・確定/訂正の識別方法・アクセス頻度上限・保存期間・費用
5. 契約・利用申請の担当窓口、必要な資料、利用規約や書面での許諾手続き

利用範囲を明確にし、許可をいただいた条件内でのみ実装する方針です。データの権利関係上、ご提供が難しい場合も、その旨または適切な問い合わせ先をご教示いただけますと幸いです。
