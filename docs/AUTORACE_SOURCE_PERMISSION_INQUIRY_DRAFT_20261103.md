## 最初の窓口への確認手順

1. **JKA 03-4226-3519** へ連絡し「オートレース振興業務部、または競走情報の機械提供・二次利用の許諾担当窓口を紹介してほしい」と依頼。お客様相談窓口自体には許諾権限があると決めつけない。
2. 必要なら**協会の法人連絡先 03-6421-7458**にも照会し、AUTORACE.JP運営・データ供給の契約責任者を確認する。
3. 正式な提出先と提出方法が確認できるまで、投票者向けの問い合わせフォーム、取材申込フォーム、無関係な公募専用メールに申請書を送らない。
4. 提出内容、提出日、先方の回答原文、許諾対象のデータ/用途/期間/レート/価格/認証手段を**非公開で記録**する。文書を公開GitHubに保存する場合は個人情報・契約情報・秘密を除外する。
5. 許可が確認できない用途の自動アクセス、保存、学習、派生表示は本番で行わない。既存PR #71の合成E2Eを継続し、main統合や本番開通は別承認。

件名：オートレース競走データの正規提供と自動取得・研究利用許諾について

ご担当者様

オートレースの全開催・全レースについて、試走前と試走後の予想を別々に記録し、確定結果との照合・精度検証を行う個人向け研究用ソフトウェア「RACE-AI」を開発しております。

1. 出走表、選手ID、近走・ハンデ、公式の予定締切、当日の試走タイムと発表時刻、出走変更・欠車、確定着順・払戻・結果訂正を機械可読形式で受け取る方法（API、認証付きフィード、CSV等）

4. データ配信の更新間隔・公開時刻・通知方式、許容アクセス頻度、保存期間、再配布制限、契約・費用・請求条件
5. 利用申請に必要な書類、責任者、正式な許諾窓口および契約条件の書面

正規のルールを遵守して運用するため、最初は非公開の試験用途から始めることを希望しております。
貴部署が所管外の場合は、適切な担当窓口をご教示いただけましたら幸いです。
