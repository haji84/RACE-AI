# 既存2モデルの展示後接続と研究原本の区分付き統合

ユーザー承認済みの2点のみを既存Draft PR #71へ実装する。新モデル・新タスク・新PR・main統合・課金・投票は行わない。

## 展示後接続
既存の観測相性とST重視相性を、A/B/C-liteと同じレースの実観測から呼び出す。全国勝率・モーター2連率・展示タイム・数値STを既存の変換と重みのまま使用。過去着順/STの未取得値を推測で補完しない。F/L/PENDINGは欠測状態を保つ。

既存モデルのURL契約はquery-freeなので、source_urlは出典の正規パスを表す。実際の取得URLはhttp_provenance.request_urlに完全保存し、日付・場・R・取得時刻・原本文字列SHAを別検証する。出典URLからレース識別を消した扱いにはしない。

同じnational.jsonに新しいoptional observed_pairwise_p1_bundlesを保存する。以前のA/B/C-lite・朝版の原本は書き換えない。read_p1が外部保存時刻、SHA、モデル別キー、選手ID、全120候補を検証して既存結果照合へ接続する。今回の新規作成は既存の選定処理が選ぶ未保存・未締切レースのみ。過去の8レース等へ後付けしない。古い3モデルの原本と新しい5モデルの原本を両方読める。

## オートの別保管原本
監査した山陽1R・2Rの非公開研究原本の予想SHAと入力SHAを確認し、既存式で8点＋追加4点を再現した。GitHubには原本の買い目・個人保管URLを転載せず、許可フィールドのみのautorace-research-import.jsonを保存する。

status.jsonとmodel_coverage.jsonにexternal_researchを別枠で接続する。研究件数2件をボートのforecast_count、scored_forecasts、的中率、回収率へ合算しない。正式な締切前保存証明のない原本は昇格させない。二重取り込みは加算せず、異なる原本の同一キー競合は拒否する。研究manifestの問題は研究欄に記録し、無関係なボート集計まで停止しない。

このmanifestは今回実際に監査した2件が対象で、別チャットが追加した全オート原本まで網羅したとの主張はしない。後続原本は同じSHA・証拠区分検査後に明示追加する。
