# ボート予想A/Bの前向き検証・正式判定手順（2026-11-03）

## 目的
「結果を見て予想を作る」「当たったレースだけ抜き出す」「後から強い重みを選ぶ」ことを防ぎ、現行Aと改善候補Bを**同じ未使用未来レース**で、予想原本保存から公式結果評価まで追跡する。RACE-AIの最終目標である全対象レースのHit@8_all 98%以上は継続する。ただし**未達の研究目標**であり、現時点の能力や保証ではない。

## 事前登録した実験群

- **A**：`boat-display-rating-PL-reference-v1-UNVALIDATED`。全国勝率＋6艇展示タイムの固定PL順位モデル。未訓練／未校正。
- **B**：`boat-course-motor-shadow-v0.1-UNTRAINED`。Aに対し、コースlog固定補正 `(+0.20,+0.10,+0.04,-0.04,-0.12,-0.18)`、6艇平均との差のモーター2連率×`0.003`。この係数は正式学習済みではなく、結果に合わせた最適値でもない。
- A/Bはオッズ、人気、予想屋の出力、確定結果を**予想入力として一切使わない**。両モデルは同じ展示・出走者・元ソースSHA・時刻を共有し、3連単120通りを各々正規化して、最大8点を上から選択する。
- 各予想原本を締切前に外部時刻付きで保存。**GitHub Actionsのrunner時刻だけでは不十分**。artifact APIが示すサーバー`created_at`と実ダウンロードZIP/JSONのSHAを照合し、締切前だった場合のみ正式な前向き比較に採用。結果発表後に過去の原本やBの係数を変更しない。7日間のartifact保持は長期保存の代替にならない。

## 公式結果照合と欠測の扱い

- 本当の結果を報告できるのは**公式で6艇着順・3連単の払戻組番・返還状況が検証できたレース**だけ。中止・返還・非発売・未確定は個別理由付きの別カテゴリで記録。
- 分母は第三者が再確認できる公式の全日／全場台帳から固定する。「AもBも予想できない」対象を分母から隠さず、確定通常レースなら両方Hit@8=0として計上する。両モデルのスコア分布評価は両方が締切前保存済みの**matched cohortのみ**で算出し、全件的中率と混同しない。
- 訂正結果は元結果を上書きせず別revisionとして追加。古い予想バージョン・SHAは不変。結果の公式取得ができない場合は`PENDING`で保持し、的中／不的中を作らない。
- 今回の実前向き保存：宮島2R `41561946057/13197470628`、宮島3R `41564362916/13198428110`。両方ユーザー指定Vercel不使用。後続の4R等は保存時刻を検証してから追加する。

## 指標と正式な比較開始条件（暫定プロトコル）

1. **主指標**：全対象のHit@8_allとHit@1_all（漏れ含む）および同一レースのB−A差。各的中率はWilson 95%区間。2モデルが食い違ったレース数（Aのみ／Bのみ）も記録。
2. **予測分布の品質**：正解組番に付けたLog loss、全120通りの多クラスBrier（平均値、小さい方が良好）。A/Bの同じレース差で評価する。
3. **確率の校正**：8点に割り当てたモデル合計質量を10分位帯に分け、予測値と実測Hit@8頻度を比較。各帯の標本が30件未満なら`low_sample_flag`を立てる。モデルのscoreは未校正で、**推定値を当たる確率として断言しない**。
4. **仮想経済評価**：予想した8点を各100円ずつ仮想購入した場合の回収率。配当欠測時は算出しない。実購入・資金収支とは区別。予測入力にオッズを混ぜない。
5. **不確実性**：A/B同一レースの差について2,000回、固定乱数種のペアbootstrapを算出。同じ会場・同じ日の相関を考慮し、会場日別のblock bootstrap（10ブロック未満は区間なし）も出す。McNemar型の不一致ペア検定は補助資料であり、相関を考えると過信しない。
6. **改善支持を検討してよい最低条件**：保存済みマッチ100レース以上、少なくとも5開催日、10会場日ブロック以上。その上でB−AのHit@8ブロックbootstrap下限が0より大きく、Brier・Log loss差の同上限が0未満、Bのみの的中がAのみを上回る場合に、**「Bを支持する前向き証拠あり（まだ自動昇格不可）」**とする。条件不足／区間が0をまたぐときは未判定。
7. **未解決の限界**：会場日ブロックbootstrapでも同日の共通環境・選手反復・データの偏りによる従属性を十分除けない。100件／5日という初期ゲートは**精度改善を保証する標本設計ではない**。大きな効果の再検証は、新しい期間・会場の保留データでも必要。
