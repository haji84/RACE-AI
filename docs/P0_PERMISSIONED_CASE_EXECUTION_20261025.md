# Permissioned single-case preparation and external witness resolution

## Goal and boundary

Connect actual operator-supplied research input to the existing four model
families, durable original-byte preparation and read-only external fingerprint
receipt resolution. This is separate from SYNTHETIC_ONLY journals. It neither
grants source rights nor promises that a real complete input exists.

Owner directs actual-device and account/cost checks to the final stages. They
do not block this code. Existing paid/security/source/publication/main gates
and held33 remain. No new provider acquisition, public write, deployment,
schedule, private key or inference on an already-closed real race in this slice.

## Existing assets and approaches

Reuse PR71 ebe93f13062cf0461b81b924a5dc0482ada37b56 deliver(persist=True),
typed private codec, model validator and unchanged four families. Reuse PR72
binding, anchor preparation, bound receipt checking and per-model settlement.
Generalizing the fictional eight-race journal would blur its evidence class;
replacing models or external storage is unnecessary. A separate one-case
checkpoint and bounded read-only resolver are the smallest chosen integration.

## Private case

An immutable request binds source ledger/race, raw source SHA, policy SHA,
snapshot SHA, as_of, cutoff and the prospective four-ID/version/source-pin
declaration plus independent evidence references. Default-denied input,
cutoff, model-roster and private-path admission happen before model execution
or target creation. Signed policy authenticates a review record, not the grant.
Use persist=True so analysis, private_storage and private_derived are checked.

Keep original typed wire, exact request/hash, local start/generated/persisted
samples and all four anchor plans atomically in one separately identified,
immutable SQLite checkpoint. Reject foreign files before DDL. Already committed
cases have a read-only replay path. For a new/uncommitted case BEGIN IMMEDIATE
precedes its locked prior lookup and computation; check cutoff again immediately
before commit. Same committed request reloads without inference even after cutoff;
different request fails. A computation killed before commit may run again.
load_case checks the original wire, IDs, hashes, plans and chronology without
renewing authority or running models. Denied inputs return only hash/reason
diagnostics and do not retain unadmitted raw data.

The inherited pinned suite/binding require exactly eight unique picks, although
their input validator accepts three horse/autorace entrants (only six possible
trifectas). This checkpoint denies that unsupported size before inference or
target creation. Maximum-eight support for that size is a separate unresolved
compatibility repair; this slice keeps the original models/pin unchanged.

The target must be outside Git and pass an independently implemented OS access
check covering parent directory, database and sidecars. Windows 0600 alone
is not proof. There is no automatic path approval or permission expansion.

## Read-only witness resolver

resolve_anchor_witness accepts an original prepared anchor, an exact known
submission commit, local persisted_at, expected branch, and explicit trusted
GitHub reader/legacy verifier. Commitless uncertain writes return STOPPED
without HTTP. Never scan a branch, repeat PUT, dispatch, infer a receipt or
reinterpret a404 as write permission. This module has no writer/network default.

At most one fixed-repository runs-list GET (exact head_sha, push, per_page100),
one selected individual-run GET and one exact-commit contents GET. Require a
complete bounded list; select an eligible candidate deterministically. Check
individual run ID/repository/branch/event/head and server-created time before
cutoff. Guard the exact URLs and call counts. Pass the same data through the
existing race-bound adapter and pinned legacy verifier; require original
canonical four-field anchor bytes, not merely value-equivalent JSON.

The result attests only fingerprint presence at an independently reported
GitHub time. It does not attest source rights, full private-payload cloud
retention, producer/model execution, official result, daily coverage or scores.
Resolution can occur after cutoff if the external presence was before it.

separate private transient exhibition analysis. Preserve those exact scopes;
do not call all existing facts unlicensed or ask the same approval again.

partial ST and missing histories/physical conditions; aggregate K counts and

The existing submit_anchor still needs independent public-release approval.

uncertain-write recovery must be independently implemented and tested.
Existing audit_model_settlements consumes original decoded delivery, real
receipt metadata and separate official-result/cutoff/coverage/roster gates;
missing forecasts remain in its denominator. No metric is promoted by this
slice. Real prospective E2E remains pending actual admitted complete input and
external retention/receipt evidence.
