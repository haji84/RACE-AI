# 競輪予想精度向上・信頼度判定 統合開発仕様

2026年11月28日のオーナー指示。対象はRACE-AIの競輪。既存の[詳細開発指示](KEIRIN_DETAILED_DEVELOPMENT_SPEC_20261125.md)、[受入状況](KEIRIN_DEVELOPMENT_ACCEPTANCE_20261125.md)、Draft PR #327と全体GOAL #67に接続する。競輪の提示点数と信頼度は本仕様を適用する。4競技共通の公式Hit@8集計は同じ順位・分母・締切前原本を継続して評価する。

## 1. 最上位目標

全国のすべてのレース・予想で、選手、ライン、映像、バンク、展開、着順、オッズの分析を高度化し、実際の的中率と収益性に結び付ける。特に1点での性能を伸ばし、信頼度の基準を維持して激アツ・高の件数と割合を増やす。

## 2. 信頼度

| 表示 | 提示全買い目の校正後の的中確率 |
| --- | --- |
| 激アツ🔥 | 90%以上 |
| 高 | 80%以上90%未満 |
| 中 | 60%以上80%未満 |
| 低 | 60%未満 |
| 判定保留 | データまたは検証不足 |

予想実績、着順確率、展開の安定性、データ品質、不確実性を調べる。激アツが0件の日も基準を維持する。過去の展開根拠のまとまりを示す指標はその固有の意味で扱う。

## 3. オッズに応じた提示点数

| 予想時点で固定した本命・狙い目の三連単オッズ | 最大点数 |
| --- | ---: |
| 10倍以下 | 2 |
| 10倍超〜20倍以下 | 4 |
| 20倍超〜100倍未満 | 9 |
| 100倍以上 | 12 |

すべての帯で1点提示を可能にし、本命・対抗の確率、展開の安定性、波乱度、候補ごとのオッズ、追加点の的中確率・期待値の増分、総投資に対する払戻、価格変動リスクを評価する。上限の根拠となる本命・狙い目は予想時点で固定する。オッズの公表・取得時刻を保存し、決定時点・締切までに利用できた値を提示と収益性評価に使う。二車単の信頼度は最大2点を評価し、1点の精度も検証する。

## 4. 評価の分離

内部の全着順候補を順位付けし、三連単Hit@1・2・4・9・12、二車単Hit@1・2を同じ点数で比較する。実際の提示全点による的中率、オッズ帯別、点数別の成績を併記する。信頼度の表示には実際の点数を付ける。予想そのものの改善は同じ固定点数・同じオッズ条件で確かめる。

## 5. 対象レース

全競輪場、全車立てと欠車、全グレード・選手クラス・レース種別・時間帯、全ライン・バンク・気象・オッズ帯・点数、A・B・C、三連単・二車単、通常・転がしを対象とする。全体集計と条件別集計を用意し、外れ、見送り、不得意条件、情報不足を記録する。発売・返還・採点不能の扱いを事前に決め、発売・結果が評価できたレースは予想が欠けても全対象分母に残す。

## 6. 選手個人の分析

- 基礎能力は競走得点、最高・平均速度、加速・瞬発・持久・速度維持、減速・失速、ギヤ、長距離先行と短距離スプリント。
- 戦法は先行、捲り、差し、追込、追走、主導権、逃げ切り、番手差し、追走離脱、ブロック・牽制、位置取り、H・B、仕掛け位置と時期、戦法ごとの試行・成否。
- 会場ごとに最終1周、最終ホーム〜バック、最終バック〜4角、4角〜ゴールを記録する。最速・平均・直近・分散、ラップ速度、同一レースのタイム差、役割・戦法・気象別の分布を学習する。上がりなど部分区間と全周を区別し、映像からの推定には誤差と選手識別精度を付ける。周長、みなし直線、傾斜、風、走行距離・位置、ラインの風よけ、役割、周回開始速度、消耗、ペース、対戦相手で補正する。
- 調子は直近着順と内容、短中長期、疲労・休養・連戦、開催日、欠場明け、昇降級、年齢、コメントと走行の一致、過去の好不調との比較から検証する。

## 7. 全国のバンク

周長、みなし直線、カント、曲率、幅員、ホーム・バック、屋内外、周辺風環境、走路状態を出典付きで保全する。会場ごとの先行・捲り・差し、逃げ切り・番手差し・3番手・単騎、ライン決着と崩壊、車立て、波乱・高配当・オッズ帯、時間帯、季節・気象、最終周回と仕掛け成功を評価する。選手の場別、周長・直線・カント別、風、地元と遠征、タイム・加速・失速・戦法の適性を推定し、類似場から補う場合は実測と区別する。

## 8. ラインと選手間相性

先頭の主導権、番手の追走・援護・差し、3番手以降の追走・突っ込み、ライン人数、連携成績、速度・加速の相性、維持・分断・離脱、単騎、ライン同士、地域連携と着順逆転を分析する。得点と実際の連携の両方を扱う。

## 9. 気象と開催条件

風向・風速・突風、区間別の風と走路、気温・湿度・雨、選手別の気象適性を検証する。勝ち上がり、種目、グレード・級班、賞金・競走条件、開催日程、欠車・ライン変更、コメント、対戦履歴を保存時点とともに扱う。条件による差はデータから学習する。

## 10. 六局面

初周、打鐘、最終ホーム、最終バック、最終4角、ゴールで位置、仕掛け、追走、進路と着順を予測する。選手の場別タイムと能力、消耗、ライン、バンク、風を反映し、本命・対抗、ライン崩壊、別線捲り、単騎突入、波乱などの展開をそれぞれ確率で評価する。

## 11. 映像

正規の利用可能な経路で、車番・選手、位置、軌跡、間隔、各区間・最終周回のタイム、速度・加速度、仕掛けと成否、維持・分断、ブロック、進路変更、速度変化、伸び・失速、不利を観測する。カメラ切替、遠近、遮蔽、フレーム精度を誤差に含める。抽出した特徴をモデルに接続し、未学習レースの改善で受け入れる。

## 12. 着順と買い目

着順間の依存を学習し、複数展開の確率から同じ着順分布で三連単・二車単を算出する。買い目は確率、展開整合性、依存、オッズ、波乱、期待値、追加点の寄与で選ぶ。本命が明確な場合は1点・少点数、有力な別展開がある場合は複数点を扱う。

## 13. 信頼度判定専用機能

確率生成と別の機能で、選んだ点の合計確率、集中度、展開安定性、選手・会場評価の信頼性、映像精度、類似レース、モデルの合意、オッズ差、欠損・異常、不確実性、点数・オッズ帯別成績を評価する。学習済み確率は別期間で校正する。認定前に検証期間・最低件数・信頼区間を固定して、未学習レースで実績を確認する。

## 14. オッズと収益性

的中信頼度、期待収益、波乱、価格変動、人気の過不足、モデルと市場の差、点数、投資、払戻、回収、最大連敗・最大資金減少を分けて計測する。固定額と資金配分を変えた仮想検証を分け、的中しても投資額を回収できないケースを数える。転がしは連続的中・資金減少・最終収支を個別に検証する。実投票は対象外。

## 15. 全レースPDCA

的中と外れの双方で、選手・タイム・バンク・ライン・気象、展開、着順、点数・組番、オッズ、信頼度、データ品質、落車・失格や的中要因を、映像・公式記録・原本が裏付ける範囲で分類する。偶発的事象の外れも原則として成績に残す。中止・返還・同着は事前の採点規則で扱う。

## 16. 自動学習と更新

予定取得、選手・ライン・バンク・気象・オッズ取得、映像取得・解析、選手・会場特徴更新、展開、着順・買い目、信頼度・期待値、締切前の暗号化保存、別環境読戻し、公式結果照合、原因分析、候補生成、バックテスト、旧新比較、未学習の未来評価、採用、サイトと集計への反映を継続する。学習・校正・最終評価を日付で分離し、予想時点で得られた入力のみを使用する。特徴、構造、展開と確率算出も改善候補に含める。

## 17. KPI

激アツ90%以上・高80%以上・中60%以上の実測と件数・割合、三連単1点と固定点数、二車単1点と2点、変動点数、少点数・1点の比率、平均点数、最終周回・区間タイム、個体識別・映像と六局面、場別精度、オッズ帯別・全体収益、最大連敗、校正誤差、網羅率100%目標、保留率を測る。少点数と信頼度の割合を増やすときも同条件で性能維持を確認する。

## 18. 開発順

既存と実測の監査、全国バンク、選手、最終周回、映像、ライン、気象と適性、六局面、着順確率、可変点数、校正、PDCA、未来レースの順に受け入れる。独立工程は並行し、利用できる既存機能とデータを再利用する。各工程は予測への寄与まで確認する。

## 19. 禁止事項

基準の引き下げ、点数による能力の水増し、外れ・不得意の除外、原本の事後変更、リーク、根拠のない確率、映像・タイムの捏造、推定と実測の混同、オッズ時刻の偽装、学習内だけの評価、テスト成功のみの完成宣言、実精度を伴わない改変を避ける。既存のGitHub・暗号化・取得権限・保護レビューに従う。

## 20. 到達状態

全選手の能力、特性、調子、戦法、会場タイム、バンク適性、ライン相性を更新し、複数展開と着順分布を学ぶ。レース条件に応じて点数を選び、全レースで継続学習し、未学習の実レースによる改善を示す。最終的に少点数、とくに1点での的中率と収益性を高める。
