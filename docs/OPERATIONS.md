# 開発とPreviewの継続運用

実行先・検証済みコミット・ジョブ番号は`OPERATIONS_STATE.json`を読む。
認証情報そのものはこのファイル群へ保存しない。

## 稼働を確認した経路

専用GitHub Actions → 当日の公式開催一覧/B番組表を2GET → 正規化 →
Preview限定の署名検証 → 非公開Blobの版保存/読み戻し → 当日APIの全内容SHA照合。
専用ワークフローは`feat/boat-oidc-probe-auth`の`RACE AI Preview Blob E2E`。
Vercelの既存信頼設定はこのブランチ・ワークフロー・Previewに限定している。

`/api/health`は同じ実際のBlob日次データを読み、完全な開催証拠・24場・
開催場ごとの12レース・全レース6艇が揃う場合にHTTP200/ready=trueを返す。
未取得、権利ゲート、古い日付、取得エラーや部分的な開催表ではHTTP503となる。
非開催が公式一覧から確認された日はレース数0を正常として扱う。
このreadinessは当日番組の状態であり、予測モデルや全レースの展示・オッズの完成判定ではない。

同じ限定OIDCの`POST /api/publish-race`で観測本文と実クラウド受領時刻を別々に不変保存し、
`GET /api/race?race_id=YYYYMMDD-vv-rr`で番組照合付きの最新種別を配信する。
実測38646273445は鳴門1Rの展示PENDING・オッズPARTIAL（9価格/111未知）を保存し、
全API内容SHA、正規化入力とAPI応答の別フォルダ復元を確認した。
当日番組の再取得はこの実行で全てスキップした。詳細は`PER_RACE_CLOUD.md`。

## 定期実行の現在地

このチャットに戻る1時間ごとの継続開発をアプリに登録した。
識別子`race-ai`、状態ACTIVE。前回の記録とPR #64を引き継ぐ。
ローカルファイルを使うため、PCとアプリが起動している必要がある。
当日APIが未取得、または最終実取得から6時間以上経過した場合だけ、
検証済みの専用GitHubジョブを一度再実行して当日取得を確認する。
実行中のジョブを重複起動しない。原本を使うリクエスト数は1実行2GET。
これはアプリによる起動であり、PC不要のクラウド定期スケジュールではない。

現在のワークフローはpushと既定dispatchで`race`だけを実行する。
`day`は明示的なdispatch入力が必要。検証済みの日次実行とレース実行のIDを混同しない。
日次を再実行する場合は状態ファイルの`last_verified_day_job_id`を使い、上記6時間条件を守る。
レースの入口は1レース最大2GETで、全場定期巡回や予想・結果の自動蓄積はまだ稼働していない。
SDKにCASがないため、この共通concurrency group以外から並列書込を始めない。

GitHubのscheduleは既定ブランチ上のワークフローで動く。
現時点のVercel設定ではmainへのコミットがProductionデプロイを作成し、
本番ドメインを自動割当することを読み取り確認した。
そのためクラウドcronをmainへ配置する操作は実施していない。
本番公開の最終判断と整合する構成を準備・検証してから導入する。

正規化JSONだけをGitHub Actions artifactへ保存し、別フォルダへ復元した。

出典原本、環境ファイル、秘密値、購入記録はアップロード対象に含めない。

証拠は`evidence/2026-10-15/github-backup-restore-live.json`。

## 調査と復旧

1. `OPERATIONS_STATE.json`で最新の検証済み実行とアプリのコミットを確認する。
2. `/api/health`、日次ジョブの段階、Vercel実行ログの順で取得/認証/保存/読取を切り分ける。
3. 認証失敗で保護を解除しない。JWTの署名・期限・repo/branch/environment/workflow/audienceの不一致を修正する。
4. 取得失敗を非開催・0オッズ・不的中へ置き換えない。前日のデータを当日として表示しない。
5. 修復後はテストと独立レビューを経たコミットをPreviewへ置き、実際の保存/読取/API照合をやり直す。
6. 不変の版を保持し、異常な配信を検知したら公開候補を止める。本番ロールバックやバックアップ復元は別途実測が必要。

本番昇格、秘密値の追加、信頼範囲の拡大、投票・決済を日次再実行に含めない。
未完要件は`COMPLETION_STATUS.md`へ残し、実通信と合成検証を区別する。
