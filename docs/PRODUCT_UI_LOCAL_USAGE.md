# PR71 統合操作画面（本人のローカル閲覧）

製品の最終完成・公開済みを意味しない。既存PR62の画面構造と手動配分を、PR71の保存済み予想の読取へ接続したもの。既存の `forecast-audit.html` も維持する。

リポジトリのルートから、端末内だけで起動する。

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory web
```

ブラウザで端末の8000番ポートを開く。公開サーバーへの配備は不要。初期表示にはレース・予想・実購入を捏造せず「データ未取得」を表示する。

## 読込と操作

- 「保存原本を読み込む」のJSON選択で、認可済みの `RACE_AI_FORECAST_AUDIT_V1` 投影を読み込む。構造は `docs/FORECAST_AUDIT_VIEWER.md` を参照。元予想そのものの上書きや再計算は行わない。
- 競技、JST対象日、期間、検索、会場、状態、候補を切り替え、カードから詳細へ進む。モデル・学習版・P0/P1を選ぶ操作は、既に保存された予想の閲覧であり新規予想ではない。
- 入力にない選手名・気象・発走時刻・予想根拠・版は未取得のまま表示。参考画像の人物や数字は収録しない。
- 候補の追加・金額編集・均等配分・削除・候補確定が可能。最大8点を標準に、16/24/32は手動候補に限定。候補確定だけでは使用額・実購入成績に計上しない。
- 実購入は明示した別操作による本人の手入力。合成データから実購入への転記は拒否。未記入の払戻は未確定であり0円の損失ではない。
- 設定の予算等だけをブラウザへ保存する。予想・購入候補・購入明細はメモリ内に保持し、再読込すると消える。個人原本を静的配信用 `web/data` やpublic Gitへコピーしない。
- 合成データは専用ボタンから明示して開く。合成・研究・監査台帳は正式Hit@8の成績に加算しない。

## 証拠と集計の限界

`product-data.js` は構造・時刻順・ハッシュの形式と相互対応・結果改訂の一致を検査する。ハッシュピンや発行者文字列をブラウザへ入力しただけで、外部署名・真正性・利用許諾が独立に認証されるわけではない。「公式対象・読込値」もインポーターの申告であり、独立監査済みという表示ではない。権限のある既存 `verified_event_projection.project` は既定拒否の検証コールバックを維持する。検証フラグや時刻を捏造して取込条件を通さない。

予想版・時点の混合集計は正式率として出さず、モデル・版・段階ごとの比較へ分ける。未予想レースを評価可能な全対象分母から除外しない。返還・特別処理は通常の的中判定に混ぜない。未校正の確率、期待収益、リスク評価を見せかけの数値として表示しない。未接続のモード・万舟推奨は理由付きで無効にする。

## 検証

```bash
node --test tests/product_data.test.cjs tests/ui_model.test.js
node tests/ui_browser.test.js
```

ブラウザ試験はPlaywright 1.62.1とインストール済みChromiumが必要。環境のChromiumを利用する場合は `CHROMIUM_PATH=/usr/bin/chromium` を指定する。証拠は既定で `artifacts/ui-browser` に出力する（合成のみ）。このクラウドの実行制限ではローカルHTTP/ブラウザ用のサポートされた実行権限が必要。

Python回帰試験のPR64/72参照は既存CIの固定SHAを使う。このクラウドの `/tmp/.git` マーカーで私有出力ガードが作動する場合は、非Gitの一時領域 `TMPDIR=/var/tmp` とサポートされた実行権限を使用する。ガードや署名/TLS検証を無効にしない。

未マウントの実予想原本、4競技の実データ供給・全対象継続運転、期限なしの本人専用保管、実機iPhone Safariでの最終受入は別ゲート。スクリーンショットと合成テストの成功を、それらの実証や98%達成と扱わない。
