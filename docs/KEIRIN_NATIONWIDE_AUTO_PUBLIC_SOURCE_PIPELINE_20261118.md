# 全国競輪A/B予想：実出走表自動供給の開発（2026-11-18）

## 本人の優先指示
「全国の本物の出走表・公開印・ライン・締切時刻を新エンジンに自動供給すること」。全国全開催・全R（11/18は8会場79R）を先に分母に固定。A（既存公開予想印などによる基準予想）とB（初周→打鐘→最終H→最終B→4角→ゴールの6局面＋複数戦術）を締切前に生成し、暗号保存後、結果を同じレースIDで採点する。Cは追走ラベル不足ならCのみHOLD。共通未完成4モデルは不要。

## 新たにGitHubへ実装したソース→自動予想までの経路

1. `scripts/keirin_discover_public_race_links.py`：毎日Kドリームスの公開開催一覧→会場別出走表一覧を通常URLで読み、**ページ内に実在する<a href>リンクだけ**を使って各レース詳細のURLを発見。会場コード・開催初日・2日目等のインデックスから実施日を検算し、レースIDと重複を照合。リンク不在はHOLD、URLやページ存在を推測で完成扱いにしない。netkeirinの通常race_id URLは後続GET候補として作成するのみで、実出走表確認済とはしない。
2. `scripts/keirin_capture_public_two_sources.py`：認可済みの通常公開URLだけに、**1巡最大8レース×2ページ**までの連続GET。403/429、アクセス不可、HTTPSリダイレクト・認証エラーではそれ以上のGETを止める。403/429はowner-privateの当日停止台帳に記録して次の10分巡でも自動再試行しない。成功時だけ元HTMLバイトSHAと取得時刻を非公開保存。
3. `race_ai/keirin_public_two_source_normalizer.py`：2サイトの本当のHTMLに出ている各選手の印、競走得点、脚質、H/B、4か月勝率と実際に記載のある並び予想/締切をrace_idで結合し、`RACE_AI_KEIRIN_NATIONWIDE_PRE_RACE_FACTS_V1`を生成。開催初日・2日目のURLを区別。本人登録IDが表にない場合はnullで保存し、選手の個人識別番号を捏造しない（Cは引き続きHOLD）。ガールズに固定ライン掲載がない場合は当面全員単騎の**仮説**であり、実映像で確認した走行位置ではない。
4. `scripts/keirin_nationwide_auto_forecast.py`：生成されたprivate cardsを一巡→A/Bを自動計算→別AES-256-GCM＋既存RSA公開鍵でowner-private封印。同じレースの既存ファイルを上書きしない。別runnerの暗号文SHA検証は既存実装。入力不足・提供元拒否・遅刻はNO_FORECAST/HOLDで分母に残す。
5. `.github/workflows/keirin-nationwide-ab-auto.yml`：ownerが有効化したmainで10分巡回、S3 private原本/既存カード読出し→day manifestがない場合は公開HTMLリンクから自動発見→まだないレースを最大8件通常GETし元HTML SHA保存・正規化→実A/B生成・暗号保存→別runner暗号文読戻しを接続する。捕獲元HTMLとカードは本人非公開のS3に保存、GitHub公開アーティファクトは暗号文とPIIなしの結果のみ。

## テストと本番を分離

- 新しいソースHTML結合の source-free CI は6車実例の形式を模したHTMLテーブル、開催2日目URLの誤結合拒否、6局面への自動入力、公開印の同着、ガールズ、原本SHA不一致、403/429停止、日付間重複防止のケースを検証。使用した選手数値と元HTMLは**テスト用の合成資料であり実レースの源泉バイトではない**。
- 2026-11-18宇都宮1Rの一度だけの実公開ソース読み取り検証 `scripts/keirin_real_public_source_smoke.py` と PRのread-only Actions jobを用意。通常公開2ページが取得できたか、変換が実際に成功したか、アクセス拒否だったかを**PIIなしのログ**で分類する。元HTMLは公開/配布しない。
- GitHub repoの本番自動生成は**PR Draftのままmain未統合、owner AUTO設定未起動**。本番で全国79レース分の実HTML→A/B暗号原本を生成した実績は未確認。前回の手動西武園1RのAES凍結1件と混同しない。

## 実稼働に残る重要条件

1. **実サイトのHTML形式が新パーサと一致するか**、GitHub runner側の本当のURL取得成功/拒否を実ログで確定し、必要ならDOM差異を調整する。siteが認可なくリダイレクト/アクセス制限を行う場合、隠しAPIやUA詐称等で突破しない。
2. **公開元との継続取得条件**と必要な項目の完全性、主催者の最新締切と変更通知は別ゲート。今回の「掲載締切」は実際の売り止め瞬間の独立証明ではない。
3. 毎10分起動はスケジュールの遅延により締切前生成を保証しない。全国全Rの実時間順のキュー、停止復旧、更新後ソース対応を本番証拠で評価する。
4. AWS/S3互換の永続ソース台帳がないと、別runnerの再開時に初期状態へ戻る。現ワークフローはprivate card/rawのS3保存を用意したが、出走前予想暗号文の**跨ぎrun create-onlyの永続一意保存**はまだ未証明。
5. 公式結果・払戻からA/B全Rの精度/仮想ROIに接続。Cは真正な映像追走履歴が確認できてからのみ算入。

**完成判定**：「実公開取得が本番で成功」≠「自動予想が本番で成功」≠「暗号永続保存・独立読戻し」≠「公式結果との全R照合完走」。各段階を証拠別に採点する。main/秘密鍵/新有料APIの利用は本人承認なしに変更していない。
