# ボートレース先行公開：安全な段階リリース方針

## 目的と現在地
RACE AI のボートレースだけを先行利用できるようにし、競馬・競輪・オートレースは Coming soon とする。
既存の main は 2026-10-14 時点 README のみ。v0.7〜v1.2 は Draft PR の依存チェーンであり、まだ main 本番稼働は未確認。

このブランチで実装したのは **スマホ対応の表示画面とローカルJSON閲覧** のみ。予想エンジンのWeb連携、本番の当日自動データ収集、発走前オッズ・レース結果取得、性能・権利・安全性の統合検証、一般公開は未完了。

## モジュールと段階
- boat: 最初に公開する唯一の機能。最初の提供範囲は「許可済みの正規化JSONをスマホのブラウザで選択して、場・レース・艇と展示情報を表示」まで。
- horse / cycle / auto: 明示的に Coming soon を表示。バックエンドの処理・データ収集・投票などは行わない。
- ユーザーが開いたファイルはローカルのFile APIからのみ取得し、どこにも送信・保存しない。外部APIアクセス、広告計測、クッキー、localStorage、架空データは禁止。
- 現段階のブラウザ画面は投票、勝率、期待値、買い目を生成しない。収録データの表示を予想成果と混同しない。
- ソースの出典、初回確認時刻、非公式/未独立検証の注意を明示。未知値は未取得、6艇未満のレースは未完として区別。

## ユーザーによる試験方法（正式公開ではない）
1. 静的サイトのドキュメントルートを web/ として Preview を作るか、web/index.html をプレビューサーバーで表示する。
2. 許可済みの前節 v1.2 正規化出力（race_ai.public_day_feed の JSON）をローカルファイル選択から開く。
3. 開催場とレースを切り替え、各艇の選手登録番号・モーター・平均ST・展示数値などを確認。
4. 不正JSON、日付相違、重複艇、欠損、巨大ファイルで安全に拒否され、過去のデータが残らないことを確認。
5. 競馬・競輪・オートレースの Coming soon 表示と、ボートへの復帰を確認する。

**注意:** 当日の勝率予測も、ソースの配信利用許諾も、公式原本との照合も、この閲覧動作によって証明されたことにはならない。元データの配信者の利用規約・再配布許可の確認を、利用前に別途実施すること。

## 本番切り離し方針
- 正本は main。開発は feature ブランチから Draft PR に限定し、既存の未完成 Draft PR を直接本番投入しない。
- CIの実行結果、独立レビュー、実機検証、権利・利用条件をすべて確認後にだけ、公開対象を main へ段階的に統合する。
- Production と Preview のビルド/URL/シークレット/DB/データ格納を分離。Preview から Production データへの書き込み、同一DBの共有、無審査の自動リリースは禁止。
- 本番ブランチへの直接push/force pushを拒否するルールセットと必須テスト・レビュー、公開承認、ロールバックを本番設定前に構成する。リポジトリの設定に実際に反映されるまで完了扱いにしない。
- リリースするまで Preview も不必要に公開しない。静的UI自体に秘密情報を含めない。
- 本番が動作している間の開発は別ブランチ・別Previewで進め、本番更新にはPRによる明示的な昇格を要求。
- 将来データ取得処理を追加するときは、取得元の権利・頻度制限と成功時だけの原子的な更新を条件とする。失敗した取得は既存本番スナップショットを書き換えない。

## ボート予想を実利用可能と呼ぶための残条件
- 最新の実B/K公式原本の受入と実物照合（異常レースを含む）。
- 開催全場の当日出走・展示・進入・オッズについて、合法的な取得と取得時刻・公開時刻の記録。
- 出走締切より前の情報のみを使った120通り確率、推奨買い目0〜8点（設定拡張16/24/32点）、見送り判断の実装。
- 過去の未来情報混入禁止、時系列分離した未使用期間の実レース予測検証、確率校正と回収率評価。
- スマホの実機E2E、複数同時アクセス、本番と開発の独立、障害時のロールバック、出典・利用許諾。
- 実証までは「予想準備中」とし、有料/無料を問わず根拠のない精度・的中率を表示しない。

## スマホ中心の運用
スマホ上のGitHubアプリまたはブラウザでIssue、PR、レビュー、Actions、公開承認を操作できるようにし、コード実行とテストはクラウド側に担当させる。PC常駐を前提にしない。手元のハードウェア依存の動画解析やブラウザ互換テストは必要に応じてPC/実機を使用する。
