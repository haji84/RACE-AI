# 競輪RACE-AI｜予想比較の正式対象切替（2026-11-18 JST）

## 現在有効な指示・結論

所有者指示：「共通予想の4モデルはまだできていないから4モデルは外して、6局面や今予想が生成されているものを対象にして。」

**本研究の比較合格に未完成の「共通4モデル」やそのPR71保存元を要求しない。** A/B比較はCの連係履歴が未完成でも先行実施する。旧PR71予測モデルの保存やコードは他用途の歴史正本として残すが、A/B/Cの必須親モデル・合格要件・阻害要因から除外する。この方針を以後の新しい引継ぎ書、進捗報告、開発指示、精度判定の最上位とする。

## 比較する3方式（対象となる原本が存在する場合のみ）

| 方式 | 対象 | 確認対象 |
| --- | --- | --- |
| A | **既存に生成・保存されている実予想**。現在確認できるのは2026-11-17の全国71R V3（最大12点）等。将来はそのレースの締切前に実生成した同方式の原本を使用 | 生の予想JSONバイトSHA、作成時刻、順位付き3連単、原本とレースID |
| B | **6局面の条件分岐・展開予想**。初周→打鐘→最終H→最終B→4角→ゴールを実際にシミュレートし順位付け。親入力はAに使う実予想・出走前原本から取得 | 6局面/複数戦術、勝ち上がり条件、同じ出走表・締切、順位付き3連単、別保存SHA |
| C | **Bに実際の過去連係経験を追加**。先頭と番手/3番手の登録ID、履歴の公開時点・動画・追走/離れ/切替の確定ラベルが必要 | Bと同条件の3連単に、真正な連係履歴を加えた差。認証履歴不足時はCのみHOLD |

比較の基本は A対B。Cが用意できたレースでは、同じレース集合に限って B対C を追加する。B全件とCがある一部だけを比較して「改善」と言わない。最大12点・可変点数を認め、Hit@1/Hit@全候補/各点100円仮想ROI/保留率で記録する。実購入を意味しない。

## 旧4モデルへの依存を外したコード

- **`race_ai/keirin_available_forecast_sources.py`**：既存71R V3の実バイトSHA・71R単位のID/順位/時刻・6局面仮説を読込み、存在する生成済み予想として検証。過去に発走した予想や未確認の締切を正式予想として扱わない。出走表/締切/元予想の外部認証が揃えば、既存6局面処理が使う**source-neutral snapshot**を作る。モデルID `existing-generated-keirin-research-v3` は共通4モデルIDではない。
- **`race_ai/keirin_round_six_phase_rank.py`**：既存の旧4モデルとの互換は壊さず、新しい生成済み予想のモデルIDを独立した有効親ソースとして扱えるように変更。元の4モデルが全部存在することは新しい6局面研究には要求しない。
- **`race_ai/keirin_active_available_pipeline.py`**：A実生成予想→Bの6局面・複数シナリオを作成。過去連係の独立ラベルが有る場合だけCを追加。履歴なし・Cの入力不正・履歴不足では**AとBを保存対象として残し、CのみHOLD**。この時点では暗号原本の跨ぎ保存やサイト反映成功を主張しない。
- **`race_ai/keirin_available_prediction_audit.py`**：A/Bの事前原本保存・独立読戻し・公式締切認証・公式結果の独立認証を条件に、2方式で先に採点。Cが有る場合のみ同レースの3方式採点。事前登録した対象レースを維持し、Cが無いだけでA/Bを捨てない。3方式の結果を別分母で集計しない。
- **`tests/test_keirin_available_forecast_comparison.py`**、**`tests/test_keirin_active_available_pipeline.py`**：架空原本によるソース検査、6局面への接続、A/B採点、CなしでもA/Bを残す処理、改ざん・後出し・独立原本未確認の拒否、B/C同レース集合比較を回帰。**合成CIは本番予想完成ではない**。
