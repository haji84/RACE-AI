## 使い方
1. 所有者はA用・B用オフラインHTMLを**別々の本当のレビュアー**に非公開で渡す。元映像は権利範囲を守って取り扱う。HTML内に映像の元ピクセルが含まれるため公開GitHub・SNSへの投稿は禁止。
2. 各人は**相手の回答も、モデルの検出結果も見ずに**全46フレームを確認する。画像をドラッグして見えているジャージ色領域を囲む。ジャージ全体と人物全身の境界箱は混同しない。
3. 車番を服色だけで推定した場合、根拠は `COLOR_ONLY` とする。数字の視認または別フレームでの独立確認がないのに `VISIBLE_DIGIT` としない。根拠がないときは `UNKNOWN`。
4. 見えている対象を漏れなく囲めたと本人が判断した場合のみ、そのフレームの「全対象確認」欄をチェック。空フレームの確認も必要。途中保存用JSONはローカルに保持して続きを再開できる。
5. 46枚すべてを確認したら各人が**別々の完了JSON**を提出。画像や座標を第三者公開しない。ファイルの送信・本人確認はユーザー側が管理する。
6. 署名と独立性の受付は、すでにPR #291にある `scripts/keirin_sign_blind_review_private.py` と `race_ai/keirin_signed_blind_review_gate.py` を使用する。ただの2つのAI署名鍵は不可。本人の別経路認証と事前チャレンジ登録が必須。
