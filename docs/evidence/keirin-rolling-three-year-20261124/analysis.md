# 過去3年の選手別履歴とバック以降の展開学習

対象は2023年11月24日〜2026年11月23日 JST。月別CSVと保存済み出走表・確定結果を日付・場・R、車番と登録番号で照合し、完全な着順を確認できた76,005レース、1,090日を採用した。登録番号付きの延べ出走は512,476行。最後の11月23日は既存の締切前出走表88件と公開結果を照合し、全車の着順と確定組が一致した82件を追加した。着順を数値で確定できない4件と、確定組の照合保留2件を除いた。公開一覧の89件のうち残る1件は締切前の保存版がなかった。11月22日以前の固定候補は63,405件すべて一致した。[資料の照合方法](../keirin-three-year-20261124/experiment.md) · [11月23日の結果](https://keirin.kdreams.jp/raceresult/2026/11/23/) · [集計と固定記録](results.json)

既存のアーカイブで全車の着順を確認できなかった6,483件は保留した。最初の約半年の12,518件で初期学習し、2024年5月24日以降の63,487件を半年ずつ順に予想・採点した。着順の係数は各期間の開始前の資料で学んだ。選手の履歴は、同じ日に予測する全レースの入力を作ったあとでその日の結果を加えた。出走表に記録された得点・脚質と、照合済みの予定ラインを共通入力にし、結果・払戻・当該レースのS/H/Bを候補作成に渡していない。採点後に採用した全76,005件で同じ研究モデルを再学習した。[期間と再学習の固定記録](results.json)

着順・決まり手と、観測できたS・H・B、バックを取ったあとの着順を選手別に記録した。予定ラインとB先頭を両方確認できたのは27,092件、H先頭を確認できたのは250件。2025年10月より前は保存資料のラインの区切りと実走の位置が大半のレースで欠けていた。公式結果と全員の登録番号が一致した旧い14件にH・B・予定ラインを追加した。Bからの着順予測は、B先頭本人、予定番手、同じラインのその他、別ラインを使う。候補ごとにB先頭の予測確率を掛けて着順の分布を合成した。観測が少ない最初の3期間はBからの着順補正を適用せず、選手実績の学習を進めた。[局面別の資料と条件](results.json)

履歴を直近1年から最大3年に延ばした場合の8点は20,576件から20,542件。条件付きでバック以降の着順を加えると20,635件になった。直近1年版との差の日別95%区間は-0.011〜+0.194ポイント。展開補正が使えたレースに限ると、3年履歴から展開を加えた差の区間は+0.235〜+0.554ポイント。全体比較には後日取得の出走表が含まれる。[点数別・期間別の採点](results.json)

締切前の出走表を確認できた516件では、直近1年版の8点が201件、3年版が201件、展開追加版が206件。同じ出走表・確定組で採点した従来の選手別研究版は516件中214件だった。この比較は既存の研究版を含む過去再現で、新しい期間での改善は未確認。[同じ締切前資料での比較](results.json) · [前回の研究版](../keirin-all-rider-phase-20261124/analysis.md)

## 過去映像で確認できた展開

2023年11月〜2025年9月の公開ダイジェスト12件を視聴し、11件で4角付近の先頭を特定した。いわき平10Rは真鍋顕汰選手がBと4角付近を先頭で通過し、直線で川口聖二選手が勝った。函館5Rは高谷雅彦選手がBを取り、市本隆司選手が4角付近で前に出て優勝した。並走で4角の前後を確定できなかった1件も記録した。[いわき平10Rの映像](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/1320240116/13202401160200/10/) · [函館5Rの映像](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/1120250914/11202509140300/5/) · [各映像の確認時刻](results.json)

この11件を既存の学習用映像25件に加え、2026年11月21〜23日の13件で、Bを取った選手が4角付近でも先頭に残る確率を採点した。ブライアスコアは0.1633から0.1629、ログ損失は0.498103から0.498113。追加映像のB先頭選手と後日のB先頭選手の登録番号が同じだった例は0件だった。3年間の全選手の通過順、仕掛け開始、追走の記録には未取得の部分が残る。今回の映像比較の件数も別に記録した。[映像の条件付き試験](results.json)
