# 競輪A/Bの着順別評価を見直す

年間の出走表を用いた現行Aは、並びが欠けている場合に全着順を候補にする。現行の1着評価は得点60%、勝率30%、掲載印10%。2着と3着には1着実績を含む連対率・3連対率を使う。候補の順位を決める各項目がどの着順に効いているか、投票組数を揃えて確かめる。

2025年11月23日〜2026年7月31日のうち単一着順が確定しているレースで学習した。8〜9月を調整に使い、10月1日〜11月22日の結果は予想と係数を固定してから読み込む。着順別条件付き評価は、前の着順に置いた選手を次着の比較から除き、2着だけと3着だけの過去実績を分ける。欠測は観測の有無を明示する。

調整では、着内率を使う方式、着順別に分解する方式、脚質を追加する方式を同じ資料で試した。上位4組で2車単が現行以上の方式から3連単の的中が最大のものを選んだ。選定方式から競走得点、掲載印、着順実績をそれぞれ外して再学習し、どの項目が調整期間の的中差に寄与したかを確かめた。候補ごとの調整成績と学習係数を保存する。

並びありのレースは現行A/B、番手自力の展開を増やした比較版、同じ展開候補を学習係数で並べ替えた版を比較する。最初に各券種の到達可能な全候補を確認し、同数の上位4組に入った数を別に集計する。1・2着の評価は3着評価と独立させる。採用点数は既存の可変点数規則で算出する。

11月23日の未締切レースでも、同じ係数と同じ出走表を使って両版を事前に作成した。予想原本は本人用領域に保存し、照合ハッシュはGitHubのCI作成時刻と照合する。
