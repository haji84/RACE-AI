# 競輪の映像から最終バック付近の前後関係を学習する

11月18〜23日の26レースで、Kドリームスの公開ダイジェストを再生した。11月18〜20日の11件を学習、11月21〜23日の別の11件を動きの評価に使った。単騎だけの2件と落車を確認した1件は学習標本から外し、11月22日小倉5Rは記録方法を確認する事例に使った。各学習・評価レースで、最終バック付近の2時点の映像から先頭とその直後の位置にいる車を確認した。車番と氏名を締切前の出走表に照合し、先頭の車番を同じ開催の結果票のB印と照合した。内外で並んでいる場合は車の前後位置を記録し、同じ進路での追走は保留した。[映像の案内](https://kdreams.faq.rakuten.net/detail/000033266) · [集計と固定記録](results.json)

11月22日小倉5Rでは、映像47.03秒付近の先頭付近が6番、9番、単騎の7番の順だった。53.03秒付近には、9番が先頭に出て7番が直後にいた。11月19日小倉8Rでは最終ホーム付近の38.76秒で7番と1番が先頭側にいた。50.76秒付近の最終バックでは2番が先頭、5番が直後に変わった。車番の位置は映像、予定上の関係は締切前の並びに基づく。[11月22日小倉5R](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/8120261118/81202611180500/5/) · [11月19日小倉8R](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/8120261118/81202611180200/8/)

既存研究版の着順確率を基に、最終バックの先頭候補ごとに次の車を推定した。映像で見た位置を正解にして、予定ラインの一致と予定上の前後関係による補正を学習した。さらに、映像で直後にいた車が3着以内に残った割合を用いて、着順への補正を学習した。三連単の候補順位では、想定した最終バックの先頭と次の車をその予測確率で平均し、既存の着順確率への補正を25%反映した。評価日の映像や当日結果を補正の学習・予想に渡さず、過去の締切前出走表から作った候補を採点前に固定した。[比較基準](../keirin-odds-opponent-form-20261124/analysis.md) · [最終バックの推定](../keirin-home-back-phase-20261124/analysis.md) · [固定記録](results.json)

映像評価11件のうち、最終バック付近の2人が同じ予定ラインだった8件では、全件で実際の直後の車に置く確率が増えた。別ラインだった3件では全件で下がった。学習11件では同じ予定ラインが9件、別ラインが2件だった。11月21〜23日の締切前出走表211件を固定し、結果が確定した207件を採点した。8点に含まれる組が入れ替わったのは211件中1件。今回の補正は同ラインの位置推定に効いたが、狙っていた別線・単騎への切り替わりと、三連単の的中増は確認できなかった。[日別と展開別の採点](results.json)

次の学習では、最終ホームと最終バックで先頭・直後の車を対応させ、先頭だけの交代と追走相手が替わる場面を区別する。仕掛け前後で位置が見える場合は、区間・車番・時刻を残す。学習期間と後日の採点期間を分け、別ラインに替わったときに実際の組を上位4組に残せるかを検証する。今回は日付順の過去再現で、前向きの三連単改善は未確認。[既存PR #327](https://github.com/haji84/RACE-AI/pull/327)
