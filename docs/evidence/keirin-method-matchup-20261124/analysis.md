# 競輪の決まり手、相手別成績、位置と仕掛けを着順予想へ加える

同じ16,325件の三連単を、前回の「相手の得点を加味した調子」の研究版と比較した。選手ごとの決まり手、同じ相手との成績、S・H・Bの先頭履歴、実走の仕掛けと追走を順に加える。着順の各段階の確率に対する補正として学習した。[前回の比較版](../keirin-odds-opponent-form-20261124/analysis.md) · [特徴量の実装](../../../scripts/keirin_tactical_history_study.py)

月別資料は1〜最終着の順位が揃う場合に使い、氏名・期別・府県を名簿と照合した。前の資料と同じレースは除いた。並びが取れていない月別結果は選手全体と相手別の履歴に使った。Hで定まる先頭や報告の仕掛け区間を使い、全選手のH・B・4角通過順位は資料不足。公式レポートは本文の記述、選手登録番号と結果を照合し、明記された配信日を過ぎてから履歴に加えた。言及のない仕掛けや追走を未実施とはみなさない。[出走表と完走の照合](sources.json) · [月別結果と公式2着決まり手の照合](method-extension.json) · [公式レポートの配信日](method-dates.json)

各選手の1・2着の決まり手は、その着順の決まり手を確認できた出走を分母に記録し、予定ラインの先頭・番手・後位・単騎で分けた。相手別では、登録番号で一致した同走における先着、逃げ・捲り・差しでの勝利、相手が勝ったときの各決まり手による2着を記録した。過去の並びが確認できる組は同ラインか別ラインかで分け、並び不明の記録や同走が少ない組の数値は強く縮めた。「相手と同走して捲りで勝った」確定結果を表す特徴で、走行中にその相手を抜いた地点の記録は公式の記述がある分を使う。[相手別の特徴量](../../../scripts/keirin_tactical_history_study.py)

## 検証の手順

締切前に知り得る予定ラインを使い、各評価日の特徴量を全件確定させた後で、その日までの結果を翌日以降の履歴へ加えた。着順補正の学習は、4〜9月評価用が2月、10〜11月評価用が8月。強さはそれぞれ3月、9月の4点・8点の的中数の合計で選んだ。出走表に予想印がない場合に備え、調整で印を伏せた条件も使った。各特徴の影響を分ける比較では補正の強さを50%に揃えた。評価レースの上位8点は固定してから結果を突き合わせた。以前の研究と期間が重なる、過去データの時系列再現。[予想固定とモデルの照合](commitment.json) · [4〜9月の設定](earlier-configuration.json) · [10〜11月の設定](recent-configuration.json)

## 着順確率を補正した比較

| 同じ16,325レースの三連単 | 1点の的中 | 4点の的中 | 8点の的中 |
| --- | ---: | ---: | ---: |
| 前回の調子を加えた版 | 1,912 | 4,686 | 6,594 |
| 決まり手 | 1,902 | 4,680 | 6,593 |
| 決まり手、相手別 | 1,911 | 4,678 | 6,581 |
| 決まり手、相手別、S・H・B | 1,894 | 4,674 | 6,586 |
| 決まり手、相手別、S・H・B、レポート | 1,891 | 4,672 | 6,584 |
| 調整期間で項目と強さを選択 | 1,896 | 4,679 | 6,596 |

調整期間で選んだ版は8点が2件増え、1点が16件、4点が7件減った。締切前の出走表が残る557件の8点は223件から220件。日単位で再抽出した、全16,325件の8点の差の95%区間は−0.167〜+0.197ポイント。固定50%の段階比較では、S・H・Bまでの8点が6,586件、仕掛け・追走も加えると6,584件。今の資料からは、実走の記述を加えたことで精度が上がったと確認できない。[予想を固定した後の同点数採点](results.json)

実際の1・2着が別ラインだった7,968件では、調整期間で選んだ版の8点が1,513件から1,545件。1・2着を正しい順で8点に含めた件数は2,439件から2,470件。同ラインで1・2着が決まった場合の8点は5,070件から5,040件、予定の番手以降の選手が勝った場合は2,118件から2,097件。照合できた捲り勝ちの4,597件の8点は1,811件から1,828件。2着のマークを確認できた59件では36件から35件だった。[結果の展開別の集計](results.json)

並びを確認して予想した対象では、別ラインの選手同士の組を方向別に延べ560,582組確認した。少なくとも一度対戦した履歴を使えた組は342,968、使った条件で3回以上あったのは71,082。仕掛けなどの公式記述に結び付いたのは延べ116,033出走中2,421出走で、今回の並びと同じ先頭・追走の関係で直接使えた記録は延べ23組。相手別の同走履歴と実走の追走記録で、利用できる量に大きな差がある。[予想日に使えた履歴](commitment.json)
