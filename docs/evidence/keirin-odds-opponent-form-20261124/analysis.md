# 保存オッズと対戦相手を考慮した調子で三連単を再検証

前回の補正は過去16,325件で8点の的中が6,559件から6,560件になった。今回は、入手できた締切前オッズの効果と、過去走の全着順から選手の調子を推定する効果を、同じ点数で別々に採点した。[前回の比較](../keirin-targeted-positions-20261124/analysis.md)

## 保存済みの締切前オッズ

11月20日は保存コミット、11月23日は原HTMLのハッシュと提供元の更新時刻を確認した。固定版が使った締切前出走表と、同一レース、締切、車番と選手名が照合できたのは20日7件、23日83件。89件を払戻と照合し、1件は結果未確認。20日の提供元の原HTMLは未復元で、明細を保存したコミットが締切前の根拠になる。23日分のうち5件は締切・価格の状態を確認できず、1件は固定版の締切前出走表が対応しなかった。[照合と固定記録](odds-commitment.json)

| 同じ89件 | 1点 | 4点 | 8点 |
| --- | ---: | ---: | ---: |
| 従来の研究版 | 15件 | 33件 | 48件 |
| オッズを50%混合 | 19件 | 32件 | 47件 |
| オッズを75%混合 | 18件 | 32件 | 45件 |
| オッズ人気順 | 17件 | 30件 | 41件 |

実際の1・2着が別ラインだった41件の8点は、従来14件、50%混合12件だった。全候補に数値オッズがある30件のうち、ラインが組まれ、結果を一意に区分できた28件で別線の確率を比べると、二乗誤差の平均は従来0.249、オッズ0.246。取得時点は中央値で締切331.6分前。10〜15分前に取った1件のオッズ更新は締切18分前だった。取得と更新の両方が10〜15分前だった資料は0件。直前オッズを使った4点・8点の改善を判定するには、現時点の記録は足りない。[点数別の採点](odds-results.json) · [取得と更新の時間差](odds-timing.json)

## 相手の強さと直近の調子

過去走の全着順を照合できた26,994件を使った。競走得点差から各相手への先着確率を置き、実際の先着とその確率の差を集計した。別ライン・同ライン・自分より得点上位の相手を分け、選手登録番号ごとに直近28日、180日、同じライン内位置、直近3日間の同会場の実績を算出した。出走表を確認した29,579件の延べ210,501出走のうち、直近28日に使える履歴は197,507、直近3日に同会場の履歴があったのは127,880。[特徴量と欠測の処理](../../../scripts/keirin_opponent_form_study.py) · [全着順照合と固定記録](form-commitment.json)

各日全件の特徴量を作った後にその日の結果を履歴へ加えた。予想対象より前の日の結果を使って調子を更新する過去再現であり、過去各日の公開時刻まで独立して照合した履歴ではない。学習時期・調整時期は前回の研究版と同じ。1・2・3着の決定木を再学習し、調整期間の4点と8点の的中数の合計で基準版との混合率を決めた。前半は印ありで全段50%、印なしは全段を新方式。直近は印ありで1着のみ50%、印なしは全段を新方式。印なしの調整では出走表から印を伏せた。元の予想の再計算結果が保存した順序と一致することを確認し、比較用の候補を固定して採点した。[前半の設定](earlier-form-configuration.json) · [直近の設定](recent-form-configuration.json)

実際の1・2着が別ラインの場合、8点は1,495件から1,513件、同ラインでは5,053件から5,070件になった。番手以降が勝った場合は2,107件から2,118件で、7車の並びありに絞ると1,753件から1,751件。日単位の差の95%区間はいずれもゼロを含む。[着順とライン条件ごとの集計](form-results.json)
