# 過去着順のばらつきと記者の最終BS配置図

## 2着候補に選手ごとの過去のばらつきを使う

着順平均が同じ選手でも、強い相手を上回った走りと大きく後退した走りの分布は異なる。過去の完走着順を同じレースの競走得点から推定した相手関係と照らし、相手を上回った割合の差、差の二乗、大きく上振れ・下振れした程度を選手の登録番号で集計した。過去365日と90日を使い、同じ日の結果を追加する前にその日の特徴を計算した。3年の資料76,005件のうち、全選手の得点と着順がそろった74,745件を履歴に使った。保存済み資料を使った時系列の再現で、元出走表の取得時刻を確認できた標本は別集計にした。

2026年5月23日までの50,939件で2着を選ぶ補正を学習した。1着確率と、1・2着を固定した条件付き3着確率は維持した。5月24日から11月20日の12,234件の予想を固定後に採点すると、1点は1,248→1,257、4点は3,234→3,227、8点は4,583→4,591。8点の差の開催日単位95%区間は−0.13〜＋0.27ポイント。締切前の資料が残る321件では、4点84→84件、8点119→119件。精度の改善を確定できなかった。[日付分離と採点](holdout-result.json)

11月26日の8場84件すべてで、既存の展開予想と静的予想の元の上位8点を再現した。その上で登録番号の過去成績を使った比較を締切前に固定した。84件の延べ580出走で履歴があり、買い目の組は1点で1件、4点で8件、8点で24件変わった。採否は二元照合による前向き採点で判断する。[84件の登録](nov26-receipt.json)

## 最終BS配置図の取得状況

締切前のKdreams出走表として扱える資料から、通常のライン表示とは別の記者予想「最終BS」を119件で確認した。CSSの横位置と図の左矢印から最前列を読み、重なりがあれば同位置のままとした。縦位置で内外の車線や車順を推定していない。公式とKdreamsが一致した112件では最前列に実際のB先頭がいたのは72件。記者図と出走表の過去B回数最多がともに一意の101件では66対59件だった。実際の勝者が分かった状態で別ラインの2着を一人ずつ比べた39件では、記者図11件、既存方式12件だった。[元資料の照合](editorial-grid-freeze.json)・[過去の採点](editorial-grid-retrospective.json)

翌日の84件を固定したKdreams出走表からは、7場72件で記者図を確認した。松山12件は図がなく、元の出走者・締切と静的予想の上位8点を再確認した。この図は記者の事前予想であり、実走を記録した図ではない。[翌日の取得記録](nov26-editorial-coverage.json)・[松山12件の再確認](matsuyama-2148-readback.json)
