# 締切前原本の確率評価と締切前取得時刻の検証

## 確率の採点

既存の `scripts.keirin_joint_forward_score.score_joint` と、実原本をRSAで復号する `scripts.keirin_joint_recovery_score.score_recovery` へ、本人用の `include_probability_metrics=True` を追加した。観測が一致した上位3着を、保存済みの同時着順分布から求めた各着順と二車単・三連単の分布で採点する。Brierは各候補の予測確率と実現指標の差の二乗和をレース平均し、対数損失は実現した候補の確率の自然対数を使う。実現確率が0のレースがあれば無限大となるため、JSONでは件数と `null` を組み合わせて表す。観測0件の平均も `null` とする。

三連単1・4・8点と二車単2点については、選んだ候補の確率合計と的中を照合する。5区間の境界は0、20、40、60、80、100%。区間ごとに件数、平均予測確率、実測頻度、二値Brierを返す。上位3着が二つの資料で一致した事例に限定し、全員完走・同着なしという予測の前提が公式に確認済みかどうかは別記する。旧CLIと通常のActionsでは従来の集計を出し、少数のレースから個別確率が推測され得る追加指標の本体は本人用領域に保持する。

11月25日の締切前原本10件を、既存P-256の本人用暗号化履歴から同じ平文SHAで復元。23時27分公開結果で9件に対して旧B・比較Bの両方を採点した。4点・8点の三連単はともに各3件、二車単2点はともに各2件だった。確率指標の方向は券種と尺度でそろわず、精度向上や信頼度の校正完了は判定できない。既存の別RSAランナーも同じ原本・9件で通常の的中数を確認した。[本人用採点の出典SHA](private-evaluation-provenance-2327.json)・[別RSAランナーの採点](../keirin-live-accuracy-closure-20261125/verified-main-score-2327.json)

## 締切15〜10分前の生成

11月21日〜25日の既存PR71定期実行22回で、開始の間隔は最短47.1分、中央値233.2分、最長520.6分。21間隔すべてが5分を超えた。通常認証で読み戻した本人用の研究保管12回と、その処理時間帯に一意に含まれる定期実行を照合した。合計236件は予想記録数で、同じレースの再取得を含み得る。締切前の優先処理7件では、起動から取得38.0〜67.1秒、起動から生成39.0〜68.0秒、取得から生成0.8〜1.0秒。短い時間帯の確保を左右していたのは、主に定期実行の開始間隔と取得までの時間。時間帯の一致と実行ログによるすべての由来確認を区別した。[定期実行と実際の取得・生成時計](scheduled-generation-timing.json)

既存の本人用収集は1回の取得を行う。全国生成の切替設定は優先処理の間隔を変えず、レース後の結果監視用ループも別の役割を持つ。既存前処理を1回15分以内で繰り返すだけでは観測した47〜521分の開始間隔を埋められない。11月26日の事前固定84件と、その日に実測する締切15〜10分前の生成件数は別々に集計する。

## 静岡5Rの保留理由

KドリームスとnetkeirinはHTTP 200で、二車単7-6・12,400円、三連単7-6-3・27,630円が一致した。netkeirinの着順表には②と④の4着同着がある。現在の取込は本文の同着を検出して公式確認を要求し、払戻欄では同着を確認できなかったため公開結果を `source_disagreement` として保留した。全着順の評価と公開保留は維持した。[両掲載元と保留の記録](shizuoka-5r-hold.json)
