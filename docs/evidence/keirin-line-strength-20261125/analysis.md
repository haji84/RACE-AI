# 並びの効果と、別ラインが2着に入る決着

11月21日・24日の過去再現18件で、同じモデルと入力を使って並び項目だけを切り替えた。8点では新規的中4件、取りこぼし3件。取りこぼした3件は、事前の並びに照らすと1着と3着が同じラインで、2着が別ラインだった。

実際にこの形だった5件では、正しい順の1・2着が三連単上位8点に残ったレースが3件から0件に減った。1・2着の確率を3着全候補で合算した場合、正しい組が上位8組に入ったのは4件から3件。並びを使う方式で1・2着の確率順位自体が弱くなった例に加え、上位8組では残っていても、三連単8点でその組を使う枠がなくなった例もあった。対象レースの実測4角や乗り換え位置は確認できていない。[着順別の候補落ち](older-relation-diagnosis.json)

11月25日の前向き12件は、並びを反映すると2件から5件。新規3件すべてで元の1着確率の上位2人に勝者が入っていた。別日18件との小規模比較では、車数・ライン形状・最上位の1着車の交代を使う採用条件は確認できなかった。
