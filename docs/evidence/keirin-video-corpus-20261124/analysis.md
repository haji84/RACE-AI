# 競輪の3年分の全掲載レースを対象とする映像学習

## 公開プレーヤーでの追加学習

楽天Kドリームスのレース結果ページから「ダイジェスト映像を見る」を選び、映像内の時刻、最終バック付近と4角付近の先頭、直後を走る車番を記録した。映像・静止画は保存していない。車番が並走や重なりで読めない場合は未確定とした。以下の時刻はダイジェスト内の観測時刻。[観測した全レースと集計](live-player-study.json)

2026年8〜11月の未判読10レースを学習用に選んだ。選定は後日の評価に登場した10選手を対象に、その選手が実際に最終バックの先頭を取った過去走をさかのぼる方法。4角付近でも先頭だったのは7件、別の選手が先頭に出たのは2件、並走で前輪の順序が確定しなかったのは1件。判定できた9件を既存の選手別の学習例36件に加えた。

- 名古屋5Rでは、舟山佑京の白1番が51.2秒で先頭。52.1秒から53.5秒の間に外の橙7番が前に出て、4角出口の59.85秒は7番、1番の順だった。[名古屋5R](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/4220261030/42202610300100/5/)
- 松山11Rでは、梶原大地の橙7番が後方から外を進み、47.5秒に先行する白1番に並んだ。48.5秒には前に出て、バック付近の59.0秒と4角付近の67.0秒は7番、3番の順だった。[松山11R](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/7520260919/75202609190200/11/)
- 11月19日の小倉2Rは2回独立に判読した。最終バック付近49.5秒と4角出口付近58.3秒のどちらも中野慎詞の赤3番、橙7番の順で一致した。同じレースは学習に1回だけ使用した。[小倉2R](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/8120261118/81202611180200/2/)

実際のB先頭が分かっているときに、その選手が4角付近まで先頭を保つ確率を既存の方式で推定した。以前に採点した11月21〜23日の13レースでは、ブライアスコアが0.1629から0.1523、対数損失が0.4981から0.4681に下がった。どちらも小さいほど正解とのずれが小さい。さらに11月22日・24日から、4角をまだ判読していない5レースを選び、11月24日14時55分58秒UTCに両方式の確率を固定してから映像を開いた。選定には選手の公式B記録を使った。[条件付き評価の固定時刻と採点](live-player-study.json)

未読5件のうち3件で両地点を判定できた。B先頭が4角まで残ったのは1件、交代したのは2件。ブライアスコアは0.3545から0.4006、対数損失は0.9125から1.0347に悪化した。広島7Rの岡部陸斗と小倉9Rの中野慎詞について、新たな過去走を加えると先頭を保つ推定確率が上がったが、どちらも別の車が前に出た。奈良4Rは4角出口で5番と7番が並び、西武園3Rは先頭交代の前後でB線を特定できず、2件とも採点対象外とした。西武園の元の観測と独立再読の判定を併記した。[中野の前に白1番が出た小倉9R](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/8120261118/81202611180500/9/)・[岡部を橙7番が抜いた広島7R](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/6220261122/62202611220100/7/)

三連単の既存方式には、締切前に保存した出走表・当時の予測・バックと4角の両方で前2車が特定できる11月19日の小倉2Rと3Rを加えた。学習例は14件から16件。11月21〜23日の211レースで元の候補順位を再現し、対象レースの実際のBや着順を渡さずに再予測した。結果が揃った207件を同じ点数で照合すると、追加の前後とも1点26件（12.6%）、4点69件（33.3%）、8点93件（44.9%）。4点で1レース、8点で2レースの買い目が変わり、的中の増減は全点数で0件だった。[三連単比較の件数と固定時のハッシュ](live-player-study.json)

## 映像から学習に使えたもの

時刻・ハッシュを照合した静止画が1,636枚ある。連続再生できた3件のダイジェストは計221.32秒、5,533フレーム。選手別の仕掛けと追走を計88項目確認し、43項目を学習に使い、45項目に判読不能の理由を残した。件数には同じ出走を短い区間と最終周全体の両方で判読した例も含まれる。[区間・判定別の実数](results.json)

- 2025年9月16日函館5Rで、5番の市本隆司は4番を追い、最終ホームからバックの間に外へ出て追い越した。2番の内藤敦は終盤に5番の後輪から離れた。4・6・7番は決勝線の通過が画面外で、その選手の全周は未確認とした。[函館5R](https://keirin.kdreams.jp/hakodate/racedetail/1120250914030005/?pageType=showResult)
- 2024年5月4日いわき平1Rでは2・3・5・7・9番の最終ホーム線と決勝線の通過を別々に読み取り、別の観測でも5人すべての時刻の範囲が重なった。映像で3番が4番を追い越し、2番が3番を追い越す場面を確認した。「前の選手を自分が抜いた」と「前の選手について行けなくなった」は別の履歴にした。[いわき平1R](https://keirin.kdreams.jp/iwakitaira/racedetail/1320240430050001/?pageType=showResult)
- 2026年11月20日小倉2Rは、ダイジェスト内の4秒間を全101フレーム確認した。1番はこの区間で新しく仕掛けなかった。同じ選手の別日の仕掛けを加えると、この実際の判定に置く確率は全体基準の14.3%から11.4%に下がった。対象区間は粗い静止画を見て選んでおり、後日の未知レースでの実証には数えない。[小倉2R](https://keirin.kdreams.jp/kokura/racedetail/8120261118030002/?pageType=showResult)

映像を読めた区間の観察を、日付順に個人別の研究用確率に反映した。採点日の結果・映像・実際の追走相手を予想に渡さず、同じ区間の過去の集団分布と、そこに当該選手の履歴を加えた場合を比較した。履歴のない選手も対象に残した。同じ選手を同じ区間で別日に再評価できた4件では、集団基準と個人履歴を加えた場合のどちらも最多確率の判定は3件的中した。三連単の的中率向上は未検証。[区間別の採点・未観測の扱い](results.json)
