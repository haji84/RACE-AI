# 競輪の3年分の全掲載レースを対象とする映像学習

2023年11月24日から2026年11月23日までの1,096日すべてで、Kドリームスの開催日・場・レース番号・詳細ページを確認した。全掲載82,774件を台帳に取り込んだ。前回の学習で全車の着順を確認できた76,005件に加え、着順が欠けていたレースも対象にした。7件は2媒体が競走中止と記録している。映像作業の台帳には残り82,767件がある。[全期間と月別の件数](results.json) · [前回の着順ベースの学習](../keirin-rolling-three-year-20261124/analysis.md)

| 確認したもの | 実数 |
| --- | ---: |
| 台帳に載った延べ出走者 | 587,009 |
| 車番を登録番号に結べた延べ出走者 | 586,679 |
| 特定できた選手の登録番号 | 2,636 |
| 全出走者の登録番号と名簿の完全性を確認できたレース | 78,015 |
| 再生映像を確認できたレース | 78 |
| 仕掛けか追走を具体的に読めたレース・選手 | 15レース、29人 |
| 最終周に全員の仕掛けと追走を両方確認できたレース | 0 |

個別に確認した出走表を過去3年に再照合し、登録番号が未確認だった延べ29,089車のうち28,759車を新たに特定した。残り330車は未確認。中止を確認した7件を除く4,752レースは、全出走者が確定していない4,454件と、一部の登録番号が未確定の298件。月次資料、保存済み出走表・結果と日別一覧を照合した。過去の所属・氏名・期別・車番と、独立した2媒体の選手情報を利用して、当時走った選手を名寄せした。同名や表記揺れで本人を確定できない場合は未確認として残した。名簿の不足は登録番号まで全員そろったレースの件数に反映している。[登録番号照合と資料別の集計](results.json)

## 映像から学習に使えたもの

時刻・ハッシュを照合した静止画が1,636枚ある。連続再生できた3件のダイジェストは計221.32秒、5,533フレーム。選手別の仕掛けと追走を計88項目確認し、43項目を学習に使い、45項目に判読不能の理由を残した。件数には同じ出走を短い区間と最終周全体の両方で判読した例も含まれる。[区間・判定別の実数](results.json)

- 2025年9月16日函館5Rで、5番の市本隆司は4番を追い、最終ホームからバックの間に外へ出て追い越した。2番の内藤敦は終盤に5番の後輪から離れた。4・6・7番は決勝線の通過が画面外で、その選手の全周は未確認とした。[函館5R](https://keirin.kdreams.jp/hakodate/racedetail/1120250914030005/?pageType=showResult)
- 2024年5月4日いわき平1Rでは2・3・5・7・9番の最終ホーム線と決勝線の通過を別々に読み取り、別の観測でも5人すべての時刻の範囲が重なった。映像で3番が4番を追い越し、2番が3番を追い越す場面を確認した。「前の選手を自分が抜いた」と「前の選手について行けなくなった」は別の履歴にした。[いわき平1R](https://keirin.kdreams.jp/iwakitaira/racedetail/1320240430050001/?pageType=showResult)
- 2026年11月20日小倉2Rは、ダイジェスト内の4秒間を全101フレーム確認した。1番はこの区間で新しく仕掛けなかった。同じ選手の別日の仕掛けを加えると、この実際の判定に置く確率は全体基準の14.3%から11.4%に下がった。対象区間は粗い静止画を見て選んでおり、後日の未知レースでの実証には数えない。[小倉2R](https://keirin.kdreams.jp/kokura/racedetail/8120261118030002/?pageType=showResult)

映像を読めた区間の観察を、日付順に個人別の研究用確率に反映した。採点日の結果・映像・実際の追走相手を予想に渡さず、同じ区間の過去の集団分布と、そこに当該選手の履歴を加えた場合を比較した。履歴のない選手も対象に残した。同じ選手を同じ区間で別日に再評価できた4件では、集団基準と個人履歴を加えた場合のどちらも最多確率の判定は3件的中した。三連単の的中率向上は未検証。[区間別の採点・未観測の扱い](results.json)

## 残る範囲

通常の公開プレーヤーでは視聴可能な過去のダイジェストを再生できる。全開催を発走から全選手のゴールまで撮影した資料は確保できていない。GitHubの2026年11月10〜14日の暗号化収録アーティファクト15件は映像として読み戻せておらず、今回の学習数に含めていない。全レースを対象に処理を再開でき、映像の取得、対象車の登録番号、実際に読めた動き、未確認の残件を追跡できる。映像の判読には確認者が必要で、全国のレースの無人判読は未実証。[Kドリームスの案内](https://kdreams.faq.rakuten.net/detail/000033266) · [KEIRIN.JPの公式案内](https://keirin.jp/pc/dfw/portal/guest/guide/question/nyumon.html) · [台帳の作成・再開・再学習](reproduce.md)
