# 過去3年の競輪映像で確認できた展開と三連単の検証

対象は2023年11月24日〜2026年11月23日（日本時間）の1,096日。掲載82,774レースのうち中止を確認した7件を除く82,767件を台帳に残した。2026年11月25日未明の集計では、映像または保存済みの映像資料を確認したレースが累計123件、具体的な位置か選手の動きを読めたレースは111件。残る82,644件は映像未確認。期間外の11月24日分2件は別に数えた。[開催別の全レース番号と残件](three-year-replay-calendar.csv)・[全件の照合結果](all-watch-coverage.json)・[累計125件のレース別資料](public-race-observations.json)

この6開催日の残り58件をすべて公開プレーヤーで試した。別開催の再生復旧を確認するために2025年6月3日の松戸1Rも開いた。結果画面がHTTP 503で、今回の7開催日の試行は計59件、判読32件、取得・再生失敗27件となった。今回の32件すべてで最終バック（B）の先頭が判別でき、30件では2番手も読めた。4角先頭を判別できた29件では、24件がB先頭を維持し、5件で先頭が交代した。接戦で先頭を断定できなかった3件は学習から外した。4角の2番手を読めたのは26件だった。[映像ページと観察秒数・車番](public-new32.json)

いわき平2RではBで3番・4番の順、4角では4番・3番の順になった。小松島2Rでは先頭1番が変わらず、2番手が7番から4番に替わった。函館7Rでは2地点の先頭と2番手が同じでも、途中で7番が3番の前に出る場面があった。Bと4角の両地点で前後が同じという記録から、区間全体の追走継続や仕掛けの開始時刻は特定できない。[いわき平2R](https://keirin.kdreams.jp/iwakitaira/racedetail/1320231124010002/)・[各レースの観測地点](public-new32.json)

最初の6開催日で再生できなかった26件では、結果ページに入れても映像要素が生成されない場合と、プレーヤーが開いても映像幅と再生時間がゼロのままの場合があった。複数のレースで、当環境からスクリプトまたは映像配信へのHTTP 503を確認した。小倉5Rは映像要素が現れず、通信原因は未特定。小松島7Rの再訪と別日の松戸1Rでは、結果またはアーカイブの入口自体がHTTP 503だった。未確認82,644件には再生をまだ試していない開催も含まれる。以前に映像ボタンを確認した12,818件についても、再生可否や映像の内容は個別に記録する。[確認範囲と残件](all-watch-coverage.json)

## 選手別の追加学習で的中は増えたか

選手登録番号で照合したB先頭について、同じ選手が4角でも先頭にいる確率を学習した。11月20日までの従来45件に今回判別できた29件と従来の資料から回収した4件を加え、学習は78件になった。回収した4件には過去の勝敗を基準に選んだ事例が含まれる。以前も検証に使った後日の17件では、先頭維持確率の誤差（Brierスコア、小さいほど良い）は0.1904から0.1973に悪化した。[対象と採点](public-aggregate.json)

11月21〜23日の三連単は、対象211件のうち結果を同条件で採点できた207件で比較した。対象当日の実際のB・4角、着順を予想入力から除き、締切前に想定できる各隊列の確率を使った。

| 三連単の検証条件 | 1点 | 4点 | 8点 |
|---|---:|---:|---:|
| 従来の隊列学習（16件） | 26 / 207 | 69 / 207 | 93 / 207 |
| 先頭と2番手の推移を追加学習（18件） | 26 / 207 | 69 / 207 | 93 / 207 |
| さらに選手別の先頭維持確率を予想に反映 | 25 / 207 | 69 / 207 | 92 / 207 |

映像の追加による三連単の改善は確認できなかった。どの選手が仕掛けを始めたか、実際に誰がその後輪に付いていたか、どこで離れたか、B先頭がゴールまで残ったかは別々に記録する必要がある。既存の公開予想と本番設定への変更はない。[固定条件と比較結果](public-aggregate.json)・[追試手順](reproduce.md)

過去の結果表の「勝敗因」については、選手を照合できた177,210出走を翌日以降の履歴として別に検証した。63,487レースの三連単8点は20,635件から20,699件。締切前に出走表を保存した516件では206件から205件だった。短評の記述は映像確認件数に含めていない。[短評を使った三連単の採点](tactics-notes-study.md)
