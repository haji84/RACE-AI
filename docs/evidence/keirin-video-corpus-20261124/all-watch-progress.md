# 過去3年の競輪映像で確認できた展開と三連単の検証

対象は2023年11月24日〜2026年11月23日（日本時間）の1,096日。掲載82,774レースのうち中止を確認した7件を除く82,767件を台帳に残した。2026年11月25日未明の集計では、映像または保存済みの映像資料を確認したレースが累計123件、公開プレーヤーでの追加確認直後、具体的な位置か選手の動きを読めたレースは111件だった。その後、以前から保存していた資料を再読し、残る12件でも1地点以上を判読できた。現在は123件すべてに具体的な観測がある。残る82,644件は映像未確認。期間外の11月24日分2件は別に数えた。[開催別の全レース番号と残件](three-year-replay-calendar.csv)・[全件の照合結果](all-watch-coverage.json)・[累計125件のレース別資料](public-race-observations.json)

この6開催日の残り58件をすべて公開プレーヤーで試した。別開催の再生復旧を確認するために2025年6月3日の松戸1Rも開いた。結果画面がHTTP 503で、今回の7開催日の試行は計59件、判読32件、取得・再生失敗27件となった。今回の32件すべてで最終バック（B）の先頭が判別でき、30件では2番手も読めた。4角先頭を判別できた29件では、24件がB先頭を維持し、5件で先頭が交代した。接戦で先頭を断定できなかった3件は学習から外した。4角の2番手を読めたのは26件だった。[映像ページと観察秒数・車番](public-new32.json)

いわき平2RではBで3番・4番の順、4角では4番・3番の順になった。小松島2Rでは先頭1番が変わらず、2番手が7番から4番に替わった。函館7Rでは2地点の先頭と2番手が同じでも、途中で7番が3番の前に出る場面があった。Bと4角の両地点で前後が同じという記録から、区間全体の追走継続や仕掛けの開始時刻は特定できない。[いわき平2R](https://keirin.kdreams.jp/iwakitaira/racedetail/1320231124010002/)・[各レースの観測地点](public-new32.json)

最初の6開催日で再生できなかった26件では、結果ページに入れても映像要素が生成されない場合と、プレーヤーが開いても映像幅と再生時間がゼロのままの場合があった。複数のレースで、当環境からスクリプトまたは映像配信へのHTTP 503を確認した。小倉5Rは映像要素が現れず、通信原因は未特定。小松島7Rの再訪と別日の松戸1Rでは、結果またはアーカイブの入口自体がHTTP 503だった。未確認82,644件には再生をまだ試していない開催も含まれる。以前に映像ボタンを確認した12,818件についても、再生可否や映像の内容は個別に記録する。[確認範囲と残件](all-watch-coverage.json)

小倉競輪の公式YouTubeにも、2026年11月19日と日付が一致する第2日の全日中継（7時間5分10秒）が掲載されている。11月25日00:43日本時間に通常の視聴ページを開いた際は、ブラウザの接続エラーでページに到達できず、この中継によるレース追加は0件だった。[小倉競輪公式の当日中継](https://www.youtube.com/watch?v=pbSHuydkuj0)

## 確認した開催と選手の偏り

全42場のうち映像または保存資料を確認したのは34場で、8,289の開催日と場の組のうち78組に集中した。2026年分は期間内の対象レースの29.8%だが、映像等を確認した123件のうち79件（64.2%）を占めた。小倉19件、岸和田12件、いわき平と函館が各10件で、この4場だけで51件だった。[開催・レース別の台帳](three-year-replay-calendar.csv)

追加32件を取り込んだ段階で、最終Bと4角の先頭を確定できた95件のB先頭は67選手だった。53選手は観測が1走だけで、2走以上は14選手。学習期間内に限ると78件・64選手のうち55選手が1走だった。この標本では、特定選手が同じ展開を繰り返す頻度を広く評価するには例が少ない。[選手登録番号と観測地点](public-race-observations.json)

## 保存済み映像を再読して見つかった展開

旧資料78レースのうちBと4角の両方を確定できていなかった24件をすべて再読した。新たに13件を判定でき、10件を過去の学習、3件を後日の検証に加えた。B先頭から4角先頭への推移を扱えるのは計108件で、学習88件・検証20件。108件にB先頭として登場したのは78選手で、62人は1走だけだった。学習に限ると88件・73選手のうち63人が1走のみ。今回読み直した24件は累計123件の内数。[24件の観測・判定保留と採点](local-frame-coverage.md)

以前に固定した95件と確定1着の照合では、Bの先頭が4角も先頭だった75件のうち、勝ったのは28件だった。負けた47件のうち、4角の2番手も確認できた35件では26件でその2番手が勝った。この2番手は実際の走行位置で、予定ラインの番手に限らない。95件の4角は映像から読み、Bのうち11件は2媒体の結果票で確認した。[ゴールとの照合・選手別の件数](b-corner-finish.md)

従来45件、公開プレーヤーからの追加後78件、保存済み資料の再読後88件で、B先頭が4角でも先頭にいる確率を同じ後日20件で比較した。Brierスコアは0.1691、0.1730、0.1737と順に悪化した。今回の再読で判定できた3件だけでは改善し、従来から判定できた17件では悪化した。過去に同じレースの別区間だけが登録済みだった分も区間単位で照合すると、締切前の出走表とB・4角の前2車がそろう学習例は18件から20件に増えた。この区間を更新した三連単の採点207件は1点26、4点69、8点93件だった。[同一条件の比較](local-frame-coverage.md)

B→4角と4角→確定1・2着の両区間に、過去の出走表と照合できた観察をすべて使う条件も採点した。B→4角は20例、4角→1・2着は22例。締切前情報から作った211件の三連単を固定し、同じ207件で確定着順と照合した。

| 1点 | 26 / 207 | 26 / 207（12.56%） |

4点は1件増え、8点は同数だった。すでに評価に使った日の再検証であり、将来の精度改善は未確認。[4角の2番手と締切前の三連単を結んだ検証](b-corner-finish.md)

## 公開プレーヤー32件を追加した段階の比較

選手登録番号で照合したB先頭について、同じ選手が4角でも先頭にいる確率を学習した。11月20日までの従来45件に今回判別できた29件と従来の資料から回収した4件を加え、学習は78件になった。回収した4件には過去の勝敗を基準に選んだ事例が含まれる。以前も検証に使った後日の17件では、先頭維持確率の誤差（Brierスコア、小さいほど良い）は0.1904から0.1973に悪化した。[対象と採点](public-aggregate.json)

11月21〜23日の三連単は、対象211件のうち結果を同条件で採点できた207件で比較した。対象当日の実際のB・4角、着順を予想入力から除き、締切前に想定できる各隊列の確率を使った。

| 三連単の検証条件 | 1点 | 4点 | 8点 |
|---|---:|---:|---:|
| 従来の隊列学習（16件） | 26 / 207 | 69 / 207 | 93 / 207 |
| 先頭と2番手の推移を追加学習（18件） | 26 / 207 | 69 / 207 | 93 / 207 |
| さらに選手別の先頭維持確率を予想に反映 | 25 / 207 | 69 / 207 | 92 / 207 |

映像の追加による三連単の改善は確認できなかった。どの選手が仕掛けを始めたか、実際に誰がその後輪に付いていたか、どこで離れたか、B先頭がゴールまで残ったかは別々に記録する必要がある。既存の公開予想と本番設定への変更はない。[固定条件と比較結果](public-aggregate.json)・[追試手順](reproduce.md)
