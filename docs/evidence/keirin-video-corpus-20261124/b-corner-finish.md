## 再現手順

1. 公開観測表（SHA-256 `5b94663ed835818baf26dd532f1ac92ecef74f1dbbd3e078e3634cc054863f07`）125件を固定し、`readable_B_to_corner == true` の95件を選ぶ。開催日・場コード・Rの組をキーとし、`B_car` と `published_B_car` の一致、出走表でのB選手の登録番号を確認する。4角の先頭車も同じ出走表に照合する。[公開観測表](public-race-observations.json)
2. 各レースの結果ページの確定1着車番を同じキーで結ぶ。90件は既存3年研究の完全着順と一致し、うち1件の登録番号は統合出走表で補った。残る5件のうち、2023年11月24日いわき平7R・2025年1月15日松山5Rは月別資料の1着と三連単の先頭車番、2026年11月20日小倉8R・11月21日豊橋7Rは保存された結果、確定組と公開結果で照合。9月18日武雄7Rは既存の個別照合により沢田がB先頭で3着、2番車が1着と確認した。95件すべてでB・4角・確定1着の車番が登録番号付きの当日出走者に対応する。[3年研究での確定方法](../keirin-rolling-three-year-20261124/analysis.md)・[個別照合](../keirin-rider-phase-video-20261124/named-rider-cases.json)
3. `fold == earlier_training` が78件。そのうち `source_groups` が `["current_viewing"]` の行と `historical_purposive_win_loss_sample == true` を除くと旧45件になる。残りの異なる3つの評価区分を合わせた17件を、両条件で同じ順序・同じ確定着順で採点する。
4. 学習全体の件数を N、B先頭が確定1着だった件数を W として、共通確率を p = (W + 1) / (N + 2) とする。評価対象のB選手と同じ登録番号で過去に n 件あり、w 回1着なら選手別確率を (w + 4p) / (n + 4) とする。n = 0 なら共通確率に一致する。正解はB車番と確定1着車番が同じなら1、それ以外は0。17件の「予測確率と正解の差の二乗」の平均が表のBrierスコアになる。

以前の研究では、結果票から選手別のB先頭と確定1着を収集し、3選手の公開ダイジェストも個別に確認した。今回の追加分は、この95件での4角を挟んだ内訳、4角の2番手と確定1着の照合、同じ17件での確率比較、過去6件を加えた三連単の再評価である。[既存研究](../keirin-rider-phase-video-20261124/analysis.md)
