**出走表の予想印**は、モデルが特定の印の選手を1・2・3着に置く確率を補正する。5月23日までの16,033件で係数を推定し、5月24日～11月20日の12,234件には同じ係数を適用した。8点の差は+0.51ポイント、日単位の対応あり95%区間は+0.23～+0.81ポイント。過去のSQL保管分はすべて結果と同時刻の取得だった。11月20日の48件では、別に残った締切前原票で全車の印が一致した。この48件で1点は8→8、4点は16→14、8点は20→22。1日分の事後採点である。[原票の時刻と再現の監査](programme-tip-source-audit.json)

月別CSVの並び欄にある印は、元の出走表と23件中15件で一致しなかったため除外した。直近287件は282件で締切前に同じ掲載元・車番の印を確認し、5件は元の順位を使用。直近で新たに当たった6件の一方、以前の的中8件を落とした。平均の対数損失は4.153→4.140と小さくなったが、限られた買い目での的中は増えなかった。[学習方法・期間別の成績](programme-tip-results.json)

**番手が差す条件**を学習すると、先頭か番手が勝った直近233件で、実際の勝者を相手より上に置けたのは168→177件だった。新たに順番を正せた13件でも、三連単の買い目に正しい1・2着が両方入ったのは5件、3着まで入ったのは2件で、どちらも変化しなかった。女子959件の8点でも、正しい1・2着の組が入ったレースが22件増えた一方、その組に正しい3着が入らない外れが140→159件に増えた。[選手別の比較と得失](rider-and-odds-results.json)

**番手が競りになるレース**は、過去に競りが記載された96件を調べ、後続がどちらを追うかまで特定できた46件を照合した。2通りの並びを等確率で予想した場合、3月までに調整したモデルの8点は9/46→14/46、4点は5/46→7/46。8点の新規的中6件は、正しい1・2着の組を拾えたもの3件、3着を選び直せたもの3件。以前の的中を1件落とした。2通りを等確率とする仮定があり、46件中、並びに締切前の保存記録があったのは2件。11月25日の静岡9Rでは、締切前に固定した両案とも掲載4点で外れ、8点までの順位では元の予想だけが的中した。[競りの対象条件と採点](rider-and-odds-results.json)

## 先行選手と番手の決着、レースごとの戦法

過去の番手勝ち9,558例から、そのとき先行選手が2着・3着・圏外のどこに入るかを数えた。同じ2人の同走数が少ないときは、車数・並び・得点順が似たレースの分布に近づけた。番手の勝率を固定してこの情報を足すと、12,234件で1点が1,248→1,256、4点が3,234→3,228、8点が4,583→4,580だった。番手が勝ち、先行選手が4着以下の1,141件では、8点で新たに拾った1件に対し元の的中9件を失った。直近287件の掲載点数では93→94で、増えた1件は番手勝ち以外のレースだった。

Kドリームスの「並び予想」には、車番ごとに押え先・追上・イン待など9種の予定戦法がある。過去519レースを復元し、そのほかに11月21・23・25日の198レースで締切前の原票まで確認した。過去284件で着順への補正を学習し、後続80件の4点は13→13、8点は23→22。現行方式と比べられる直近119件の掲載点数は44→44（新規2件、失点2件）。予定戦法は同じ普段の脚質でも異なる。予定どおりの位置で実際に仕掛けたかは、出走表のこの欄からは判定できない。[着順の組み直しと予定戦法の採点](joint-and-tactics-results.json)

過去12,234件のうち、時刻と出走車が一致する締切前の選手別H回数を独立に確認できたのは109件。映像補正を再計算する入力、締切前の全組オッズ、H回数の三つがそろったのは3件で、いずれも現行係数の学習最終日の11月20日だった。全入力をそろえた現行モデルを当時の締切前に実行した成績として、過去12,234件を扱うことはできない。

**予想印と今の方式との相性**も追加検証した。映像補正を入れる前の同系統の着順予測を、各期間より早く学習した係数で再現した。10,867件全てで、元の上位8点が順番まで過去の記録と一致した。この分布に5月23日までに固定した予想印の補正を加えると、4点は3,181→3,133（114件を拾い、162件を失う）、8点は4,451→4,435。4点で実際の勝者が1着欄に入った数は7,276→6,978、正しい1・2着の組が入った数も4,708→4,524に減った。もともと予想印が入っていた10,544件で4点の的中は45件減少し、入っていなかった322件でも3件減少した。元のモデルでの印の有無だけではこの差を説明できない。11月20日までに学習した現行の映像係数を過去の検証には持ち込まなかった。[同系統モデルでの追加検証](joint-and-tactics-results.json)

採点コマンドは同一レースの公開台帳にある締切と出走車を確認し、二つの掲載元で確定した三連単だけを採点する。レースごとに同じ点数を使い、新規的中・取りこぼし・未確定の件数を出す。原本の登録時刻の確認には各案のGitHub記録を併用する。

python -m scripts.keirin_forward_score --predictions predictions.json --receipt receipt.json --roster roster.json --results results.json
