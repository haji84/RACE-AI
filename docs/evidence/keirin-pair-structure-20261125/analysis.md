# 三連単の1・2着の組み合わせと11月26日の事前登録

## 8点で外れる箇所

過去の時系列比較12,234件を、締切前資料に基づく旧方式の順位で採点した。8点で4,583件的中。外れ7,651件の内訳は、勝者を1着欄に入れられなかった3,213件、勝者は入っていても正しい2着と組めなかった2,694件、正しい1・2着は入っていて3着を外した1,744件。正しい順の1・2着を落とした5,907件のうち、組の確率を3着全候補で合算して8位内に入るのは1,965件。残る3,942件は組そのものが8位外だった。

上位8組に1点ずつ割く固定方式は、別ライン決着の的中を490→705件に増やし、同ライン決着を3,210→2,229件に減らした。全体は4,583→3,570件、締切前の取得時刻も確認できた321件では119→104件。的中候補の順位を全組で調べると、旧方式の過去予想で正解を95%含むまでに全標本では131位、時刻付き321件では111位を要した。元の順位分布の診断であり、本研究の上限8点は維持する。[外れの段階と標本](miss-decomposition.json)・[全組順位の診断](independent-review.json)

## 映像で確かめた展開と外れ

11月16〜19日から出走表の締切前原本と公式Bを確認できる15件を着順に触れずに選んで再生した。両地点で順序付きの先頭2車を読めた9件を追加すると既存の学習候補が24→33件、別ラインへの先頭交代は2→3件だった。さらに別ラインへ交代した例が1件あったが、Bの2番手が確定できず学習行には入れていない。事前に定めた別ライン交代4件の条件には未達。

別に、11月24日に公開した元の8点で勝者を拾い、実際の2着を落とした3件を選んだ。別ライン決着の2件は2着のライン自体が候補外。同ラインの1件は正しいラインから別の選手を選んでいた。全3件のBの先頭と当日の登録番号を公式記録で照合した。外れから選んだ3件は原因を調べるための事例で、無作為な的中率の標本に加えない。[追加した映像15件](video-extend.json)・[追加5件の判読](video-extend-further.json)・[外れの3件](video-targeted.json)
