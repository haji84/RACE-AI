# 競輪3連単を8点で95%に近づけるための過去走検証

## 過去の走行と成績を照合

2025年10月〜2026年9月から、日付・場・R・全出走車と氏名・予定ライン・完全着順・払戻を照合できた23,750レースを採用した。23,750件でBが1人、22,348件でSが1人と確認できた。延べ168,619出走のうち165,181行を登録番号に結び付けた。過去の先頭・番手・後位・単騎ごとに、S・Bの取得、Bを取った本人の2着以内、同じラインまたは別線がBを取ったときの着順を集計した。同じラインの選手の組には、過去に同時に上位に入り、どちらが先着したかを加えた。結果表のS・Bから分かるのは先頭にいた選手である。全員の通過位置、実際に離れた区間、仕掛け開始時点は今回の学習に含まれない。[固定した資料と学習条件](commitment.json) · [Kドリームス由来SQLite](https://github.com/sumidatadayoshi/keirin-data/tree/2a1260fb0940ad11160b56a36f9c24cc4fb2f6d2) · [公式のマークの見方](https://keirin.jp/pc/static/beginner/keirin-glossary/numbers-alphabets.html)

過去走の履歴は前日までで作る。4〜5月の評価用履歴は3月31日、10〜11月の評価用履歴は9月30日で固定した。従来の着順評価に、過去のS・Bとライン内外の着順を足す方式、さらに同じラインの相手との過去成績を足す方式を比較した。先の期間を学習し、続く調整期間だけで上位8点、次いで4点の順に評価して方式を選んだ。両期間ともS・Bとライン内外の着順を足す方式を選んだ。予想用の入力に対象レースの結果・払戻・オッズは含めていない。後日取得の出走表があるため、当時の締切前の保存版557件でも照合した。[4〜5月の係数](earlier-config.json) · [10〜11月の係数](recent-config.json) · [採点前の固定を確認したGitHub Actions](https://github.com/haji84/RACE-AI/actions/runs/45282202826)

## 1・4・8点の再現試験

| 同じレースと点数で比較 | 1点 | 4点 | 8点 |
| --- | ---: | ---: | ---: |
| 10〜11月の保存方式・3,989件 | 479件・12.01% | 1,125件・28.20% | 1,579件・39.58% |
| S・Bとライン内外の着順を追加 | 483件・12.11% | 1,138件・28.53% | 1,579件・39.58% |
| さらに同じラインの相手との履歴を追加 | 483件・12.11% | 1,137件・28.50% | 1,578件・39.56% |

10〜11月は4,002件中3,989件を照合した。追加史料の413件は保存方式の候補を3条件で共通に使った。この413件には前回復元した412件と、出走表の着順実績を事後に補った1件が含まれる。S・Bとライン内外の着順を加えた方式は8点で59件を拾い直し、別の59件を落とした。差は0.00ポイントで、日単位の95%区間は−0.45〜+0.45ポイント。4〜5月の4,621件では8点が1,875件から1,872件、締切前の元出走表557件では211件で同数だった。元出走表557件の4点は156件から162件。同じ相手・役割での過去レースが3件以上ある組を一つ以上含むのは、10〜11月の元入力3,590件中509件だった。3,989件の95%に必要な3,790件に対し、上位8点は1,579件だった。[期間・点数別の採点](results.json) · [4,002件の出走表の範囲](../keirin-ordered-ticket-20261124/analysis.md)

## なぜ8点に正解が残らないか

全車・予定ラインのある10〜11月の3,576件で原因を調べた。下表は同着時の複数払戻を除いた3,559件。グループは事後の着順で決めた。並びは当時掲載された予定ラインを使う。[着順別の原因集計](results.json)

| 確定した1・2着の順序 | レース数 | 保存方式の8点 |
| --- | ---: | ---: |
| 同じラインで前の選手が先着 | 1,173件 | 748件・63.77% |
| 同じラインで後ろの選手が先着 | 694件 | 362件・52.16% |
| 別々のライン | 1,692件 | 288件・17.02% |

別線の1,692件中1,184件で、上位8点に正しい1・2着の順序がなかった。この3,559件で95%にするには、同じラインの1,867件を全て当てられたとしても、別線で1,515件（89.54%）の的中が必要。Bを照合した3,471件でBを取った本人の勝ちは1,095件（31.55%）、そのライン以外の勝ちは1,431件（41.23%）だった。S・Bを両方確認した3,350件で最初のSと最後のBが同じラインだったのは1,591件（47.49%）。[決まり手・Bと着順別の集計](results.json)

別線を最低2点含める再配分も試した。10〜11月の3,576件で別線の的中が288件から329件に増えたが、全体は1,403件から1,378件に下がった。正しい1・2着の順序が8点に入る件数は1,909件から1,962件に増えた。6〜7月の別試験4,665件でも全体は1,829件から1,782件。10〜11月に方式が別線へ割り当てた確率の平均は49.26%、一意に判定できた3,572件で実際に別線だった割合は47.56%。上位の候補では同ライン内の数組に確率が集中し、別線側は多くの組に分かれる。別線を一律に増やすと、まとまっていた同ラインの候補を削るため的中全体が下がった。[再配分の固定](cross-commitment.json) · [再配分の採点](cross-results.json)

正しい展開の情報を仮に教えてもらった場合も、保存順位で上位8点を取り直した。3,576件で、勝者の予定ラインだけが分かると1,998件（55.87%）、勝者本人が分かると2,501件（69.94%）、1・2着が所属する二つの予定ラインと順序が分かると2,890件（80.82%）。勝者本人と2着選手の予定ラインの両方が分かると3,392件（94.85%）。実結果を使った事後の診断で、同じ3,576件の保存方式の再現成績は39.23%だった。[固定順位を使った情報別の診断](results.json)

## 3年分の確定人気との比較

2023年11月24日〜2026年11月23日の固定CSVとSQLiteから、重複を除いた82,406件を調べた。11月22日までの81,967件で払戻と確定人気を確認できた。上位1点は11,148件（13.60%）、4点は26,715件（32.59%）、8点は37,204件（45.39%）。確定人気順で過去の95%を拾うには113点を要した。表示順位の意味を確認するため、保存したレース詳細23件と日付別払戻6,078件で、払戻組・金額・人気順位を照合した。確定人気は事後の比較に使った。[市場の集計と出典](market.json) · [月別CSVの固定版](https://github.com/Kenseimk/keirin-data/tree/8ba8316329c145aea55b5ada529b0af7b0d94c48/keirin_data)

10〜11月の同じ3,497件で全ての確定払戻組が一致した。確定人気8点が1,563件（44.70%）、保存方式8点が1,364件（39.00%）。いずれかの8点が当たれば拾う事後比較でも1,696件（48.50%）。日付別の払戻で85件を補っても、同じ比較では3,582件中1,742件（48.63%）だった。最大16点を含む比較で、同じ点を除いた実際の点数は未確認。終盤のオッズを将来の入力に使う試験では、締切前の取得時刻を確認できる価格を別途確保する必要がある。[同じレースでの比較](market-shared.json) · [日付別払戻を加えた照合](market-shared-supplement.json)

## 次に集める情報と検証条件

公式の過去結果から新たにHとBを同じ登録番号で照合できた。旧い各月の7車1件などを含む31件では、全件にH・Bそれぞれ1人の記録があり、7件は選手が替わった。10〜11月の12日間から出走表で選んだ7車・9車各24件でも、全件にHとBがあり、15件で先頭が替わった。うち14件は予定の所属ラインも替わった。通常の結果票では全員の通過順位や仕掛け開始は得られず、松阪の公式レポートでは最終Hで競っていた位置、その後のBの通過順、仕掛けた区間を個別に確認できた。この標本から全競輪の交代率は推定していない。一般のレースで同じ粒度を満たす記録や映像の調査が残る。[公式79件の照合](official-phase-sample.json) · [H・Bの定義](https://keirin.jp/pc/static/beginner/basics/rules.html) · [松阪の公式レポート](https://keirin.jp/pc/dfw/portal/guest/report/GIII/47matsusaka/2025/report_3.html)

まず締切前の並びと変更時刻を保存し、過去走のH→Bの先頭・ライン交代と登録番号で結び付ける。仕掛けた区間や番手の追走成否は、公式記述か通過位置が確認できる映像からラベル化する。次の比較では、別線から勝者や2着が出るときの組の順位、そこから3着まで残る率を測る。全レース8点の同条件で、1・2着が入る率と、その候補で3着まで合う率の積が95%に届くか確認する。

11月24日の並び付き66件について、2026年9月末までの履歴を使う比較を07:43:09 JSTに固定した。登録番号を確認できたのは延べ455出走で、同じ役割の過去Bの観測が3件以上あるのは446行。最初の締切は08:45 JST。前向きの成績は結果照合後に判定する。[前向き予想の固定](forward-commitment.json)
