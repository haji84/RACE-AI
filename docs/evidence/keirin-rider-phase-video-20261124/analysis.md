## 映像から学んだこと

前回はバックと4角の先頭を読めた学習14件、後日評価13件の間に、同じバック先頭選手が0人だった。後日の評価映像でバックを先頭通過した選手のうち、過去のバック先頭記録が多い6人について、別開催を含む過去映像を2本ずつ追加した。車番と氏名を出走表・結果票で照合し、バック先頭は結果票のB印とも照合した。4角で並走した小田原7Rの1件は、前輪の前後を判断できず採点対象の学習例から外した。4角はダイジェスト上で先頭が判別できる付近の時刻で、全周の順位や仕掛け開始を一律にラベル化していない。[12レースの観測点・結果票・照合時刻](results.json)

11月20日以前の確認済み25本で、バック先頭が4角付近でも先頭を保った事例は20件だった。選手別の方式は、従来14本から求めた共通確率を仮の4レース分として加え、同じ選手の過去1〜2本で確率を更新した。同じ25本から選手を区別せず確率を出す方式と比べ、11月21〜23日に同じ6人がバック先頭だった6件を採点した。バック先頭が4角付近まで残ったのは5件、そのうち1着を守ったのは3件だった。[固定した確率と採点](results.json)

| バック先頭が4角付近まで残る確率 | ログ損失 | ブライアスコア |
| --- | ---: | ---: |
| 同じ25本を全選手でまとめる | 0.460 | 0.142 |
| 過去映像で選手ごとに補正 | 0.379 | 0.113 |

指標は小さい方が予測誤差が少ない。選手別の差の大半は、前橋5Rで阿久津浩之選手がバックから4角までの間に先頭を交わされた1件による。6件は映像と登録番号で対応が取れたレースで、後日のバック先頭を基準に対象を選んでいる。展開が分かった後の条件付き診断であり、レース前にそのバック先頭を正しく予測できたかは別の集計で測った。[前橋5Rの映像](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/2220261120/22202611200200/5/) · [採点対象と選定範囲](results.json)

## 確定結果の履歴を使った三連単の再現

映像の6件とは別に、2025年10月〜2026年9月の結果票から、登録番号を確認できたバック先頭23,535件、1,423選手を学習した。以前の研究版を基準に、予定ラインでの役割・車数・出走時得点、次に登録番号と役割別の実績、最後に別線で最高得点の選手との対戦履歴を順に加えた。過去実績の重みは180日で半減させ、対戦履歴は3件以上の組を使った。実際のバック先頭は採点時の条件付き確率にだけ使った。三連単の比較候補は、各選手がバック先頭になる事前確率で各展開を平均し、既存研究版との差を25%反映する設定で固定した。対象レースの着順・払戻・オッズは当該レースの候補に渡していない。[候補の固定時刻・元資料・学習設定](results.json)

10月1日〜11月23日にバック先頭を確認できた3,244件で、押し切る確率のブライアスコアは0.1664から0.1639になった。締切前の版を確認できた434件でも0.1740から0.1708。別線の同じ選手との対戦を使えた例は全体で10件、締切前の版だけでは0件だった。[条件付き確率と対戦履歴の採点](results.json)

| 照合範囲と方式 | 1点 | 4点 | 8点 |
| --- | ---: | ---: | ---: |
| 3,989件・既存研究版 | 493 | 1,153 | 1,616 |
| 3,989件・選手と役割を加えた版 | 487 | 1,153 | 1,613 |
| 締切前の出走表557件・既存研究版 | 70 | 166 | 223 |
| 締切前の出走表557件・選手と役割を加えた版 | 67 | 167 | 221 |

全件比較には締切前の版を証明できない出走表も含む。4,002件で候補を作成し、確定結果と三連単の組が照合できた3,989件を採点した。8点では追加4件、取りこぼし7件。差の日別95%区間は−0.226〜+0.075ポイントだった。失った7件中5件は、正しい1・2着の順序が8点内に残り、同じ1・2着で正しい3着を落とした。事前予測で実際のバック先頭を最上位に置けたのは2,049/3,244件だった。押し切る確率に加え、どの番手が残り、別線や単騎の誰が入ってくるかを、同じ展開の下で評価する必要がある。[点数別の採点と取りこぼし](results.json)

今回の採点は日付順の過去再現。映像の選手別傾向は4角の診断までを対象とし、三連単の表は結果票から学んだ候補の比較である。局面予測・ライン・戦術履歴に関する既存13テストを実行し、全件の成功と集計の再現を確認した。[集計と検証記録](results.json)
