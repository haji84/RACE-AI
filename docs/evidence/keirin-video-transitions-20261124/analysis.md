# 競輪の映像からホーム・バック・4角の位置変化を学習する

Kドリームスの公開ダイジェストを16レース追加し、前回確認した映像も見直した。最終ホーム、最終バック、4角付近で先頭と次の車の車番を、確認できた時点ごとに記録した。出走表と結果票の車番・氏名を照合し、映像のバック先頭は結果票のB印で確認した。車が並走して前後を確定できない局面や落車後の局面は採点から外した。前後の位置を確認できる区間を記録しており、全選手の軌跡や仕掛け開始の瞬間は一律に確認できていない。[前回の映像学習](../keirin-video-following-20261124/analysis.md) · [今回の固定記録と集計](results.json)

11月16日川崎5Rでは1番が先頭を保ち、最終ホーム付近の34.38秒では4番が次にいた。45秒から47.5秒にかけて2番が外を進み、バック付近の47.5秒では次の位置にいた。55.38秒の4角付近でも1番・2番の順だった。11月17日静岡7Rでは、バック付近の49.47秒で5番・3番、4角付近の58.47秒で5番・4番だった。先頭が替わらず次の車が替わる変化を、先頭が交代する変化と区別した。[川崎5Rの映像](https://keirin.kdreams.jp/yenjoy/keirin-kaisai/race-card/result/3420261114/34202611140300/5/) · [静岡7Rの映像と対象範囲](results.json)

11月16〜20日の20レースを学習に使った。前後の車番を両方確認できたのはホームからバックが17件、バックから4角が14件。4角から確定した1・2着までの学習は14件。既存研究版の着順確率とバック先頭の推定を基に、同じ2車が残る、前後を入れ替える、先頭を保って次の車が替わる、別ラインから次の車が入る条件を学んだ。次の局面の確率は、あり得る前の局面の組をその予測確率で平均した。学習した1・2着の分布を25%反映し、同じ1・2着を仮定したときの3着には既存研究版の条件付き確率を使った。11月21〜23日の出走表から作った211レースの候補は、対象レースの映像と結果を採点に使う前に固定した。[比較基準と前回の補正](../keirin-video-following-20261124/analysis.md) · [学習期間・固定時刻・検証ハッシュ](results.json)

最終バックの比較基準は前回の映像学習版。前回の方式に4角の予測段階がないため、4角の比較には同じ出走表での既存研究版の1・2着確率を使った。三連単は比較基準と前回の映像学習版で表の成績が一致した。211件のうち4件は確定結果の照合が保留。8点では新方式で新たに1件を拾い、従来が拾った1件を落とした。[日別・局面別の採点と除外](results.json)

前2車が入れ替わったレースで比較すると、ホームからバックに替わった3件の上位4組は両方0件、バックから4角に替わった5件は両方3件。4角で1件増えたのは同じ組が残ったレースだった。別ラインの車が新たに次の位置に入った学習例は、ホームからバックの17件中3件、バックから4角の14件中1件だった。ホームの実際の2車を診断用に事後入力すると、バックの最上位が合う件数は12件中6件から9件に増えた。出走前に予測したホームの最上位で実際の2車が揃ったのは1/12件で、上位4組には10/12件入った。仕掛けで組が替わる場面の識別と、三連単の的中向上は今回の過去再現では確認できなかった。[組の変化と診断用の採点](results.json)
