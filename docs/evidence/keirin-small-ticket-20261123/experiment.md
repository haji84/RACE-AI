# 競輪の1点・4点・8点で90%を検証する

3連単の全採点レースを分母とする。2車単も独立して計測する。各版の上位1点、4点、8点を同じレースで比較し、可変点数では合計点数と各点数のレース数も記録する。

前回の採点期間とは重ならない2025年の月別アーカイブを使う。得点、予想印、脚質、級班を出走表の項目として取得する。アーカイブの印と車番を含む欄にはラインの区切りがない。印を車番に対応させ、並び・H・B・S・選手IDは欠測とする。2025年1〜7月で係数を学習し、8月で順位付けを選択する。9月は点数の決め方の調整にだけ使う。10月1日〜11月22日の予想は結果列を除いた出走表の項目で作る。GitHubに照合用ハッシュを置き、固定記録を確かめてから着順・払戻を読み込む。[月別アーカイブの固定版](https://github.com/Kenseimk/keirin-data/tree/8ba8316329c145aea55b5ada529b0af7b0d94c48/keirin_data)

現行Aと、前回の着順別の学習方式を2025年の学習期間だけで再学習した版を比較する。競走得点の場内順位・級班・脚質を加える設定と、先に置いた選手の印・脚質・得点差との関係を使って2着・3着を評価する設定を試す。頭を強制的に分散する設定も、同じ候補・同じ点数で比較する。8月の2車単4点と3連単8点が前回方式以上の候補から、3連単4点の的中が最大の設定を選ぶ。

9月では、平均4点を守る可変点数と、通常4点のうち上位4点の支持が低く追加の4点で拾える候補が多いときに8点を許す設定を比較する。後者は9月で8点のレースを25%以下とする。1点に絞る閾値の候補は、過去100件以上で95%ウィルソン区間の下限が90%以上となる場合に限る。この基準を満たした閾値はなかった。設定選択と同じ標本での判定は候補を挙げる工程で、採用判断には別標本での確認が要る。

補助比較では2026年11月23日の保存出走表と締切前オッズを使う。各レースで両方の取得時刻が締切前、掲載のオッズ更新時刻が取得時刻以前、オッズ表と出走表の車番が一致するものを集計する。アーカイブの元ページをハッシュで照合し、有効な途中オッズの人気順と、オッズ及び出走表の支持を事前指定の比率で混ぜる二つの設定を比較する。この日は既報の結果がある。締切前の入力を使った補助比較として、2025年の評価とは別の日と分母で報告する。

## 2025年10月1日〜11月22日の結果

1〜7月の確定15,826件で学習し、8月2,302件で着順を決める設定、9月2,345件で点数設定を選んだ。評価用の3,953件はすべて予想を固定してから採点した。アーカイブの採取コードは結果ページ内の出走表と予想印を抽出する。入力を出走表の項目に限定し、当該レースの着順・払戻の列は採点で開いた。2025年の資料には当時の締切前取得時刻の独立した証明がない。払戻と着順が整合する記録を採点し、あらかじめ決めた4日から各1件を別の掲載元で確認した。[予想固定の記録](forecast-commitment.json) · [GitHub Actionsの固定時刻](https://github.com/haji84/RACE-AI/actions/runs/45194534181) · [採点記録](results.json)

前回方式と比べた3連単の差の日別95%区間はいずれもゼロを含んだ。2車単4点は1,767件から1,811件（44.70%から45.81%）で、差の95%区間は+0.23〜+2.05ポイント。9月の各設定で支持が高い100件を個別に見ると、3連単は1点15件、4点36件、8点50件だった。[同点数の比較](results.json)

8点を全て同じ誤った1着に寄せた件数は491件から445件に減った一方、正しい1・2着が入っても3着が違う件数は510件から542件に増えた。採点後の原因調査として固定済み係数の組み合わせだけを変えた。1・2着を前回方式に固定し、3着の評価だけを入れ替えると4点の的中が810件から826件、8点が1,233件から1,238件に増えた。逆に1・2着だけを入れ替えると8点は1,223件に落ちた。全段階を入れ替えると3着側の改善が相殺された。これらの組み替えは原因調査用の事後比較。固定した評価版の選び直しには使っていない。[着順別の原因調査](results.json)

4点を基本に788件だけ8点へ広げると、3連単の的中は817件から918件に増えた。全3,953件で23.22%、平均4.80点。同数のレースを無作為に8点へ広げる場合の期待値より19.47件多く、分母全体で+0.49ポイント（95%区間+0.11〜+0.89）。平均4点を保つ調整は4点固定を選んだ。[可変点数と無作為配分の比較](results.json)

11月20日は出走表・オッズ表の保存コミット時刻が締切前で、全国発売のオッズと車番を確認できた7件を別に固定した。3連単4点は2件から3件、8点は3件から4件。掲載元の原HTMLは未復元。7件の結果は二つの保存結果資料で一致した。参考として、2025年の確定人気を後から集計できた3,918件では、上位8組に正解があったのは1,718件（43.85%）。確定人気はこの事後参考にだけ使った。[11月20日の固定記録](earlier-odds-commitment.json) · [採点記録](results.json)

並びのライン区切り、選手ごとの4コーナーまでの位置と仕掛け時点、締切10〜15分前の全国発売オッズが評価に十分な件数で揃っていない。3連単90%は未達。

## 再実行

Python 3.12とNumPy、SciPyがある環境で、学習・設定選び・点数調整の三つに分けたgzip圧縮JSONを使う。各レコードには `input`、`cohort: "annual"`、払戻が確認できた `outcomes` がある。レースは指定期間内で一意とし、入力は能力比較用の `line_groups: null`。予想固定用の入力は `outcomes` を除く。原本と照合用の情報は本人用領域で暗号化して保管した。

```sh
python -m scripts.keirin_small_ticket_study \
  --fit fit.json.gz --tune tune.json.gz --calibrate calibrate.json.gz \
  --output fitted-weights-local.json
```

レビュー後、前回方式の比較を現行の予想エンジンで統一し、平均4点の設定にも1点の選定条件を適用した。8月の比較、係数、9月の点数設定は最初に固定した結果と一致した。[固定した係数](weights.json) · [採点記録](results.json)
