# 競輪の1点・4点・8点で90%を検証する

3連単の全採点レースを分母とする。2車単も独立して計測する。各版の上位1点、4点、8点を同じレースで比較し、可変点数では合計点数と各点数のレース数も記録する。

前回の採点期間とは重ならない2025年の月別アーカイブを使う。得点、予想印、脚質、級班を出走表の項目として取得する。アーカイブの印と車番を含む欄にはラインの区切りがない。印を車番に対応させ、並び・H・B・S・選手IDは欠測とする。2025年1〜7月で係数を学習し、8月で順位付けを選択する。9月は点数の決め方の調整にだけ使う。10月1日〜11月22日の予想は結果列を除いた出走表の項目で作る。GitHubに照合用ハッシュを置き、固定記録を確かめてから着順・払戻を読み込む。[月別アーカイブの固定版](https://github.com/Kenseimk/keirin-data/tree/8ba8316329c145aea55b5ada529b0af7b0d94c48/keirin_data)

現行Aと、前回の着順別の学習方式を2025年の学習期間だけで再学習した版を比較する。競走得点の場内順位・級班・脚質を加える設定と、先に置いた選手の印・脚質・得点差との関係を使って2着・3着を評価する設定を試す。頭を強制的に分散する設定も、同じ候補・同じ点数で比較する。8月の2車単4点と3連単8点が前回方式以上の候補から、3連単4点の的中が最大の設定を選ぶ。

9月では、平均4点を守る可変点数と、通常4点のうち上位4点の支持が低く追加の4点で拾える候補が多いときに8点を許す設定を比較する。後者は9月で8点のレースを25%以下とする。1点への絞り込みには、同じ閾値の過去100件以上で95%ウィルソン区間の下限が90%以上となる条件を使う。評価期間の点数や閾値を結果に合わせて変更しない。

補助比較では2026年11月23日の保存出走表と締切前オッズを使う。各レースで両方の取得時刻が締切前、掲載のオッズ更新時刻が取得時刻以前、オッズ表と出走表の車番が一致するものを集計する。アーカイブの元ページをハッシュで照合し、有効な途中オッズの人気順と、オッズ及び出走表の支持を事前指定の比率で混ぜる二つの設定を比較する。この日は既報の結果がある。締切前の入力を使った補助比較として、2025年の評価とは別の日と分母で報告する。
