# Rights-gated exact BOATRACE HTML GET (not activated), 2026-10-23

`race_ai/controlled_boat_html_capture.py` adds the **first optionally callable official-Web transport** in PR72. After an independent legal/terms/access-method reviewer decides an exact BOAT RACE `https://www.boatrace.jp/owpc/pc/race/racelist?hd=YYYYMMDD&jcd=NN&rno=N` GET is permissible at the chosen cadence/purpose, the caller can supply a rights checker. The transport makes exactly one HTML GET, accepts only exact URL and status 200, disallows redirects, bounds content to 1.5 MiB and 8s, and passes bytes to `boat_official_web_adapter`. It returns **AUDIT_ONLY**, not a forecast or actual cutoff proof. The HTML itself is not stored in the public repo.

No production reviewer/checker has been configured. Do not activate with a trivial always-true callback; the synthetic tests use such callbacks only as test doubles. BOAT RACE's published policy prohibits disruptive massive access; compliant bounded fetch requires individual review of terms, relevant legal exemptions, robots/access expectations, caching, requests/hour and source ownership. This is not a legal conclusion that every screen is authorized for AI training or republication. The current public feed shape is **not confirmed against actual native HTML yet**; parser must fail closed and be updated based on legitimate real source evidence.

Do not add cron or automatic credentials until source review and full E2E (true cutoff + SHA writer + independent run receipt + official result/revisions) are accepted. Existing PR71 model development is untouched.
