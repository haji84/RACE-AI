## 同じGitHub経路での継続手順

使用する実行は既存 `.github/workflows/boat-nationwide-ab-one-shot.yml`（workflow ID `405276784`）に一本化する。新しいscheduleやChatGPTタスクを作らない。既存トリガー `docs/evidence/boat-nationwide-pilot-trigger.txt` を1回更新すると起動する。

`race_ai/cycle_recovery.py` は当日の以前のrunをページングし、保存済み予想・結果訂正履歴を復元する。`race_ai/first_receipt_continuity.py` で最初の版だけ採点し、全記録を保全する。結果未確定を不的中として扱わない。原本不足や復元失敗時は理由を記録して停止し、成功と報告しない。
